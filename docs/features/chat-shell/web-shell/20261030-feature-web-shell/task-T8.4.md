## Investigation Notes
Решения оркестратора (2026-10-30), отменяют соответствующие пункты процедуры чек-листа:
- Измерение — прямыми HTTP-запросами из Node-скриптов в scratchpad, не в браузере. TTFT = от отправки `POST /api/chat/assistant` до первого SSE-чанка с событием `*-delta` (text или reasoning, одно правило на обе стороны; фактически во всех прогонах — `text-delta`). Один промпт, одна модель (`ASSISTANT_MODEL=anthropic/claude-haiku-5-5`), по одному разогреву на запуск сервера, затем 5 замеров на сторону; критерий median(after) − median(before) ≤ 50 мс, иначе отчёт без повторных прогонов.
- «После» — уже запущенный API ветки на `http://localhost:4000` (не останавливается); беседа создаётся `POST /api/threads`, её `id` идёт в `body.id`.
- «До» — `main@83fd532` в git worktree вне репозитория (scratchpad), `pnpm install --offline`, API на **PORT=4100** с `DATABASE_URL=postgres://agent:agent@localhost:5433/agent_os` и тем же `.env` (ключ не выводился). После — API остановлен, worktree удалён.
- T6.3-b — 20 бесед через API ветки (10 RU, 10 EN), опрос `GET /api/threads/:id` до непустого `title` (макс. 15 с) + строки `ThreadTitleService` в `api-dev.log`; после — удалить только эти 20 бесед.
