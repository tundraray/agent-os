## Наблюдения

1. **API при старте выполнил чужую задачу на платной модели.** В общей базе `agent_os` остались задачи тестов. Через 15 мс после старта воркер взял задачу типа `agent` владельца `e2e-07aa9706-e156-4705-83ec-6ff47e93c0cf` (`taskId b33931eb-ec41-4dd1-b48b-5e917e378d28`, шаг 8, девятый захват) и сделал настоящий вызов модели: 4 177 токенов входа, 449 выхода, 0,000747 USD. После этого задача ушла в `waiting`, других посторонних вызовов не было. В базе на момент старта ещё 565 задач `agent` в `waiting` и 20 тестовых задач в `queued`; любой запуск API с настоящим ключом на этой базе может потратить деньги на остатки тестов.
2. **Идентификатор сервера `backoffice` маскируется как секрет.** В строке лога старта: `"servers":["logs","[redacted]","tracker"]`. Причина: секретами считаются все значения `env` серверов (`secretValuesOf`), а у фикстуры `FIXTURE_SOURCE=backoffice` — 10 символов, выше порога в 8. Тот же маскировщик применяется к выводу и итогу `run_code` (`create-agents.ts:111`), поэтому слово `backoffice` в итоге скрипта модель увидела бы как `[redacted]`. В этом прогоне этого не случилось: в историях четырёх бесед `[redacted]` нет, ни один итог не содержал этого слова.
3. **Модель выбирала `run_code` там, где нужно, но в двух задачах сначала шла прямыми вызовами.** В задаче 1 — один `aggregate_logs` (потом полный результат прочитан через `readResult`, без повторного вызова). В задаче 2 — четыре `search_tickets`, чьи обрезанные страницы легли в контекст: это самая дорогая задача (68,7 тыс. токенов записи в кэш), хотя по сути она проще задачи 3. В задаче 4, где формулировка прямо говорит о страницах, модель сразу написала скрипт — и это самая дешёвая задача.
4. **Состояние между запусками не сохраняется, и модель платит за это повторными вызовами.** В задаче 3 третий скрипт заново сделал те же 16 вызовов `get_trace`, что и второй.
5. **Отказов и подтверждений не было.** Все шесть запусков — класс `read`, все вызовы из кода завершились `success`; ошибок уровня `error` и `warn` в логе API за прогон нет.
