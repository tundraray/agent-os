# Отчёт агента

## Purpose

Отчёт фонового агента или глубокого агента, который дошёл до родителя: в беседу или в историю родительского агента. С отчётом приходит уведомление — статус, число вызовов инструментов и длительность. После отчёта в беседе идёт обычный ответ чата на него.

## Anatomy

```
┌──────────────────────────────────────────────────────┐
│ Отчёт · Инциденты по оплате            ✓ Завершён   │  1 заголовок · 2 статус
│ 9 вызовов инструментов · 3 мин 40 с · 14:24          │  3 уведомление
│                                                      │
│ Открыто 3 инцидента по payments: INC-412 …           │  4 текст отчёта
└──────────────────────────────────────────────────────┘
⧉                                                         5 action bar
```

При сбое или остановке:

```
│ Отчёт · Сбор · выкладки за день          ⓧ Сбой     │
│ 30 вызовов инструментов · 6 мин 2 с · 14:41          │
│ Причина: исчерпан предел ходов                       │  6 причина
```

1. **Заголовок** — Heading: слово отчёта и описание агента (agent-platform UXRD, MC-18). Описание — ссылка на страницу агента.
2. **Статус** — [agent-status](./agent-status.md), вариант «Метка», справа в строке заголовка.
3. **Уведомление** — Caption, `--muted-foreground`, табличные цифры.
4. **Текст отчёта** — Body, Markdown как в ответе чата; не шире прозы (chat-shell UXRD, D-01).
5. **Action bar** — chat-shell UXRD, TH-10: «Копировать» копирует текст отчёта.
6. **Причина** — UI, `--foreground`; есть только у статусов «Сбой» и «Остановлен».
7. **Документ** — только у глубокого агента, который написал отчёт документом блокнота: под текстом отчёта вложенный блок с рамкой 1 px `--border`, радиус md, отступ 12 px. В нём заголовок документа Heading, описание Caption `--muted-foreground` и текст Markdown Body, свёрнутый до 24 строк обрезкой по строке без градиента. Под текстом — «Показать полностью» / «Свернуть» (`ghost` `sm`) и «Открыть в панели» (`ghost` `sm`); короче 24 строк — только «Открыть в панели». «Копировать» в action bar копирует текст документа.

Подложка `--card`, рамка 1 px `--border`, радиус lg, отступ 16 px; промежуток между заголовком и уведомлением 4 px, перед текстом 12 px.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Агент | Отчёт фонового агента | Как в Anatomy |
| Глубокий агент | Ответ запуска глубокого агента: отчёт финального сабагента или, без него, самого агента | В заголовке — имя записи вместо описания агента; если ответ ссылается на документ блокнота — часть 7 |
| Документ в панели | Документ блокнота, открытый на вкладке «Документы» панели беседы | Без рамки и без частей 2–3: стрелка назад к списку, заголовок документа Heading, описание, текст целиком и «Копировать». Пока агент пишет документ, рядом с заголовком — `LoaderCircle` и «Пишется», и текст дописывается в конец на месте, без анимации и без прокрутки к концу |

Размер один.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Статус «Завершён», текст отчёта целиком | Появляется сразу целиком, без каскада и без анимации фрагментов; длинный текст отчёта не сворачивается — сворачивается только документ (часть 7) |
| Документ раскрыт | Текст документа целиком, кнопка «Свернуть» | Раскрытие без анимации высоты; фокус остаётся на кнопке |
| Сбой, Остановлен | Статус, уведомление и причина; текст отчёта — если агент его успел сдать, иначе строка об отсутствии отчёта (UI, `--muted-foreground`, agent-platform UXRD, MC-18) | — |
| Повторный отчёт | Ещё один блок после продолжения с историей | Прежний блок не меняется |
| После перезагрузки | Как Default, на той же позиции ленты | — |
| В ветке | Документ (часть 7) — только заголовок и строка UI `--muted-foreground` о том, что документ остался в исходной беседе (create-and-test UXRD, MC-19); «Показать полностью» и «Открыть в панели» нет | Отчёт стоит в унаследованной части ветки, а документ принадлежит исходной беседе |
| Hover / Focus ссылки | Подчёркивание / кольцо `--ring` | Enter или клик открывает страницу агента |

## Content Rules

- Длительность — по [foundations → Language & Formats](../foundations.md#language--formats), строка «Длительность»; число вызовов — целая фраза с формами языка (там же, «Слова при числах»).
- Описание агента в заголовке усекается в конце; полное — в подсказке.
- В отчёте нет токенов, стоимости, статусов утверждений и групп уверенности.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | `article` с именем «Отчёт: {описание}»; заголовок — заголовок на уровень ниже заголовка страницы |
| Порядок чтения | Заголовок, статус, уведомление, причина, текст, документ (заголовок, описание, текст, «Показать полностью», «Открыть в панели»), «Копировать» |
| Документ | Вложенный `region` с именем — заголовком документа; «Показать полностью» — `button` с `aria-expanded` и `aria-controls` на текст |
| Документ в панели | Стрелка назад — `button` «Назад к документам»; «Пишется» и дописанный текст не объявляются |
| Клавиатура | Tab по ссылке агента, ссылкам в тексте и «Копировать» |
| Объявления | Приход отчёта объявляет экран |
| Цвет | Статус передают иконка и текст |
