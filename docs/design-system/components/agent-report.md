# Отчёт агента

## Purpose

Отчёт фонового агента или workflow, который дошёл до родителя: в беседу или в историю родительского агента. С отчётом приходит уведомление — статус, число вызовов инструментов и длительность. После отчёта в беседе идёт обычный ответ чата на него.

## Anatomy

```
┌──────────────────────────────────────────────────────┐
│ Отчёт · Инциденты по оплате            ✓ Завершён   │  1 заголовок · 2 статус
│ 9 вызовов инструментов · 3 мин 40 с · 14:24          │  3 уведомление
│                                                      │
│ Открыто 3 инцидента по payments: INC-412 …           │  4 текст отчёта
└──────────────────────────────────────────────────────┘
⧉                                                         5 action bar
```

При сбое или остановке:

```
│ Отчёт · Сбор · выкладки за день          ⓧ Сбой     │
│ 30 вызовов инструментов · 6 мин 02 с · 14:41         │
│ Причина: исчерпан предел ходов                       │  6 причина
```

1. **Заголовок** — Heading: слово отчёта и описание агента (agent-platform UXRD, MC-18). Описание — ссылка на страницу агента.
2. **Статус** — [agent-status](./agent-status.md), вариант «Метка», справа в строке заголовка.
3. **Уведомление** — Caption, `--muted-foreground`, табличные цифры.
4. **Текст отчёта** — Body, Markdown как в ответе чата; не шире прозы (chat-shell UXRD, D-01).
5. **Action bar** — chat-shell UXRD, TH-10: «Копировать» копирует текст отчёта.
6. **Причина** — UI, `--foreground`; есть только у статусов «Сбой» и «Остановлен».

Подложка `--card`, рамка 1 px `--border`, радиус lg, отступ 16 px; промежуток между заголовком и уведомлением 4 px, перед текстом 12 px.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Агент | Отчёт фонового агента | Как в Anatomy |
| Workflow | Отчёт запуска workflow: итог агента последнего шага шаблона | В заголовке — имя шаблона вместо описания агента |

Размер один.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Статус «Завершён», текст отчёта целиком | Появляется сразу целиком, без каскада и без анимации фрагментов; длинный текст не сворачивается |
| Сбой, Остановлен | Статус, уведомление и причина; текст отчёта — если агент его успел сдать, иначе строка об отсутствии отчёта (UI, `--muted-foreground`, agent-platform UXRD, MC-18) | — |
| Повторный отчёт | Ещё один блок после продолжения с историей | Прежний блок не меняется |
| После перезагрузки | Как Default, на той же позиции ленты | — |
| Hover / Focus ссылки | Подчёркивание / кольцо `--ring` | Enter или клик открывает страницу агента |

## Content Rules

- Длительность — «45 с», «3 мин 40 с», «1 ч 05 мин»; число вызовов — со склонением «вызов», «вызова», «вызовов».
- Описание агента в заголовке усекается в конце; полное — в подсказке.
- В отчёте нет токенов, стоимости, статусов утверждений и групп уверенности.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | `article` с именем «Отчёт: {описание}»; заголовок — заголовок на уровень ниже заголовка страницы |
| Порядок чтения | Заголовок, статус, уведомление, причина, текст, «Копировать» |
| Клавиатура | Tab по ссылке агента, ссылкам в тексте и «Копировать» |
| Объявления | Приход отчёта объявляет экран |
| Цвет | Статус передают иконка и текст |
