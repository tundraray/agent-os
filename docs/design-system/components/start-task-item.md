# Стартовая задача

## Purpose

Одна стартовая задача в редакторе глубокого агента: что сделать, какой сабагент делает и каких задач ждёт. Каждый запуск начинается с копии этих задач, поэтому карточка читается как первая строка будущего списка задач и несёт тот же номер. Ждать можно только обычные задачи выше по списку, а финальная задача одна и всегда последняя, так что по кругу задачи ждать друг друга не могут.

## Anatomy

```
┌───────────────────────────────────────────────────────────┐
│ Задача 2                                               ✕  │  1 номер · 2 убрать
│ Что сделать                                               │
│ [ Разобрать каждый инцидент из отчёта сбора            ]  │  3 текст
│ Кто делает  [ Глубокое исследование ▾ ]                   │  4 исполнитель
│ Ждёт        ☑ 1 · Собрать инциденты за ночь               │  5 зависимости
└───────────────────────────────────────────────────────────┘
┌───────────────────────────────────────────────────────────┐
│ Задача 3                                    финальная  ✕  │  6 метка финальной
│ Что сделать  [ Написать бриф по всем инцидентам        ]  │
│ Кто делает   [ Бриф ▾ ]                                   │
│ ⓘ Ждёт все остальные задачи: «Бриф» пишет ответ           │  7 заметка финальной
└───────────────────────────────────────────────────────────┘
```

1. **Номер** — «Задача {N}», UI 500; номер — место карточки в списке.
2. **Убрать** — иконочная кнопка `X` 16 px, `ghost`, с подсказкой.
3. **Текст** — обязательное многострочное поле UI с высотой по содержимому, 2–6 строк.
4. **Исполнитель** — обязательный список shadcn `select` из сабагентов команды по имени.
5. **Зависимости** — флажки по обычным задачам выше этой (финальной среди них не бывает): номер и текст задачи Caption, усечение в конце. У первой задачи части нет. Ни один флажок не отмечен — под ними Caption `--muted-foreground` «не ждёт — стартует сразу».
6. **Метка финальной** — [метка состояния](./state-badge.md), вариант «Источник», «финальная»; только у задачи сабагента, который пишет ответ.
7. **Заметка финальной** — Caption с `Info` `--info` вместо части 5: финальная задача ждёт все остальные.

Подложка `--card`, рамка 1 px `--border`, радиус lg, отступ 12 px; карточки идут столбцом с промежутком 8 px, по номеру. Подпись «Что сделать», «Кто делает», «Ждёт» — слева в колонке 112 px, в области уже 560 px — над полем.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Обычная | Исполнитель — не тот, кто пишет ответ | Части 1–5 |
| Финальная | Исполнитель — сабагент из «Кто пишет ответ» | Части 1–4, 6, 7 |

Вариант меняется сам, когда меняется исполнитель или «Кто пишет ответ». Карточка, ставшая финальной, переходит в конец списка за 150 ms и берёт последний номер; номера карточек ниже её прежнего места уменьшаются на один, а флажки других карточек, которые её ждали, снимаются с заметкой, как при уходе задачи.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Как в анатомии | Правка меняет форму, сохраняет её общая панель сохранения |
| Focus | Кольцо `--ring` у поля, списка, флажка или кнопки | — |
| Новая | Встаёт перед финальной, а без неё — последней, раскрываясь по высоте за 150 ms; фокус — в поле текста | Берёт номер своего места; финальная получает следующий |
| Убрана | Схлопывается за 150 ms; карточки ниже получают номера на один меньше | Флажки других карточек, которые ждали убранную, снимаются, под каждой такой — заметка `Info` об этом; фокус — на «Добавить задачу» |
| Нет текста | Рамка поля `--destructive`, под полем ошибка Caption `--destructive` | Появляется при сохранении; ввод снимает ошибку |
| Нет исполнителя | Ошибка у списка | То же |
| Исполнитель ушёл из команды | Список пуст, под ним ошибка с именем убранного сабагента | Сохранение отклоняется, пока не выбран другой |
| Исполнитель переименован | Список показывает новое имя | Задача следует за сабагентом без заметки |
| Вторая финальная | Ошибка у списка исполнителя на второй карточке финального сабагента | У того, кто пишет ответ, одна задача; сохранение отклоняется |
| Больше предела сабагента | Ошибка у списка исполнителя на карточке, с которой задач у сабагента стало больше, чем его можно звать за запуск | Сохранение отклоняется, пока задач не станет меньше или предел не вырастет |

Неудачное сохранение ставит фокус на первое поле с ошибкой, считая и карточки задач. Под reduced motion появление и уход — мгновенно.

## Content Rules

- Текст задачи — одно-два предложения: что сделать и что вернуть. Порядок задач задают зависимости, а не слова в тексте.
- Номер в карточке и номер этой задачи в запуске совпадают.
- Тексты — deep-agents UXRD, MC-7.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | Задачи — список (`ul`) с именем «Стартовые задачи»; карточка — `li` с заголовком «Задача {N}» |
| Убрать | `button` с именем «Убрать задачу {N}»; подсказка с тем же текстом |
| Поля | `textarea` и `select` с видимыми подписями; ошибка — `aria-invalid` и `aria-describedby` |
| Зависимости | `fieldset` с легендой «Ждёт»; флажок — с именем «Задача {N}: {текст}» |
| Заметки | Описание ближайшего поля; не объявляются |
