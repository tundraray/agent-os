# Поле инструкции

## Purpose

Одна секция с одним длинным текстом, который получают агенты: личная инструкция сотрудника на странице «Мой доступ» и инструкция организации в панели администратора. Сотрудник пишет текст, видит, сколько знаков осталось до предела, сохраняет его своей кнопкой и очищает, стерев текст. Секция собрана из полей [формы настроек](./settings-form.md); от короткой формы её отличают длинное поле со счётчиком, состояние «Изменено» и защита несохранённого текста, как в [редакторе записи](./record-editor.md).

## Anatomy

```
Как со мной работать                                       1 заголовок
Ваши агенты читают этот текст на каждом шаге.              2 пояснение
Его видите только вы.
┌────────────────────────────────────────────────────┐
│ Я SRE команды платежей. Отвечайте коротко,         │     3 поле
│ по-русски, с командами для терминала.              │
│                                                    │
└────────────────────────────────────────────────────┘
                                     Осталось 3 912 знаков 4 счётчик
● Есть несохранённые изменения  [Отменить правки] [Сохранить]  5 ряд сохранения
```

1. **Заголовок** — Heading, секция страницы.
2. **Пояснение** — Caption, `--muted-foreground`: кто получает текст и кто его видит.
3. **Поле** — многострочное, Body 16 / 26, высота по содержимому от 6 строк. На ширине ≥ 768 px — до 50 % высоты окна, дальше прокрутка внутри поля; на узкой поле растёт без своей прокрутки. Пустое поле показывает пример текста цветом `--muted-foreground`.
4. **Счётчик** — Caption, табличные цифры, `--muted-foreground`, справа под полем: сколько знаков осталось до предела.
5. **Ряд сохранения** — под счётчиком: слева состояние Caption, справа «Отменить правки» (`ghost`) и «Сохранить» (`default`). Пока изменений нет, состояния и «Отменить правки» нет.

Ширина секции — как у остальных секций страницы, поле во всю её ширину.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Сотрудник | Личная инструкция на странице «Мой доступ» | Комфортная плотность страницы сотрудника |
| Организация | Инструкция организации в панели администратора | Компактная плотность панели; под пояснением — предупреждение формы настроек о том, что текст доходит до каждого сотрудника и секретов в нём быть не должно; оно не мешает сохранению |

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Loading | Скелетон заголовка и поля высотой 6 строк | Пульсация по [foundations → Motion](../foundations.md#motion) |
| Ошибка загрузки | Вместо поля — текст ошибки и «Повторить» (`outline`) | Поля нет, пока текст не загружен: пустое поле нельзя спутать с пустой инструкцией |
| Пусто | Пример текста в поле; счётчик показывает весь предел | «Сохранить» недоступна, пока поле совпадает с сохранённым |
| Сохранено | Поле с текстом; ряд без состояния | — |
| Изменено | Точка 6 px `--muted-foreground` и «Есть несохранённые изменения»; «Отменить правки» видна | «Отменить правки» сразу возвращает сохранённый текст. Стёртый сохранённый текст — тоже «Изменено»: «Сохранить» доступна и сохраняет пустую инструкцию |
| Больше предела | Счётчик цветом `--destructive`: на сколько знаков текст длиннее предела | Ввод не обрезается. «Сохранить» ставит ошибку поля «Сократите текст на …» и фокус в поле; запрос не уходит |
| Сохраняем | «Сохранить» с индикатором и подписью «Сохраняем…», поле недоступно | Повторное нажатие ничего не делает |
| Готово | Ряд: «Сохранено» на 4 s, затем пусто | Фокус остаётся на «Сохранить»; уведомления нет |
| Очищено | Как «Пусто»; ряд: «Сохранено» на 4 s | Стёртый и сохранённый текст — пустая инструкция: агенты ничего не получают |
| Сервер отказал | Ошибка формы с причиной над рядом сохранения; введённое остаётся | Фокус на блок ошибки; повтор — та же кнопка |
| Уход с изменениями | `alert-dialog` «Уйти без сохранения?», как у редактора записи | Ссылка, «Назад» и закрытие вкладки при изменениях спрашивают; фокус по умолчанию — «Остаться» |

Смена состояния ряда — растворение 150 ms; ряд не меняет высоту.

## Content Rules

- Текст сотрудника не меняется: пробелы и переносы строк сохраняются как введены.
- Счётчик — «Осталось {N} знаков» со словом по числу ([foundations → Слова при числах](../foundations.md#слова-при-числах)); за пределом — «Больше предела на {N} знаков».
- Предел задаёт PRD фичи; тексты — agent-guidance UXRD, MC-6 – MC-9.

## Accessibility

| Аспект | Правило |
|---|---|
| Структура | `section` с заголовком `h2`; поле — `textarea` с подписью-заголовком, пояснение — описание поля |
| Счётчик | Описание поля; объявляется только при переходе через предел, в обе стороны |
| Ошибка | Ошибка поля — `aria-invalid` и описание; ошибка формы — `alert` с фокусом |
| Состояние ряда | «Сохранено» объявляется `polite` |
| Клавиатура | Enter — перенос строки; Ctrl+S и Cmd+S сохраняют, когда фокус в поле |
