# История записи

## Purpose

Все версии одной записи памяти, новые сверху: что было в каждой, кто и когда её сделал. Отсюда человек возвращает хорошую версию, если запуск агента испортил запись или удалил её. Возврат не стирает историю: он добавляет новую версию с прежним текстом, поэтому ошибку возврата тоже можно отменить.

## Anatomy

```
Изменена · агент · 20 нояб., 14:32                 Текущая    1 строка версии · 2 метка
Логи оплаты лежат в индексе billing-api-*,                    3 текст
ошибки шлюза — с кодом 504.
──────────────────────────────────────────────────────────
Создана · агент · 12 нояб., 09:10                             1
Логи оплаты — в billing-api.                                  3
                                        [ Вернуть эту версию ] 4 действие
```

1. **Строка версии** — Caption: вид изменения `--foreground`, через « · » — кто и когда `--muted-foreground`. Кто: «агент», имя человека или «вы».
2. **Метка** — «Текущая» у верхней версии: [метка состояния](./state-badge.md), вариант «Источник».
3. **Текст** — UI 14 / 20, `--foreground`, с переносами строк как сохранено; скрытый секрет виден маской. У версии «Удалена» текста нет.
4. **Действие** — «Вернуть эту версию», кнопка `outline` `sm`, по правому краю под текстом; есть у каждой версии с текстом, кроме текущей.

Версии делит линия 1 px `--border`, промежуток 12 px сверху и снизу.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| С возвратом | Смотрит тот, кто может удалять запись на её экране | Как в Anatomy |
| Только чтение | Права возвращать нет | Кнопок «Вернуть эту версию» нет |

Виды изменения: «Создана», «Изменена», «Удалена», «Возвращена».

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Loading | Три скелетона версии | Пульсация по foundations; для скринридера — статус с текстом экрана |
| Error | Текст ошибки и «Повторить» (`outline`, `sm`) | «Повторить» возвращает Loading |
| Default | Версии, новые сверху | Список прокручивается внутри своего контейнера |
| Запись удалена агентом | Верхняя версия — «Удалена» без текста, с меткой «Текущая» | «Вернуть эту версию» есть у всех версий ниже |
| Возврат идёт | Нажатая кнопка показывает вращающийся индикатор и недоступна, остальные кнопки тоже недоступны | — |
| Возвращено | Сверху появляется версия «Возвращена» с меткой «Текущая»; метка уходит с прежней верхней версии | Появление — раскрытие за 150 ms, под reduced motion — мгновенно; фокус — на строку новой версии |
| Конфликт | Над списком — блок предупреждения [формы настроек](./settings-form.md) с текстом экрана; список перечитан, новая версия сверху | Возврат не выполнен; человек решает заново по новой истории |
| Ошибка возврата | Под версией — текст Caption `--destructive`; кнопки снова доступны | — |

## Content Rules

- Текст версии показывается как его сохранила платформа и не переводится.
- Время — «День и время» по [foundations → Language & Formats](../foundations.md#language--formats).
- В истории записи агента нет имени сотрудника, в чьём запуске агент её изменил: изменения агента подписаны «агент».

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | Нумерованный список; версия — элемент списка, строка версии — её заголовок |
| Кнопка | Доступное имя «Вернуть версию от {дата и время}» |
| Объявления | Возврат и конфликт объявляются `status` текстом экрана; Loading и Error — `status` |
| Фокус | После возврата и после конфликта фокус на строке верхней версии |
