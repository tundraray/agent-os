# Вызов инструмента

## Purpose

Один вызов инструмента в ленте беседы или агента: какой инструмент, с какими аргументами, когда и чем кончился. Компонент расширяет блок инструмента assistant-ui (`ToolFallback`, chat-shell UXRD, TH-01) и его группы: добавляет исходы вызова и время. Текст ошибки от инструмента или сервера не показывается — только исход (chat-shell UXRD, D-15).

## Anatomy

```
▾ ✓ Найти инциденты                              готово   14:22   1 · 2 · 3 · 5 · 6
    find_incidents · incidents                                    4
  Аргументы                                                       7
  Сервис      payments
  state       open
  urgent      да
  filters
  {"from":"2026-11-14T00:00","tags":["prod"]}
  ▸ Показать как JSON                                             8
  ┌ Результат ───────────────────────────────────────────────┐    9
  │ [ { "id": "INC-412", … } ]                               │
  └──────────────────────────────────────────────────────────┘
```

1. **Шеврон** — `ChevronRight`, поворот на 90° в раскрытом блоке.
2. **Иконка исхода** — 14 px, цвет основы исхода (States).
3. **Инструмент** — UI, `--foreground`: подпись встроенного инструмента (agent-platform UXRD, MC-23; code-execution UXRD, MC-1); у MCP-инструмента — название, которое дал сервер (`title` инструмента), а без него — имя инструмента как есть.
4. **Техническое имя и сервер** — Caption, `--muted-foreground`. Если у MCP-инструмента есть название, под ним стоит вторая строка заголовка «{имя инструмента} · {сервер}». Без названия в строке заголовка за именем инструмента стоит только имя сервера. У встроенных инструментов этой части нет; у запуска кода на её месте стоит описание запуска, усечённое в конце, полное — в подсказке.
5. **Исход** — Caption цветом основы исхода; текст — agent-platform UXRD, MC-22.
6. **Время** вызова — Caption, `--muted-foreground`, табличные цифры.
7. **Аргументы** — подпись «Аргументы» (Caption) и строки «подпись — значение» (раздел «Строки аргументов» ниже).
8. **Сырой вид** — кнопка раскрытия «Показать как JSON» под строками. Раскрытая, она называется «Скрыть JSON» и открывает под собой блок Mono 13 / 20 на `--muted`, радиус md, с точным JSON аргументов, которые ушли в инструмент. По умолчанию свёрнута.
9. **Результат** — подпись Caption и блок Mono 13 / 20 на `--muted`, радиус md. Если результат — плоский объект, он показан строками «подпись — значение», как аргументы, без сырого вида. Блок не выше 320 px, дальше прокрутка внутри блока. У исходов без результата блока нет. У запуска кода под итогом стоит **вывод скрипта**: подпись Caption (code-execution UXRD, MC-4) и такой же блок, строки вывода как напечатал скрипт. Если скрипт ничего не печатал, вывода нет.

Строка заголовка — 32 px, компактная плотность; вторая строка с техническим именем добавляет 16 px. Блок — радиус lg, рамка 1 px `--border`, без подложки ([foundations → Shape & Elevation](../foundations.md#shape--elevation)).

### Строки аргументов

Аргументы показаны списком строк «подпись — значение» вместо блока JSON. Тот же формат использует карточка решения ([decision-card](./decision-card.md)).

- **Строки**: одна на аргумент верхнего уровня, в том порядке, в котором аргументы ушли в инструмент.
- **Подпись**: `title` аргумента из схемы входа инструмента, а без него — ключ аргумента как есть. Caption, `--muted-foreground`. Подписи стоят колонкой слева по ширине самой длинной, не шире трети блока; длинная подпись переносится.
- **Значение**: справа от подписи, `--foreground`; Data в блоке вызова, UI в карточке решения.

| Значение | Как показано |
|---|---|
| Строка | Обычным текстом; длинный текст переносится, без усечения |
| Число | Текстом, как пришло |
| Логическое | «да» или «нет» |
| `null` или нет значения | «—» |
| Вложенный объект или массив | Компактный JSON, Mono 13 / 20, отдельной строкой под подписью, с переносом |
| Скрипт запуска кода | **Блок кода** отдельной строкой под подписью: Mono на `--muted`, радиус md, строки и отступы как в скрипте. Слева номера строк, `--muted-foreground`, табличные цифры; они не попадают в выделение. Длинная строка переносится, продолжение идёт без номера. В блоке вызова — Mono 13 / 20, не выше 320 px, дальше прокрутка внутри; в карточке решения — Mono 14 / 22, целиком |

Вызов без аргументов строк не показывает; сырой вид раскрывает `{}`.

У запуска кода строки идут в постоянном порядке: описание, класс запуска, скрипт. Подписи и значение класса словами — code-execution UXRD, MC-2 и MC-3.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| MCP-инструмент | Инструмент внешней системы | Есть имя сервера; при названии от сервера — вторая строка заголовка |
| Встроенный | Инструменты самой платформы | Подпись на русском, без сервера. Удачный запуск агента или workflow показывает карточка хода, а этот блок — только запуск, в котором платформа отказала (agent-platform UXRD, KD-4) |
| Запуск кода | Встроенный `run_code` | Описание запуска во второй строке заголовка, скрипт блоком кода, вывод скрипта под итогом |

Подряд идущие вызовы собираются в группу assistant-ui без изменений.

## States

| Состояние (исход) | Иконка, цвет | Как ведёт себя |
|---|---|---|
| Выполняется | `LoaderCircle`, вращение, `--info` | Блок свёрнут; аргументы доступны раскрытием |
| Готово | `CircleCheck`, `--success` | Результат — в раскрытом блоке |
| Пустой результат | `Circle`, `--muted-foreground` | Блок результата показывает «[]» или «{}» как вернул инструмент. У запуска кода, который ничего не вернул, на месте итога стоит «—», под ним вывод скрипта (code-execution UXRD, KD-5) |
| Ошибка инструмента | `CircleX`, `--destructive` | Блока результата нет. У запуска кода — любая ошибка запуска, включая превышенный предел; вывода скрипта тоже нет |
| Нет связи с сервером | `Unplug`, `--destructive` | Блока результата нет |
| Отказано | `Ban`, `--destructive` | Платформа не исполнила вызов: нет права, инструмент вне набора агента или превышен предел платформы. Под заголовком — строка причины (Caption, `--muted-foreground`, agent-platform UXRD, MC-22), видна и в свёрнутом блоке; блока результата нет |
| Ждёт подтверждения | `Hand`, `--approval` | Сразу под блоком — карточка решения ([decision-card](./decision-card.md)) |
| Отклонено | `CircleMinus`, `--muted-foreground` | Сотрудник отклонил действие; блока результата нет |
| Прервано | `CircleStop`, `--muted-foreground` | Вызов отменён прерыванием; блока результата нет |
| Исход неизвестен | `CircleQuestionMark`, `--warning` | Изменяющее действие или изменяющий запуск кода был начат до рестарта сервера; блока результата нет |
| Раскрыт | Шеврон повёрнут | Клик, Enter или Space по заголовку сворачивает и раскрывает; состояние не сохраняется после перезагрузки. Строки аргументов видны только в раскрытом блоке |
| Сырой вид раскрыт | Шеврон кнопки раскрытия повёрнут, подпись «Скрыть JSON»; под ней блок JSON, над результатом | Клик, Enter или Space по кнопке раскрывает и сворачивает; открывается за 150 ms, под reduced motion — мгновенно |
| Hover / Focus | Заголовок: фон `--accent` / кольцо `--ring` | — |

Смена исхода — растворение 150 ms; высота свёрнутого блока не меняется. Под reduced motion — статичная `CircleDashed`.

## Content Rules

- Техническое имя инструмента, ключи и значения аргументов не переводятся. Название и техническое имя усекаются в конце; полное — в подсказке.
- Значения аргументов и результат показываются как пришли, с переносом длинных строк; в результате больше 320 px высоты — прокрутка внутри блока.
- Время — «ЧЧ:ММ» за сегодня, иначе «12 нояб., ЧЧ:ММ».

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | Заголовок — `button` с `aria-expanded`; блоки аргументов и результата — `region` с именами «Аргументы» и «Результат» |
| Строки | Список описаний: подпись — термин (`dt`), значение — определение (`dd`); скринридер читает пары по порядку |
| Блок кода, вывод скрипта | `region` с именами «Скрипт» и «Вывод скрипта»; номера строк скрыты от скринридера. Фокус для прокрутки — только когда блок прокручивается |
| Сырой вид | `button` с `aria-expanded`; доступное имя — его видимая подпись, «Показать как JSON» или «Скрыть JSON»; после нажатия фокус остаётся на кнопке |
| Доступное имя | «{инструмент}: {исход}, {время}»; инструмент — название или, без него, имя инструмента. У запуска кода — «Выполнить код: {описание}, {исход}, {время}» |
| Клавиатура | Tab на заголовок и на кнопку сырого вида; Enter и Space раскрывают; блоки с прокруткой фокусируются для прокрутки стрелками |
| Объявления | Смена исхода не объявляется; запрос на подтверждение объявляет экран |
| Цвет | Исход передают форма иконки и текст |
