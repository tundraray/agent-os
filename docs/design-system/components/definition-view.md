# Определение записи

## Purpose

Показывает определение агента или глубокого агента целиком и только для чтения, в том порядке, в каком его читает человек: что делает, чем работает, что умеет, а у глубокого агента — из кого состоит команда. Стоит в карточке подтверждения, которой сотрудник одобряет создание или правку записи, в панели «Схема» рядом с беседой, на странице записи в библиотеке и в панели администратора. У глубокого агента представление говорит, что он получает только задание, а команду показывает набором, а не очередью.

## Anatomy

**Агент:**

```
Описание         Разбирает падения оплат по логам и тикетам      1 строка «подпись — значение»
Инструкция       Ты разбираешь падения оплат. Сначала найди…     2 длинный текст
                 ▸ Показать целиком                              3 раскрытие
Модель           Haiku
Максимум шагов   40
Системы          Sentry · Инциденты · Jira ⊖ у вас недоступна    4 системы
Способности      список задач                                    13 способности
Может запускать  Сбор логов · моя  только вы                     5 список записей
```

**Глубокий агент:**

```
Описание         Отвечает по внутренней документации
Глубокий агент получает только задание, которое вы подтверждаете… 6 задание
Инструкция       Ты отвечаешь на глубокий вопрос. Сначала…       2 · 3
Системы          Confluence                                      4
Способности      список задач · поручение по списку              13 способности
Сабагенты · 3    кого и когда звать, решает агент                7 команда
 Ответ — пишет ответ по всем отчётам               пишет ответ   8 сабагент
 План — делит вопрос на направления
 Сбор — собирает данные по направлению
 ▸ Подробнее                                                     9 подробности
Кто пишет ответ  Ответ                                           10 ответ
Агент            Haiku · до 30 шагов                             11 модель агента
```

**Схема** (панель рядом с беседой, подписи над значениями):

```
Отвечает по внутренней документации                               1 описание
Системы  Confluence                                               4
Сабагенты · 3                                                     7
 Ответ — пишет ответ по всем отчётам                пишет ответ   8
   без систем                                                     14 системы сабагента
 Сбор — собирает данные по направлению
   Confluence
```

**Пояснение получателю** (запись коллеги, вариант «На странице»):

```
ⓘ Автор — Борис Ким. Агент открыт вашей роли SRE.                12 пояснение
  Работает с вашими правами и подключёнными аккаунтами. …
```

1. **Строка** — подпись Caption, `--muted-foreground`, значение UI, `--foreground`. В области не уже 560 px подпись стоит слева в колонке 140 px, в более узкой — над значением.
2. **Длинный текст** — инструкция агента или глубокого агента: Body, `--foreground`, абзацы и переносы как у автора. Не Mono: это текст для чтения.
3. **Раскрытие** — `ghost` `sm` «Показать целиком» / «Свернуть» с шевроном.
4. **Системы** — отображаемые имена через « · »; у системы, на которую у смотрящего нет права, — [метка состояния](./state-badge.md) «Выключено» с текстом «у вас недоступна». Нет систем — «без систем»; у агента компании со всеми системами — «все системы».
5. **Записи, которые агент может запускать** — [подписи записей](./record-label.md) через запятую; строки нет, если список пуст.
6. **Задание** — одна фраза Caption, `--muted-foreground`, всегда перед командой.
7. **Команда** — подпись с числом сабагентов и уточнение Caption, `--muted-foreground`.
8. **Сабагент** — одна строка: имя UI 500, тире и строка «за что отвечает» UI `--muted-foreground`, усечение в конце; у финального сабагента — метка «пишет ответ» (вариант «Источник»). Сабагенты идут по алфавиту, без номеров и стрелок.
9. **Подробности** — раскрытие «Подробнее»: под каждой строкой сабагента его модель, системы, способности, «Сколько раз можно звать» и раскрытие инструкции.
10. **Ответ** — имя финального сабагента или «Сам агент».
11. **Модель агента** — модель и максимум шагов самого глубокого агента.
12. **Пояснение получателю** — блок `--info-subtle`, рамка `--info-border`, иконка `Info` `--info`, текст Caption `--foreground` четырьмя короткими фразами. Только на странице записи коллеги, над строками.
13. **Способности** — включённые способности записи словами через « · »: «список задач», «поручение по списку»; ни одной — «нет». Поручение по списку бывает только у глубокого агента.
14. **Системы сабагента** — только в варианте «Схема»: под строкой сабагента его системы через « · » Caption `--muted-foreground`, «без систем», если их нет.

Промежуток между строками 8 px, между строками сабагентов 4 px.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Агент | Запись вида «агент» | Части 1–5 и 13 |
| Глубокий агент | Запись вида «глубокий агент» | Части 1–4, 6–11, 13 |
| В карточке | Карточка подтверждения создания записи | Длинные тексты свёрнуты до 6 строк; подробности сабагентов свёрнуты |
| На странице | Карточка записи в библиотеке и в панели администратора | Инструкция раскрыта; подробности сабагентов раскрыты, их инструкции свёрнуты; у записи коллеги — часть 12 |
| Правка | Карточка подтверждения правки записи | Как «В карточке». У изменённой строки или сабагента — метка «изменено», у добавленных — «новый» (вариант «Источник»); убранное — строкой «Убрано: …» под своей частью |
| Схема | Панель «Схема» рядом с беседой | Описание без подписи, части 4, 7, 8 и 14; у агента — описание и 4. Строка сабагента не усекается, а переносится; подписи — над значениями. Инструкций, моделей, подробностей и части 6 нет |

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Свёрнуто | 6 строк текста, обрезка по строке без градиента; под ним «Показать целиком» | Кнопки нет, если текст короче 6 строк |
| Раскрыто | Текст целиком; «Свернуть» под ним | Раскрытие за 150 ms, под reduced motion — мгновенно; фокус остаётся на кнопке |
| Система недоступна | Метка «у вас недоступна» после имени системы | Только сведения: при запуске система выпадет (custom-agents PRD, FR-14) |
| Пустое значение | «—» | Описание, инструкция и строка сабагента «когда звать» пустыми не бывают |

## Content Rules

- Тексты автора не переводятся, не усекаются в середине и не меняют разметку; строка сабагента «когда звать» усекается только в конце.
- Числа — табличные цифры: «до 3 раз», «40».
- Подписи и фразы — custom-agents UXRD, MC-6 и MC-7; подписи глубокого агента и способности — deep-agents UXRD, MC-27; пометки правки, подписи схемы и фраза о задании — deep-agents UXRD, MC-24–MC-26.

## Accessibility

| Аспект | Правило |
|---|---|
| Структура | Список описаний (`dl`): подпись — `dt`, значение — `dd` |
| Команда | Список (`ul`) с доступным именем «Сабагенты, кого и когда звать, решает агент»; сабагент — `li`, имя читается первым |
| Раскрытие | `button` с `aria-expanded` и `aria-controls` на текст или подробности |
| Пояснение | Обычный текст (`note`), не объявляется |
| Метки | Слово, не цвет; иконка декоративная |
| Клавиатура | Tab только по кнопкам раскрытия и ссылкам подписей записей |
