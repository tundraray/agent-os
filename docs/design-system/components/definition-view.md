# Определение записи

## Purpose

Показывает определение агента или workflow целиком и только для чтения, в том порядке, в каком его читает человек: что делает, по каким правилам, чем работает. Стоит в карточке черновика, которую сотрудник подтверждает в беседе, на странице чужой записи и в панели администратора. У workflow представление объясняет устройство по пути: координатор сам решает порядок, поэтому команда показана набором, а не очередью.

## Anatomy

**Агент:**

```
Описание         Разбирает падения оплат по логам и тикетам      1 строка «подпись — значение»
Промпт           Ты разбираешь падения оплат. Сначала найди…     2 длинный текст
                 …
                 ▸ Показать целиком                              3 раскрытие
Модель           Haiku
Предел ходов     40
Серверы          sentry · incidents · jira ⊖ нет доступа у вас   4 список серверов
Может запускать  Сбор логов · моя  личная                        5 список записей
```

**Workflow:**

```
Описание         Разбирает инцидент и пишет сводку
Координатор читает правила и сам решает, кого из команды          6 пояснение
вызвать, в каком порядке и сколько раз.
Правила          Пусть «Сбор логов» и «Сбор тикетов» работают…    2 · 3
Команда · 3      порядок вызовов решает координатор               7 команда
 ┌ Ответ                                итог · до 1 раза ┐        8 исполнитель
 │ Пишет сводку из собранного                            │
 │ Sonnet · без серверов                    ▸ Промпт     │
 └───────────────────────────────────────────────────────┘
 ┌ Сбор логов                                до 3 раз   ┐
 │ …                                                    │
Итог даёт        Ответ                                            9 итог
Координатор      Sonnet · до 30 ходов                             10 координатор
```

1. **Строка** — подпись Caption, `--muted-foreground`, значение UI, `--foreground`. В области не уже 560 px подпись стоит слева в колонке 140 px, в более узкой — над значением.
2. **Длинный текст** — промпт агента или правила координатора: Body, `--foreground`, абзацы и переносы как у автора. Не Mono: это текст для чтения.
3. **Раскрытие** — `ghost` `sm` «Показать целиком» / «Свернуть» с шевроном.
4. **Серверы** — имена Mono 13 / 20 через « · »; у сервера, на который у смотрящего нет права, — [метка состояния](./state-badge.md) «Выключено» с текстом «нет доступа у вас». Нет серверов — «без серверов»; у системной записи со всеми серверами — «все серверы развёртывания».
5. **Записи, которые агент может запускать** — [подписи записей](./record-label.md) через запятую; строки нет, если список пуст.
6. **Пояснение** — одна фраза Caption, `--muted-foreground`, всегда перед правилами.
7. **Команда** — подпись с числом исполнителей и уточнение «порядок вызовов решает координатор» Caption, `--muted-foreground`.
8. **Исполнитель** — блок с рамкой 1 px `--border`, радиус md, отступ 8 px: имя UI 500; метка «итог» (вариант «Источник») у исполнителя последнего шага; «до {N} раз» Caption табличными цифрами; описание; модель и серверы Caption; раскрытие «Промпт». Исполнители идут по алфавиту, без номеров, стрелок и линий между ними.
9. **Итог** — имя исполнителя последнего шага или «итог пишет координатор».
10. **Координатор** — модель и предел ходов координатора.

Промежуток между строками 8 px, между блоками исполнителей 8 px.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Агент | Запись вида «агент» | Части 1–5 |
| Workflow | Запись вида «workflow» | Части 1–3 и 6–10; серверы показаны у каждого исполнителя |
| В карточке | Карточка черновика в беседе | Длинные тексты свёрнуты до 6 строк; промпты исполнителей свёрнуты |
| На странице | Чужая запись, запись в панели | Промпт агента и правила координатора раскрыты; промпты исполнителей свёрнуты |
| Правка | Черновик правки уже сохранённой записи | У изменённой строки или исполнителя — метка «изменено» (вариант «Источник»); убранное — строкой «Убрано: …» под своей частью |

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Свёрнуто | 6 строк текста, обрезка по строке без градиента; под ним «Показать целиком» | Кнопки нет, если текст короче 6 строк |
| Раскрыто | Текст целиком; кнопка «Свернуть» под ним | Раскрытие за 150 ms, под reduced motion — мгновенно; фокус остаётся на кнопке |
| Сервер без доступа | Метка «нет доступа у вас» после имени сервера | Только сведения: при запуске сервер выпадет (custom-agents PRD, FR-14) |
| Пустое значение | «—» | Описание и промпт пустыми не бывают |

## Content Rules

- Тексты автора не переводятся, не усекаются в середине и не меняют разметку.
- Числа — табличные цифры: «до 3 раз», «40».
- Подписи строк — custom-agents UXRD, MC-12 и MC-15.

## Accessibility

| Аспект | Правило |
|---|---|
| Структура | Список описаний (`dl`): подпись — `dt`, значение — `dd` |
| Команда | Список (`ul`) с доступным именем «Команда, порядок вызовов решает координатор»; исполнитель — `li`, его имя читается первым |
| Раскрытие | `button` с `aria-expanded` и `aria-controls` на текст |
| Метки | Слово, не цвет; иконка декоративная |
| Клавиатура | Tab только по кнопкам раскрытия и ссылкам подписей записей |
