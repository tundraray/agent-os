# Поле «Скиллы»

## Purpose

Поле «Скиллы» — вариант поля «Может запускать» [редактора записи](./record-editor.md) (часть 8) с видом записи «скилл». Автор подключает к агенту скиллы, которые видит в библиотеке. Строка «Скиллы» в просмотре — вариант строки «Может запускать» [определения записи](./definition-view.md) (часть 5): кто открывает страницу агента, видит, по каким процедурам агент работает. ## Поле

Поле устроено так же, как «Может запускать» сегодня: под подписью всегда стоит поле поиска, под ним — выбранные скиллы чипами [подписи записи](./record-label.md) с кнопкой «Убрать». Поиск предлагает кандидатов по имени; выбор добавляет скилл в конец, повторный выбор снимает его. Поле поиска названо подписью поля, кнопка чипа — «Убрать: {имя}». На узкой ширине чипы переносятся строками, список поиска — во всю ширину поля.

| Что | Как у «Скиллы» |
|---|---|
| Место | Основная колонка, сразу после «Системы», а не под «Дополнительно» (agent-guidance UXRD, KD-7) |
| Кандидаты | Скиллы, которые автор видит в библиотеке |
| Подсказка | Под подписью, Caption `--muted-foreground`: что агент делает со скиллом |
| Недоступный скилл | Чип «скилл недоступен»: автор скилла сузил аудиторию. Убрать можно, вернуть нельзя |
| Предел | Проверяется при сохранении: больше предела — ошибка поля, запрос не уходит. Предел задаёт PRD фичи |
| Окно глубокого агента | У глубокого агента формы нет, поэтому то же поле стоит в диалоге «Скиллы «{имя}»» на его карточке, с «Отмена» и «Сохранить» в подвале |

Поле сохраняется вместе со своей формой: редактор создаёт новую версию агента, окно — новую версию глубокого агента. Скилл, удалённый автором, пропадает из поля и из просмотра без пометки.

## Строка «Скиллы» в просмотре

Строка стоит после «Системы» на странице агента и на карточке глубокого агента; без скиллов строки нет.

- **Видимый скилл** — подпись записи ссылкой на страницу скилла.
- **Скрытый скилл** — скилл, текст которого смотрящему не открыт: имя без ссылки, тире, описание `--muted-foreground` и [метка состояния](./state-badge.md) «текст вам не виден». Метка читается после описания, словом, не цветом.

Тексты — agent-guidance UXRD, MC-14 – MC-16.
