# Скиллы агента

## Purpose

Список скиллов, подключённых к агенту или глубокому агенту: автор выбирает их из тех, что видит сам, а каждый, кто открывает страницу агента, видит, по каким процедурам агент работает. Скилл приходит вместе с агентом, поэтому смотрящий может увидеть скилл, текста которого ему не открыли: такой скилл показан именем и описанием, без ссылки. Компонент — поле выбора в редакторе и строка «Скиллы» в просмотре определения.

## Anatomy

**Поле выбора** (редактор агента, окно скиллов глубокого агента):

```
Скиллы                                                              1 подпись
Агент читает скилл, когда задача подходит под его описание.         2 подсказка
┌────────────────────────────────────────────────────────────┐
│ Постмортем  ⊖ у вас недоступен — останется у агента     ✕  │      3 потерянный скилл
│ Разбор инцидента · Борис Ким  SRE                        ✕  │      4 скилл
│ Когда агент разбирает инцидент по логам и алертам          │
└────────────────────────────────────────────────────────────┘
[ + Добавить скилл ]                                                5 добавить
  ┌──────────────────────────────────────────────┐
  │ [ Найти скилл…                             ] │                  6 поиск
  │ Постмортем · моя                             │
  │ Когда нужно оформить разбор после инцидента  │
  └──────────────────────────────────────────────┘
```

**Строка в просмотре** (страница агента, карточка глубокого агента):

```
Скиллы   Разбор инцидента — Когда агент разбирает инцидент…          7 видимый скилл
         Постмортем — Когда нужно оформить разбор   текст вам не виден   8 скрытый скилл
```

1. **Подпись** — как у поля формы настроек; у поля — `fieldset` со списком.
2. **Подсказка** — Caption, `--muted-foreground`: что агент делает со скиллом.
3. **Потерянный скилл** — скилл, который подключён, но автору больше не виден: автор скилла сузил аудиторию. Стоит первым, имя UI 500 без ссылки и [метка состояния](./state-badge.md) «у вас недоступен — останется у агента». Его можно убрать, но вернуть нельзя.
4. **Скилл** — [подпись записи](./record-label.md), вариант «Строка», ссылкой на страницу скилла, под ней описание UI `--muted-foreground` в две строки с усечением в конце; справа иконочная кнопка «Убрать». Порядок — порядок добавления.
5. **Добавить** — `outline` `sm` под списком. Открывает поповер с поиском.
6. **Поиск** — поле и список совпадений: скиллы, которые автор видит в библиотеке и которые ещё не подключены; строка — подпись записи и описание Caption. Выбор добавляет скилл в конец списка и оставляет поповер открытым для следующего.
7. **Видимый скилл** — имя ссылкой на страницу скилла, тире и описание UI `--muted-foreground`; описание переносится, не усекается.
8. **Скрытый скилл** — имя UI `--foreground` без ссылки, тире, описание и метка состояния «текст вам не виден».

Промежуток между скиллами в поле 8 px, в строке просмотра 4 px.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Поле | Редактор агента; окно скиллов глубокого агента | Части 1–6 |
| Просмотр | Определение записи в вариантах «На странице», «В карточке» и «Правка»; карточка глубокого агента | Части 7–8; строки нет, если скиллов нет. В варианте «Правка» добавленный скилл несёт метку «новый», убранный — строкой «Убрано: …», как сабагенты |
| Окно глубокого агента | Владелец меняет скиллы глубокого агента на его карточке | Поле в диалоге по правилам формы диалога: заголовок «Скиллы «{имя}»», в подвале «Отмена» и «Сохранить» |

На ширине < 480 px строка просмотра ставит описание под именем, а поповер поиска встаёт на всю ширину экрана снизу.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Пусто | Вместо списка — Caption «Скиллов нет» `--muted-foreground` | «Добавить скилл» доступна |
| Поиск: загрузка | Две строки-скелетона в поповере | — |
| Поиск: нет совпадений | «Скиллов не нашли» | — |
| Поиск: в библиотеке нет скиллов | «В библиотеке пока нет скиллов» и ссылка «Создать скилл» | Ссылка открывает новый скилл в новой вкладке: несохранённый агент не теряется |
| Поиск: ошибка | Текст ошибки и «Повторить» в поповере | — |
| Предел | «Добавить скилл» недоступна (`aria-disabled`), причина — в подсказке кнопки | Сколько скиллов можно подключить, задаёт PRD фичи |
| Убран | Строка уходит за 150 ms, под reduced motion — мгновенно | Форма переходит в «Изменено»; у потерянного скилла вернуть нельзя |
| Hover | Фон строки поиска `--accent` | — |
| Focus | Кольцо `--ring` у ссылок, кнопок «Убрать» и «Добавить скилл» | — |

Скилл, удалённый автором, пропадает из поля и из просмотра без пометки. Сохранение поля — как у формы, в которой оно стоит: редактор записи создаёт новую версию агента, окно глубокого агента — новую версию глубокого агента.

## Content Rules

- Имена и описания скиллов — как их написал автор, без перевода.
- Метки — словами: «у вас недоступен — останется у агента», «текст вам не виден».
- Тексты — agent-guidance UXRD, MC-14 – MC-16.

## Accessibility

| Аспект | Правило |
|---|---|
| Поле | `fieldset` с легендой «Скиллы», подсказка — описание; список — `ul` |
| Убрать | Кнопка с именем «Убрать: {имя}»; после нажатия фокус — на следующую кнопку «Убрать», без неё — на «Добавить скилл» |
| Поиск | `combobox` со списком вариантов; выбор объявляется «{имя} добавлен» (`polite`); Esc закрывает поповер, фокус — на «Добавить скилл» |
| Метки | Описание строки (`aria-describedby`), слово, не цвет |
| Просмотр | Строка определения: `dt` «Скиллы», в `dd` — список `ul`; у скрытого скилла метка читается после описания |
