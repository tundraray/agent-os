# Скрипт агента

## Purpose

Один сохранённый скрипт глубокого агента: код, который агент или его сабагент вызывает как свой инструмент. Компонент показывает скрипт для чтения на карточке, становится формой, когда автор его правит, и показывает изменение скрипта в результате обучения.

## Anatomy

**На карточке:**

```
count_errors_by_service                          читает        1 имя · 2 класс
Считает ошибки оплаты по сервисам за период                    3 описание
Вызывает: сабагент «Сбор» · Вход: период и список сервисов     4 владелец · 5 вход
▸ Показать код                         [ Изменить ] [ Удалить ] 6 код · 7 действия
```

**Правка:**

```
Имя                [ count_errors_by_service            ]      8 поля
Описание для агента[ Считает ошибки оплаты по сервисам… ]
Входные данные     [ Период и список сервисов           ]
Кто вызывает       [ Сабагент «Сбор»                  ▾ ]
Что делает         (•) Только читает  ( ) Меняет данные
Код                [                                    ]      9 поле кода
⊗ Не удалось сохранить: …                                      10 ошибка формы
[ Сохранить скрипт ]  [ Отмена ]                               11 действия формы
```

1. **Имя** — Mono, `--foreground`: под этим именем агент видит инструмент. Усекается посередине, полное — в подсказке.
2. **Класс** — [метка состояния](./state-badge.md), вариант «Источник»: «читает» или «меняет данные».
3. **Описание** — UI, `--foreground`: когда звать скрипт и что он возвращает.
4. **Владелец** — Caption, `--muted-foreground`: «Вызывает: сам агент» или «Вызывает: сабагент «{имя}»».
5. **Вход** — в той же строке через « · »; переносится.
6. **Код** — раскрытие «Показать код» / «Скрыть код» и блок кода по правилам блока кода [вызова инструмента](./tool-call.md#строки-аргументов). По умолчанию свёрнут.
7. **Действия** — `outline` `sm` «Изменить» и `ghost` `sm` «Удалить»; только у того, кто правит агента.
8. **Поля** — по [форме настроек](./settings-form.md): «Имя» (Mono), «Описание для агента» и «Входные данные» (многострочные), «Кто вызывает» (shadcn `select`: сам агент и сабагенты по алфавиту), «Что делает» (радиогруппа).
9. **Поле кода** — обычное многострочное поле Mono 14 / 22, без проверки орфографии, высота по содержимому от 12 строк.
10. **Ошибка формы** — как в форме настроек.
11. **Действия формы** — «Сохранить скрипт» (`default`) и «Отмена» (`outline`).

Скрипты в списке разделяет 1 px `--border`; промежуток между частями одного скрипта 4 px.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| На карточке | Секция скриптов на карточке глубокого агента | Части 1–6; часть 7 — только у того, кто правит агента |
| Правка | Автор нажал «Изменить» или «Добавить скрипт» | Части 8–11 на месте блока. У нового скрипта поля пусты, «Что делает» — «Только читает», «Кто вызывает» — «сам агент» |
| Изменение | Скрипт в результате обучения | Части 1–5, рядом с классом — метка «новый», «изменено» или «убран». Код двумя колонками «Было» и «Стало» блоками кода; у нового — только «Стало», у убранного — только «Было». Действий нет |

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Код свёрнут / раскрыт | Шеврон и подпись раскрытия; раскрытый — блок кода | Фокус остаётся на кнопке |
| Правка открыта | Форма на месте блока | Фокус — в поле «Имя»; одновременно открыта одна форма |
| Ошибка поля | Как в форме настроек | Фокус — на первое поле с ошибкой |
| Сохраняем | «Сохранить скрипт» с `LoaderCircle`, поля недоступны | Повторное нажатие ничего не делает |
| Сохранено | Блок «На карточке» с новыми значениями; под ним «Сохранено» на 4 s | Фокус — на «Изменить» этого скрипта |
| Сервер отказал | Ошибка формы; введённое остаётся | Фокус — на блок ошибки. Если агента изменили, пока правили, ошибка просит перечитать карточку и даёт кнопку «Перечитать» |
| Удаляем | «Удалить» с `LoaderCircle`, недоступна | Ошибка — Caption `--destructive` под блоком |

## Content Rules

- Имя и код не переводятся и в форме не усекаются.
- Описание и вход пишет автор или тренер; они показываются как есть.
- Тексты — self-learning UXRD, MC-13 и MC-14.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | Скрипт — `article`, доступное имя — имя скрипта |
| Раскрытие кода | `button` с `aria-expanded` |
| Действия | Доступные имена «Изменить: {имя}», «Удалить: {имя}» |
| Форма | Подписи связаны с полями; «Что делает» — `radiogroup`; в поле кода Tab уходит из поля |
| Объявления | «Сохранено» — `polite`; ошибка формы — `alert` |
