# Итог проверки

## Purpose

Показывает итог проверки версии на прошлых случаях: сколько жалоб исправлено и осталось, сколько одобрений сохранилось и сломалось и сколько случаев не оценено. Каждое число стоит рядом со своим основанием — «3 из 4», — а случаи для анализа и контрольные идут разными колонками. Общей отметки «прошло» нет: компонент даёт числа, решение принимает человек.

## Anatomy

```
Проверка на случаях · 19 нояб., 14:31 · 3,10 $ из 5 $        1 шапка
                          Для анализа   Контрольные           2 колонки
Жалобы                                                        3 группа
  ✓ исправлено            3 из 4        1 из 2                4 строка исхода
  ✕ осталось              1 из 4        1 из 2
  ? не оценено            0 из 4        0 из 2
Одобрения
  ✓ сохранилось           2 из 2        нет случаев           5 нет случаев
  ✕ сломалось             0 из 2        нет случаев
  ? не оценено            0 из 2        нет случаев
⚠ Остановлена на пределе 5 $: прошли 5 из 9, не стартовали 3  6 предупреждение
```

1. **Шапка** — Heading: название секции, время итога и расход «{потрачено} из {предел}» табличными цифрами; действия справа задаёт экран.
2. **Колонки** — Caption `--muted-foreground`: «Для анализа» и «Контрольные».
3. **Группа** — «Жалобы» или «Одобрения», UI 500.
4. **Строка исхода** — [метка состояния](./state-badge.md) исхода и в каждой колонке «{n} из {m}» Data табличными цифрами по правому краю; `{m}` — все случаи этого вида в колонке, строки группы в сумме дают `{m}`. Нулевая строка показывается: «сломалось 0 из 2» — тоже ответ. Строка «расхождение» есть, только когда случаи повторяли больше одного раза; строка «не стартовал» — только в состояниях «Частично» и «Сбой».
5. **Нет случаев** — ячейка «нет случаев» `--muted-foreground` вместо «0 из 0». Если вида нет ни в одной колонке, группа — одна строка Caption `--foreground` с иконкой `Info` `--info`: «Одобрений нет — проверки на одобрениях не было» или то же для жалоб.
6. **Предупреждение** — подложка `--warning-subtle`, рамка `--warning-border`, `TriangleAlert` `--warning`, текст `--foreground`; только в состоянии «Частично». В состоянии «Сбой» на том же месте — ошибка: подложка `--destructive-subtle`, рамка `--destructive-border`, `CircleX` `--destructive`, текст `--foreground`.

Компактная плотность; таблица — в ширину колонки страницы. Цвет есть только у иконок меток исходов: числа и фон строк нейтральны, поэтому итог нельзя прочитать по цвету без чисел.

## Variants & Sizes

Вариант один. Количество строк меняется по правилам части 4.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Идёт | Вместо таблицы — [метка состояния](./state-badge.md) «Идёт» и «Пройдено {k} из {N} · {потрачено}» | Числа исходов не показываются, пока проверка не закончилась: частичный итог не выдаётся за итог. Ход не объявляется |
| Готово | Части 1–5 | Смена «Идёт» на таблицу — растворение 150 ms; объявление задаёт экран |
| Частично | Части 1–6: таблица по пройденным случаям, строка «не стартовал» и предупреждение | Не стартовавшие случаи входят в `{m}` своей колонки |
| Сбой | Части 1–5 по пройденным случаям, строка «не стартовал» и ошибка вместо предупреждения | Сломалась сама проверка; сделанное остаётся в итоге, не стартовавшие входят в `{m}`. Действие «Проверить снова» задаёт экран |
| Случаев нет | Компонента нет; причину пишет экран | — |
| Loading | Шапка и шесть строк-скелетонов | Пульсация по foundations |

## Content Rules

- Число — всегда с основанием: «3 из 4», никогда «75 %» и никогда одно «3».
- Слова исходов со строчной: «исправлено», «осталось», «сохранилось», «сломалось», «расхождение», «не оценено», «не стартовал».
- Все тексты компонента — self-correction UXRD, MC-14.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | `table` с подписью «Итог проверки»; группа — заголовок строк (`th` на строке группы), исход — заголовок строки, колонки — заголовки столбцов |
| Ячейка | Читается с заголовками: «исправлено, для анализа: 3 из 4» |
| «Нет случаев» | Текст ячейки, не пустая ячейка |
| Предупреждение, ошибка «Сбой» | `note`; не забирает фокус |
| Идёт | `status` с текстом хода; обновления не объявляются |
| Цвет | Исход передают слово и форма иконки |
