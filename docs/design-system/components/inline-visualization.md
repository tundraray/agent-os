# Блок визуализации

## Purpose

График, схема или раскрашенная таблица, которую агент нарисовал HTML-страницей прямо в своём тексте: в ответе ленты, в отчёте агента, в документе блокнота. Сотрудник видит отрисованную страницу, а код — по запросу. Блок не показывает картинки из документов и файлы с диска.

## Anatomy

```
  …текст ответа до блока.
 ┌───────────────────────────────────────────────────────────────┐
 │                                                               │  1 рамка: страница агента,
 │      ▇▇                                                       │    без рамки и подложки,
 │      ▇▇  ▇▇      ▇▇                                           │    на фоне ответа
 │      ▇▇  ▇▇  ▇▇  ▇▇  ▇▇                                       │
 │      пн  вт  ср  чт  пт       ■ ошибки  ■ предупреждения      │
 └───────────────────────────────────────────────────────────────┘
  Ошибки по дням недели                            ‹/› Показать код   2 строка подписи
 ┌ html ─────────────────────────────────────────── Копировать ─┐
 │ <!doctype html> …                                             │  3 код — только по запросу
 └───────────────────────────────────────────────────────────────┘
  Текст ответа после блока…
```

1. **Рамка** — изолированная страница агента на всю ширину колонки ответа. Обводки, тени и своей подложки у неё нет: фон страницы совпадает с поверхностью, на которой стоит блок, — фоном ленты, карточки отчёта или панели блокнота. Контур рамки на схеме нарисован только для чтения схемы.
2. **Строка подписи** — под рамкой: слева название блока (Caption, `--muted-foreground`, одна строка, усечение в конце, полное — в подсказке), справа кнопка-призрак «Показать код» с иконкой `CodeXml`.
3. **Код** — обычный блок кода ответа с подписью языка и кнопкой «Копировать»; появляется под строкой подписи.

**Высота.** Рамка берёт высоту страницы, но не меньше 80 px и не больше меньшего из 640 px и 70 % высоты окна. Более высокая страница прокручивается внутри рамки. Страница шире колонки прокручивается по горизонтали внутри рамки, а не вместе со страницей Agent OS.

**Что страница получает от темы.** Страница рисует цветами текущей темы и режима и перекрашивается вместе с ними: фон поверхности, `--foreground`, `--muted-foreground`, `--border`, `--muted`, `--primary`, `--chart-1` … `--chart-5` и основы статусов `--info`, `--success`, `--warning`, `--destructive` ([foundations → Color](../foundations.md#color)). Текст страницы — роли UI и Caption ([foundations → Typography](../foundations.md#typography)); семейство — Geist, если рамка получает его без сети, иначе запасной `system-ui`.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Пишется | Вместо рамки — строка статуса 36 px: вращающийся `LoaderCircle` и мерцающая подпись `--muted-foreground` ([foundations → Motion](../foundations.md#motion), «Идёт работа»). Код не виден | Недописанная страница не запускается. Строка остаётся, пока блок не закрыт |
| Готовится | Та же строка статуса | Блок закрыт, страница запускается; строка уходит, когда страница нарисовала первый кадр |
| Отрисована | Рамка в своей высоте, строка подписи | Появляется в один кадр, без растворения. Рост высоты после первого кадра — раскрытие за 150 ms; текст, который сотрудник читает в ленте, при этом не сдвигается |
| Взаимодействие | Как задумала страница: подсказка над столбцом, вкладка внутри страницы | Страница работает внутри рамки. Ссылка открывается только по клику сотрудника и так же, как такая же ссылка в тексте ответа. Новое окно, отправка формы, переход вкладки Agent OS на другой адрес и любые запросы в сеть не происходят, и страница продолжает работать без них |
| Смена темы или режима | Страница в новых цветах | Перекрашивается без перезапуска: открытая вкладка, прокрутка и подсказки внутри сохраняются |
| Ошибка до отрисовки | Вместо рамки — блок высотой 80 px: радиус lg, рамка 1 px `--border`, иконка `CircleX` `--destructive`, текст «Визуализация не отрисовалась» и под ним текст ошибки — Mono `--muted-foreground`, до трёх строк. Строка подписи на месте | Скрипт страницы упал, не нарисовав первый кадр. «Показать код» открывает код |
| Ошибка после отрисовки | Рамка остаётся; между рамкой и строкой подписи — строка Caption с иконкой `CircleX` `--destructive`: «В визуализации ошибка: {текст ошибки}» | Нарисованное не пропадает; строка видна, пока блок на экране |
| Код показан | Под строкой подписи — блок кода; кнопка называется «Скрыть код» и нажата | Рамка остаётся на месте и продолжает работать. Код раскрывается и схлопывается за 150 ms |
| Не закрыт или пуст | Обычный блок кода, без рамки и строки подписи | Ответ оборвался посреди блока, или блок пуст: страница не запускается никогда |

## Content Rules

- **Название** даёт агент — короткая фраза с заглавной буквы, о чём картинка: «Ошибки по дням недели». Без названия подпись — «Визуализация».
- **Подписи рядов.** Цвет ряда не единственный признак: у каждого ряда есть подпись в легенде или у линии ([foundations → Color](../foundations.md#color), «Палитра графиков»).
- **Движение внутри страницы** подчиняется [foundations → Motion](../foundations.md#motion): ничего не мигает, при `prefers-reduced-motion` анимаций нет.
- **Текст ошибки** показывается словами браузера, как пришёл.

## Accessibility

| Аспект | Правило |
|---|---|
| Доступное имя рамки | «Визуализация: {название}», без названия — «Визуализация» |
| Клавиатура | Tab входит в рамку: на первый элемент страницы, а если элементов нет — на саму рамку, чтобы прокручивать её стрелками. Tab с последнего элемента выводит к следующему элементу ленты; ловушки фокуса нет |
| Фокус | Пока фокус в рамке или на ней, вокруг рамки — кольцо 3 px `--ring` со смещением 2 px |
| «Показать код» | Кнопка-переключатель с состоянием «нажата», связана с блоком кода |
| Объявления | Строка статуса — `status`, объявляется один раз; ошибка до отрисовки — `polite` «Визуализация не отрисовалась»; ошибка после отрисовки — `polite` со строкой ошибки |
| Содержимое | Программа чтения с экрана читает страницу внутри рамки так, как её написал агент |
