# Строка библиотеки

## Purpose

Одна запись в списке библиотеки сотрудника: что это за запись, чья она, кто её видит, что она делает и что выпадет у смотрящего при запуске. Строка ведёт на страницу записи и даёт действия над записью, доступные смотрящему.

## Anatomy

```
⌬ Разбор оплат · моя  ролевая                             ⋯     1 иконка вида · 2 подпись записи · 3 действия
  агент · SRE, Оплаты                                             4 мета
  Разбирает падения оплат по логам и тикетам, пишет…              5 описание
  ⊖ Без доступа у вас: jira — выпадет при запуске                 6 пометки
```

1. **Иконка вида** — 16 px, `--muted-foreground`: `Bot` у агента, `Workflow` у workflow.
2. **Подпись записи** — [record-label](./record-label.md), вариант «Строка»; имя — ссылка на страницу записи.
3. **Действия** — меню «⋯» (shadcn `dropdown-menu`), видно всегда.
4. **Мета** — Caption, `--muted-foreground`: вид словом; у своей ролевой записи — роли через запятую.
5. **Описание** — UI, `--foreground`, не больше двух строк с усечением в конце; полное — на странице записи.
6. **Пометки** — Caption, иконка 14 px; каждая пометка — своя строка.

Комфортная плотность: отступ строки 12 px по вертикали, 16 px по горизонтали; строки делит 1 px `--border`. Ширина — колонка ленты (chat-shell UXRD, D-01).

## Variants & Sizes

| Вариант | Когда | Действия в меню |
|---|---|---|
| Своя | Владелец — смотрящий | Открыть, Поделиться, Скопировать себе, Удалить |
| Чужая | Ролевая запись коллеги | Открыть, Скопировать себе |
| Системная | Системная запись | Открыть, Скопировать себе; администратору ещё «Открыть в панели» |

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Как в анатомии | Клик по строке вне меню или Enter по имени открывает страницу записи |
| Hover | Фон `--accent` у всей строки | — |
| Focus | Кольцо `--ring` у имени и у кнопки меню | — |
| Сервер без доступа | Пометка: `CircleMinus` и текст `--muted-foreground` | У смотрящего нет права на сервер записи или её исполнителей |
| Доступ закрыт администратором | Пометка: `ShieldOff` и текст `--muted-foreground` с датой | Только у своей записи, пока владелец снова не поделится ею |
| Действие идёт | Кнопка меню показывает `LoaderCircle` и недоступна | Ошибка — Caption `--destructive` под строкой |
| Строка ушла | Схлопывается за 150 ms | После удаления; под reduced motion — мгновенно |
| Loading | 4 строки-скелетона: две полосы разной ширины | Пульсация по [foundations → Motion](../foundations.md#motion) |

## Content Rules

- Описание — как его написал автор, без перевода.
- Пометки называют серверы по имени; больше трёх — «jira, gmail, sentry и ещё {N}».
- Тексты — custom-agents UXRD, MC-2.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | Список (`ul`), строка — `li`; имя — ссылка, остальное читается как текст после неё |
| Меню | Кнопка с именем «Действия: {имя}» |
| Клавиатура | Tab по ссылке имени, затем по кнопке меню; клик по фону строки — только для мыши и касания |
| Цвет | Пометки передают слово и иконка |
