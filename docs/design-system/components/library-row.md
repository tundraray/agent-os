# Строка библиотеки

## Purpose

Один агент или workflow в списке библиотеки сотрудника: что это, чьё, кто видит, что делает и что будет у смотрящего при запуске. Строка ведёт на страницу записи, а меню даёт действия, доступные смотрящему, — первым «Использовать в чате».

## Anatomy

```
⌬ Сводка дежурства · Борис Ким  SRE                       ⋯     1 иконка вида · 2 подпись записи · 3 действия
  агент · Готовит сводку смены по алертам                         4 вид и описание
  ⊖ Jira у вас недоступна — агент будет работать без неё          5 пометки
```

1. **Иконка вида** — 16 px, `--muted-foreground`: `Bot` у агента, `Workflow` у workflow.
2. **Подпись записи** — [record-label](./record-label.md), вариант «Строка»; в группе «Мои» без источника.
3. **Действия** — меню «⋯» (shadcn `dropdown-menu`), видно всегда.
4. **Вид и описание** — вид словом Caption `--muted-foreground`, « · » и описание UI `--foreground`; не больше двух строк с усечением в конце, полное — на странице записи.
5. **Пометки** — Caption, иконка 14 px; каждая пометка — своя строка.

Комфортная плотность: отступ строки 12 px по вертикали, 16 px по горизонтали; строки делит 1 px `--border`. Ширина — колонка ленты (chat-shell UXRD, D-01).

## Variants & Sizes

| Вариант | Когда | Действия в меню |
|---|---|---|
| Своя | Владелец — смотрящий | Использовать в чате, Открыть, Поделиться, Скопировать себе, Удалить |
| Коллеги | Агент коллеги по роли | Использовать в чате, Открыть, Скопировать себе |
| От компании | Агент или workflow компании | Использовать в чате, Открыть, Скопировать себе; администратору ещё «Открыть в панели» |

«Использовать в чате» стоит первым и его нет, если чат смотрящего запись не запустит: автор открыл её только для чтения, модель смотрящему недоступна, это определение самого чата. «Поделиться» без ролей у смотрящего или под запретом делиться недоступно, причина — в подсказке пункта.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Как в анатомии | Клик по строке вне меню или Enter по имени открывает страницу записи |
| Hover | Фон `--accent` у всей строки | — |
| Focus | Кольцо `--ring` у имени и у кнопки меню | — |
| Система недоступна | Пометка: `CircleMinus`, текст `--muted-foreground` | У смотрящего нет права на систему записи или её исполнителей; запись работает без неё |
| Модель недоступна | Пометка: `CircleMinus`, текст `--muted-foreground` | У смотрящего запись не запустится |
| Только для чтения | Пометка: `BookOpen`, текст `--muted-foreground` | Запись коллеги, которую его чат не запускает |
| Делиться нельзя | Пометка: `ShieldOff`, текст `--muted-foreground` с датой | Своя запись, к которой администратор закрыл доступ, пока запрет не снят |
| Действие идёт | Кнопка меню показывает `LoaderCircle` и недоступна | Ошибка — Caption `--destructive` под строкой |
| Строка ушла | Схлопывается за 150 ms | После удаления; под reduced motion — мгновенно |
| Loading | 4 строки-скелетона: две полосы разной ширины | Пульсация по [foundations → Motion](../foundations.md#motion) |

## Content Rules

- Описание — как его написал автор, без перевода.
- Пометки называют системы по отображаемым именам; больше трёх — «Jira, Gmail, Sentry и ещё {N}».
- Тексты — custom-agents UXRD, MC-2.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | Список (`ul`), строка — `li`; имя — ссылка, остальное читается как текст после неё |
| Меню | Кнопка с именем «Действия: {имя}»; недоступный пункт — `aria-disabled` с причиной как описанием |
| Клавиатура | Tab по ссылке имени, затем по кнопке меню; клик по фону строки — только для мыши и касания |
| Цвет | Пометки передают слово и иконка |
