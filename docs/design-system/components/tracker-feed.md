# Лента задачи

## Purpose

История одной задачи трекера и поле, в котором сотрудник её продолжает: его комментарии, комментарии агента из бесед задачи и события — поручения и смены статуса. Комментарий из поля может уйти агенту следующим сообщением беседы. Это не чат: ответ агента сотрудник читает в беседе, а на задачу агент переносит только итог и ход работы.

## Anatomy

```
Вы · 27 нояб., 14:02                                              1 автор · время
Проверь заодно стейдж, там те же алерты.                          2 текст
↗ Передано в беседу «Разбор алертов за выходные»                  3 пометка передачи

⌬ Сводка дежурства · 14:20 · из беседы «Разбор алертов…» ↗        1 · 4 источник
Нашёл 12 алертов, три новых — по оплатам. Подробности в беседе.   2
◕ Агент «Сводка дежурства» сменил статус на «На проверке» · 14:20  5 событие

┌───────────────────────────────────────────────────────────┐
│ Комментарий                                               │     6 поле
└───────────────────────────────────────────────────────────┘
[●─] Передать агенту · в беседу «Разбор алертов…»   [Отправить]   7 переключатель · 8 цель · 9 кнопка
```

1. **Автор и время** — Caption: автор UI 500 `--foreground`, « · », время `--muted-foreground` табличными цифрами. Сотрудник — «Вы»; агент — значок вида 14 px `--muted-foreground` и имя агента, которому поручена беседа.
2. **Текст** — Body `--foreground`, абзацы и переносы как их написали; не шире 640 px.
3. **Пометка передачи** — Caption `--muted-foreground`, стрелка 14 px: комментарий ушёл в беседу; название беседы — ссылка на неё.
4. **Источник** — у комментария агента после времени: « · из беседы «{название}»», название — ссылка со стрелкой 14 px.
5. **Событие** — одна строка Caption `--muted-foreground`: [иконка статуса](./tracker-status.md) или значок поручения 14 px и фраза; время в конце. Событие из того же отчёта агента стоит сразу под его комментарием.
6. **Поле** — многострочное поле shadcn `textarea`, от 3 строк, растёт до 10, дальше прокручивается.
7. **Переключатель** — shadcn `switch` с подписью справа.
8. **Цель** — Caption `--muted-foreground` после подписи: в какую беседу уйдёт комментарий; название усекается в конце.
9. **Кнопка** — `default` `sm`, справа в строке переключателя.

Записи идут по времени, старые сверху, поле — под последней записью. Между записями 16 px, событие отделено от соседей 8 px. Комфортная плотность ([foundations → Spacing & Density](../foundations.md#spacing--density)).

## Variants & Sizes

| Запись | Когда | Чем отличается |
|---|---|---|
| Комментарий сотрудника | Сотрудник написал в поле | Части 1, 2; часть 3, если комментарий передан агенту |
| Комментарий агента | Чат беседы задачи оставил отчёт | Части 1, 2, 4 |
| Событие | Поручение, смена статуса, создание задачи | Только часть 5, без текста |

Размер один.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Записи и поле | Enter отправляет, Shift+Enter переносит строку; пустое поле не отправляется, кнопка недоступна |
| Focus | Кольцо `--ring` у поля, переключателя, кнопки, ссылок | Tab: ссылки записей по порядку, затем поле, переключатель, кнопка |
| Передать: включено | Переключатель включён, цель названа | Кнопка — «Отправить агенту» |
| Передать: выключено | Переключатель выключен, цели нет | Кнопка — «Комментировать»; комментарий останется только на задаче |
| Передать: недоступно | Переключатель выключен и недоступен; вместо цели — причина | Сотрудник не может его включить, пока у задачи нет живой беседы |
| Отправка | Поле и переключатель недоступны, в кнопке вращающийся индикатор | Текст остаётся в поле до ответа |
| Отправлено | Запись встаёт в конец ленты, поле очищается, фокус остаётся в поле | Переключатель сохраняет положение до ухода с экрана |
| Ошибка отправки | Под полем Caption `--destructive` с причиной | Текст остаётся в поле, всё снова доступно |
| Новая запись извне | Комментарий агента или событие встаёт в конец ленты сразу | Прокрутка страницы не меняется, текст в поле не трогается |
| Беседа удалена | Источник и пометка передачи называют беседу без ссылки, со словами «беседа удалена» | — |
| Loading | 3 записи-скелетона: строка автора и две строки текста | Пульсация — [foundations → Motion](../foundations.md#motion) |
| Empty | Над полем одна строка Caption `--muted-foreground` | Поле доступно |

## Content Rules

- Текст комментария — как его написали сотрудник или агент; не переводится, не усекается.
- Имя агента и название беседы — как в списке бесед и в библиотеке; название беседы в цели и в источнике усекается в конце, полное — в подсказке.
- Тексты — task-tracker UXRD, MC-8 и MC-9.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | Лента — `feed` с именем «Лента задачи»; запись — `article` с именем «{автор}, {время}» |
| Поле | `textarea` с доступным именем «Комментарий»; видимой подписи нет, её роль играет подсказка в пустом поле |
| Переключатель | `switch` с именем «Передать агенту»; цель или причина — его описание (`aria-describedby`) |
| Клавиатура | Enter отправляет, Shift+Enter — новая строка; Space переключает |
| Объявления | Новый комментарий агента — `status` вежливо, имя агента и начало текста; события и свои комментарии не объявляются |
| Цвет | Автора передают слово и значок, статус — форма иконки и слово |
