# Список задач

## Purpose

Показывает план и задачи одного запуска глубокого агента на его странице: что поставлено, кто делает, кого ждёт, кто поставил и чем кончилось. Список обновляется вживую и только читается: задачи добавляют и ведут агенты и платформа, а сотрудник направляет работу сообщением. Строка короткая, чтобы десятки задач читались одним взглядом; подробности раскрываются на месте.

## Anatomy

**Широкая область (не уже 720 px):**

```
В работе: 2 · Ожидают: 1 · Готовы: 3 · Сбой: 1          [Раскрыть все]   1 сводка · 2 раскрыть все
✓  1  Собрать инциденты за ночь                Сбор                    ▸  3 строка: статус · номер · текст · кто делает · раскрытие
⟳  3  INC-412: разобрать падение оплат в 02:10 Глубокое исследование   ▸
✕  4  INC-415: проверить алерт gateway         Лёгкое исследование     ▾
       Статус      ✕ Сбой                                                 4 подробности
       Задача      INC-415: проверить алерт gateway за 01:00–03:00
       Кто делает  Лёгкое исследование   Открыть запуск ↗
       Поставил    сабагент «Сбор», задача 1 · 02:41
       Работа      02:42–02:44 · 2 мин
       Результат   Причина: исчерпан предел ходов
✓  5  Проверить, что все инциденты взяты       свой пункт              ▸
○  2  Написать бриф                            Бриф  финальная         ▸  5 финальная задача — всегда последней
```

**Узкая область (уже 720 px):**

```
⟳  3  INC-412: разобрать падение оплат…   ▸
      Глубокое исследование
```

1. **Сводка** — Caption, `--muted-foreground`: число задач в каждом статусе, только ненулевые, в порядке «В работе», «Ожидают», «Готовы», «Сбой», «Отменены». Обновляется вместе со списком.
2. **Раскрыть все** — `ghost` `sm`; когда раскрыты все строки — «Свернуть все».
3. **Строка** — [статус задачи](./agent-status.md#статусы-задачи), вариант «Иконка»; номер задачи Data табличными цифрами, `--muted-foreground`, колонка шириной по самому длинному номеру; текст задачи UI `--foreground`, одна строка с усечением в конце; «кто делает» — имя сабагента UI `--muted-foreground`, колонка шириной по самому длинному имени, до 200 px, у пункта плана — слово «свой пункт» тем же цветом; у финальной задачи — [метка состояния](./state-badge.md), вариант «Источник», «финальная»; справа кнопка раскрытия 24×24 с шевроном 14 px.
4. **Подробности** — строки «подпись — значение», как в [определении записи](./definition-view.md): подпись Caption `--muted-foreground` в колонке 120 px (в области уже 560 px — над значением), значение UI. Строки сверху вниз:
   - «Статус» — статус задачи, вариант «Метка»;
   - «Задача» — текст целиком, с переносами как у автора;
   - «Кто делает» — имя сабагента и ссылка «Открыть запуск» (UI `--primary`, `ArrowUpRight` 14 px), когда сабагент стартовал; у пункта плана — «свой пункт — ведёт сам агент»;
   - «Ждёт» — номера задач ссылками внутри списка; у финальной — «все остальные задачи»; нет зависимостей — строки нет;
   - «Поставил» — кто добавил задачу и время;
   - «Элемент» — ключ элемента Mono, только если он есть;
   - «Работа» — время старта и конца с длительностью, у идущей — только старт; у задачи, которая не стартовала, строки нет;
   - «Результат» — отчёт сабагента как текст ответа (Body, разметка как в [отчёте агента](./agent-report.md)), свёрнутый до 6 строк с «Показать целиком»; у сбоя — `CircleX` `--destructive` и причина Caption; у отменённой — фраза об остановке запуска. У пункта плана и у задачи, которая ещё идёт, строки нет.
5. **Финальная задача** стоит последней при любом номере: она стартует последней и пишет ответ.

Строки — по номеру, то есть в порядке добавления; новая встаёт перед финальной. Компактная плотность ([foundations → Spacing & Density](../foundations.md#spacing--density)): строка 32 px, в узкой области — две строки по 20 px; при грубом указателе строка не ниже 44 px. Строки делит 1 px `--border`, подробности стоят под своей строкой с отступом до колонки текста, промежуток между строками подробностей 4 px. Ширина — вся основная область до 1200 px.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| План | Запуск без задач с исполнителем (часть `agent-types`) | Все строки — пункты плана; нет строк «Кто делает» в подробностях кроме «свой пункт», нет «Результата» |
| Задачи | Запуск с задачами с исполнителем (части `tasks`, `flows`) | Пункты плана и задачи в одном списке; все части |

Размер один.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Строки свёрнуты | Клик по строке вне ссылок или Enter и Space по кнопке раскрытия раскрывают подробности |
| Hover | Фон `--accent` у строки | — |
| Focus | Кольцо `--ring` внутрь строки у кнопки раскрытия, у ссылок — своё | — |
| Раскрыто | Шеврон вниз, подробности под строкой | Раскрытие по высоте за 150 ms; выбор живёт до перезагрузки, смена статуса его не меняет |
| Открыта по ссылке | Строка раскрыта и прокручена в видимую часть, фокус на её кнопке раскрытия | Так список открывается со страницы сабагента и из строки события ленты |
| Новая задача | Строка раскрывается по высоте за 150 ms перед финальной | Если список прокручен, видимые строки остаются на месте |
| Смена статуса | Иконка меняется растворением 150 ms; сводка обновляется | Высота строки и порядок строк не меняются |
| Ждёт подтверждения | Иконка `Hand` `--approval` вместо иконки «В работе» | Сабагент задачи остановился на изменяющем вызове; карточка решения стоит в беседе |
| Переход по «Ждёт» | — | Ссылка с номером раскрывает ту задачу и ставит фокус на её кнопку раскрытия |
| Loading | Сводка-скелетон и 6 строк-скелетонов 32 px разной ширины | Пульсация — [foundations → Motion](../foundations.md#motion) |
| Empty | Иконка `ListTodo` 24 px `--muted-foreground`, заголовок Heading и фраза Body по центру области | Агент ещё не добавил ни одного пункта |
| Error | Текст ошибки и «Повторить» (`outline`) по центру области | Повтор показывает Loading |

Под reduced motion раскрытие, новые строки и смена статуса — мгновенно; вращение «В работе» заменяется по правилу статуса.

## Content Rules

- Текст задачи — как его написал агент; не переводится, усекается только в конце.
- Номер — порядковый номер задачи в запуске, с 1; стартовые задачи флоу получают свои номера из записи. Номер нигде не пересчитывается.
- Имя сабагента — как в команде глубокого агента.
- Время — по [foundations → Language & Formats](../foundations.md#language--formats): «Время в списках и ленте» и «Длительность».
- Тексты — deep-agents UXRD, MC-10–MC-14.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | Список (`ul`) с именем «Задачи»; строка — `li`; сводка — текст перед списком |
| Кнопка раскрытия | `button` с `aria-expanded` и `aria-controls`; имя — «Задача {номер}: {текст}, {статус}» |
| Подробности | Список описаний (`dl`) |
| Иконка статуса | `img` с именем статуса, подсказка через 500 ms |
| Клавиатура | Tab по «Раскрыть все», затем в каждой строке по кнопке раскрытия и, у раскрытой, по ссылкам подробностей |
| Объявления | Новые задачи и смены статусов не объявляются |
| Цвет | Статус передают форма иконки и имя |
