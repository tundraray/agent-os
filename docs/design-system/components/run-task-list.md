# Список задач

## Purpose

Показывает список задач одной сессии — беседы или глубокого агента — и поручения глубокого агента его сабагентам. Задачи агент ведёт сам, по образцу Claude Code; поручения запускает платформа. Список обновляется вживую и только читается: изменить его сотрудник просит чат. Строка короткая, чтобы десятки строк читались одним взглядом.

## Anatomy

**Вариант «Задачи»:**

```
✓  1  Разбить вопрос на направления                   План   ▸   1 строка: статус · номер · тема · исполнитель · раскрытие
      Готова                                                     2 вторая строка
⟳  2  Собрать данные по направлениям                         ▾
      В работе · Собираю данные по трём направлениям
      По каждому направлению — релизы и откаты за год.           3 описание
○  3  Написать ответ                                         ▸
      Ожидает · ждёт 2
```

**Вариант «Поручения»:**

```
Поручения · 4      в работе 1 · готово 2 · сбой 1               4 шапка · 5 сводка
✓  План  Разбить вопрос на направления      задача 1       ↗    6 строка: статус · сабагент · текст · задача · ссылка
         Готово · Три направления: регламент, откаты, …         7 вторая строка
✕  Сбор  Гайды дежурных                                    ↗
         Сбой · исчерпан предел шагов
```

1. **Строка задачи** — иконка [статуса задачи](./agent-status.md#статусы-задачи); номер Data табличными цифрами `--muted-foreground`, колонка по самому длинному номеру; тема UI `--foreground`, одна строка с усечением в конце, у готовой — `--muted-foreground`; исполнитель, если задан, — UI `--muted-foreground` справа, до 200 px; шеврон 14 px в поле 24×24. Вся строка — кнопка раскрытия.
2. **Вторая строка задачи** — Caption `--muted-foreground`: статус словом; у задачи «В работе» — « · » и текст в работе; у заблокированной — « · ждёт {номера}». Одна строка с усечением, у раскрытой — с переносами.
3. **Описание** — Body `--foreground`, абзацы и переносы как у агента; только у раскрытой строки, с отступом до колонки темы.
4. **Шапка раздела** — Heading «Поручения · {N}».
5. **Сводка** — Caption `--muted-foreground`: число поручений в каждом статусе, только ненулевые, в порядке «в работе», «готово», «сбой», «отменено».
6. **Строка поручения** — иконка [статуса поручения](./agent-status.md#статусы-поручения); имя сабагента UI 500, колонка по самому длинному имени, до 160 px; текст поручения или пункт UI `--foreground`, одна строка с усечением; метка «задача {N}» Caption `--muted-foreground`, если поручение назвало задачу; `ArrowUpRight` 14 px `--muted-foreground`. Вся строка — ссылка на страницу сабагента; пока он не стартовал, строка не ссылка и стрелки нет.
7. **Вторая строка поручения** — Caption `--muted-foreground`: статус словом; у готового — « · » и начало ответа, до двух строк с усечением; у сбоя — « · » и причина.

Строки идут по номеру задачи или в порядке поручений, пункты поручения по списку — в порядке пунктов. Компактная плотность ([foundations → Spacing & Density](../foundations.md#spacing--density)): первая строка 32 px, вторая 20 px; при грубом указателе строка не ниже 44 px. Строки делит 1 px `--border`. Ширина — вся основная область до 1200 px; в панели «Схема» — ширина панели, всегда по правилам узкой области.

**Узкая область** (уже 560 px и всегда в панели): исполнитель и метка «задача {N}» уходят в начало второй строки через « · ».

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Задачи | Список задач беседы или глубокого агента | Части 1–3 |
| Поручения | Поручения глубокого агента, под его задачами | Части 4–7; строки не раскрываются |

Размер один.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Строки задач свёрнуты | Клик, Enter или Space раскрывают описание; строка поручения открывает страницу сабагента |
| Hover | Фон `--accent` у строки | — |
| Focus | Кольцо `--ring` внутрь строки | — |
| Раскрыто | Шеврон вниз за 150 ms, описание под строкой | Описание появляется сразу, без анимации высоты; выбор живёт, пока список на экране |
| Новая строка | Встаёт на своё место сразу | Если список прокручен, видимые строки остаются на месте |
| Смена статуса | Иконка меняется растворением 150 ms; сводка обновляется | Порядок строк не меняется |
| Ждёт подтверждения | У строки поручения `Hand` `--approval` | Сабагент остановился на изменяющем вызове; карточка решения стоит в беседе |
| Loading | 6 строк-скелетонов 32 px разной ширины | Пульсация — [foundations → Motion](../foundations.md#motion) |
| Empty | Иконка `ListTodo` 24 px `--muted-foreground`, заголовок Heading и фраза Body по центру области | Экран решает, когда показывать |
| Error | Текст ошибки и «Повторить» (`outline`) по центру области | Повтор показывает Loading |

Под reduced motion поворот шеврона и смена статуса — мгновенно.

## Content Rules

- Тема, текст в работе, описание, пункт, ответ и причина — как их дал агент или платформа; не переводятся, усекаются только в конце.
- Номер — тот, что дала платформа; он нигде не пересчитывается.
- Имя сабагента — как в команде глубокого агента.
- Тексты — deep-agents UXRD, MC-10–MC-14.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | Список (`ul`) с именем «Задачи» или «Поручения»; строка — `li`; сводка — текст перед списком |
| Строка задачи | `button` с `aria-expanded` и `aria-controls` на описание; имя — «Задача {номер}: {тема}, {статус}» |
| Строка поручения | Ссылка с именем «{сабагент}: {пункт}, {статус}»; без ссылки — тот же текст |
| Иконка статуса | Декоративная: статус — словом во второй строке |
| Клавиатура | Tab по строкам задач, затем по ссылкам поручений |
| Объявления | Новые строки и смены статусов не объявляются |
| Цвет | Статус передают слово и форма иконки |
