# Таблица данных

## Purpose

Список однотипных записей, которые сравнивают по одним и тем же колонкам: сотрудники, роли, серверы, модели, права. Компонент собран на shadcn `table` (Source) и добавляет к нему строку-ссылку, действия строки, вложенные строки и состояния загрузки. Высота строки, текст ячеек и отступы следуют плотности страницы ([foundations → Spacing & Density](../foundations.md#spacing--density)); размеры ниже даны для компактной.

## Anatomy

```
Сотрудник              Статус       Роли                    Последний вход    1 шапка
Аня Смирнова           ● Включён    SRE · Дежурный          14:20         ⋯   2 строка · 3 действия
anya@corp.example
  update_issue         ⊘ Закрыт     закрыто личным запретом                   4 вложенная строка
                       [ Показать ещё ]                                       5 подгрузка
```

1. **Шапка** — Caption, `--muted-foreground`, нижняя граница 1 px `--border`. Не липкая.
2. **Строка** — Data, `--foreground`, высота 32 px, нижняя граница 1 px `--border`. Первая ячейка может нести вторую строку Caption `--muted-foreground` (почта, техническое имя); тогда строка растёт на 16 px.
3. **Действия строки** — справа, видны всегда: кнопки `outline` `sm` или меню «⋯» (shadcn `dropdown-menu`); что из двух, решает экран.
4. **Вложенная строка** — отступ 24 px в первой ячейке, без своей шапки; показывает часть родителя, например цены длинных запросов модели.
5. **Подгрузка** — «Показать ещё» (`ghost`, `sm`) под последней строкой.

Отступ ячейки по горизонтали 12 px. Числа — табличные цифры, по правому краю; числа и деньги оформлены по [foundations → Language & Formats](../foundations.md#language--formats).

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Строка-ссылка | Запись открывается на своей странице: сотрудник, роль, сервер | Вся строка — ссылка на запись по первой ячейке; наведение `--accent` |
| Строка с действиями | Действие делают на месте: права роли, личные права | Строка не ссылка; кнопки или «⋯» справа |
| Вложенная | Часть записи под ней: цены длинных запросов модели | Вложенные строки всегда раскрыты, шеврона нет |
| Две строки | Таблица комфортной плотности на ширине < 768 px | Шапки нет; запись — первая ячейка строкой UI, под ней остальные ячейки через « · » Caption `--muted-foreground` |

Таблица занимает ширину основной области. Колонки задаёт экран; узкая область прокручивает таблицу по горизонтали внутри её блока, страница целиком не прокручивается вбок.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Строки по порядку, который задаёт экран | Порядок постоянный; сортировки по клику на шапку нет |
| Hover | Фон строки `--accent` | Только у строки-ссылки и строки с действиями |
| Focus | Кольцо `--ring` внутрь строки-ссылки или на кнопке действия | Tab идёт по ссылкам строк и кнопкам действий |
| Loading | Шапка и 6 строк-скелетонов разной ширины | Пульсация по foundations; для скринридера — статус с текстом экрана |
| Empty | Шапки нет; на месте строк — текст в две строки: первая UI `--foreground`, вторая Caption `--muted-foreground`; иконка 24 px по центру сверху | Действие, если есть, — основная кнопка экрана в шапке страницы, не дубль внутри таблицы |
| Нет совпадений | Шапка остаётся; одна строка текста экрана на месте строк | Появляется, когда поиск или отбор ничего не нашёл |
| Error | Текст ошибки и «Повторить» (`outline`, `sm`) по центру блока | «Повторить» возвращает Loading |
| Partial | «Показать ещё» под последней строкой | Подгружает следующую страницу; ошибка подгрузки — текст и «Повторить» на месте кнопки, загруженные строки остаются |
| Строка ушла | Строка схлопывается за 150 ms | После решения или удаления на месте; под reduced motion — мгновенно |
| Действие идёт | Кнопка действия показывает `LoaderCircle` и недоступна; остальные строки работают | Ошибка — текст ошибки Caption `--destructive` под строкой, кнопки снова доступны |
| Итог действия | Под строкой Caption-строка с отступом ячейки: пока действие идёт — `LoaderCircle` и текст экрана; успех — [метка состояния](./state-badge.md) «Хорошо» и время; отказ — `CircleX` и текст `--destructive` | Для действий, чей итог нужно видеть и после ответа, например проверки подключения. Держится, пока человек на странице; повтор заменяет итог. Текст переносится, не усекается и не прокручивается вместе с таблицей. Начало и итог объявляются `status` |

## Content Rules

- Шапка колонки — одно-два слова с заглавной буквы, без точки.
- Текст в ячейке усекается в конце одной строкой, полное значение — в подсказке. Технические имена — Mono 13 / 20, усечение посередине.
- Пустое значение — «—».
- Время — по [foundations → Language & Formats](../foundations.md#language--formats), строка «Время в списках и ленте».

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | `table` с подписью (`caption`, визуально скрытой) — название таблицы на экране |
| Строка-ссылка | Ссылка в первой ячейке; остальные ячейки читаются как текст строки |
| Действия | Кнопки с доступным именем «{действие}: {запись}», например «Отказать: Аня Смирнова» |
| Вложенная строка | Первая ячейка начинается со скрытого «в {родитель}:» |
| Клавиатура | Tab по ссылкам и кнопкам по порядку на экране; Enter открывает запись или нажимает кнопку |
| Объявления | Loading и Error — `status`; ушедшая строка не объявляется, фокус переходит по правилу экрана |
