# Секрет

## Purpose

Поле формы для секрета — ключа или токена, который платформа хранит, но никому не показывает после сохранения. Секрет можно только задать или заменить.

## Anatomy

```
Ключ                                           1 подпись
● Задан  …x9Qz                  [ Заменить ]   2 метка · 7 концовка · 3 кнопка
──────────────────────────────────────────────
Ключ
[ ••••••••••••••••••          👁 ] Отменить замену   4 поле · 5 показать · 6 отмена
```

1. **Подпись** — как у любого поля формы ([settings-form](./settings-form.md)).
2. **Метка «Задан»** — [метка состояния](./state-badge.md), вариант «Состояние», нейтральная.
3. **«Заменить»** — кнопка `outline` `sm`.
4. **Поле** — ввод скрытыми символами, Mono 13 / 20.
5. **Показать ввод** — иконочная кнопка `Eye` / `EyeOff` внутри поля справа; показывает только то, что человек сейчас ввёл.
6. **«Отменить замену»** — кнопка `ghost` `sm`; есть, только если секрет уже был задан.
7. **Концовка** — «…» и последние четыре символа секрета, Mono 13 / 20 `--muted-foreground`, сразу после метки. Есть, только если сервер их возвращает, как у ключа провайдера моделей; у других секретов её нет.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Не задан | Пустое поле с плейсхолдером | Обязательное поле проверяется при сохранении, как любое другое |
| Задан | Метка «Задан», концовка, если она есть, и «Заменить»; поля ввода нет | Значения нет ни на экране, ни в коде страницы; концовка — единственное, что сервер о нём сообщает |
| Замена | Пустое поле с фокусом и «Отменить замену» | Сохранение формы заменяет секрет; «Отменить замену» возвращает «Задан» без изменений. В форме, где есть другие поля, пустое поле при сохранении оставляет прежний секрет; в форме из одного поля секрета сохранение недоступно, пока поле пусто ([settings-form](./settings-form.md)) |
| Ввод показан | Символы видны, иконка `EyeOff` | Скрытие — тем же нажатием; после сохранения поле снова «Задан» |
| Ошибка | Рамка `--destructive`, текст ошибки под полем | Как ошибка поля в settings-form |

## Content Rules

- Плейсхолдер — «Новое значение».
- Секрет не попадает в подсказки, уведомления, заголовки вкладки и сообщения об ошибке.

## Accessibility

| Аспект | Правило |
|---|---|
| Поле | Поле со скрытым вводом и подписью; «Показать ввод» — `button` с `aria-pressed` и именем «Показать введённое значение» |
| Метка «Задан» | Связана с подписью поля: скринридер читает «{подпись}: задан», с концовкой — «{подпись}: задан, заканчивается на {символы}» |
| «Заменить» | Имя «Заменить: {подпись}»; после нажатия фокус в поле |
| «Отменить замену» | Фокус возвращается на «Заменить» |
