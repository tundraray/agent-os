# Секрет

## Purpose

Секрет — ключ, токен или пароль, который платформа хранит, но никому не показывает после сохранения. Компонент даёт два способа работать с ним: **поле секрета** в форме, которое можно только задать или заменить, и **показ один раз** — окно с секретом, который создала сама платформа и который больше нигде не появится.

## Anatomy

**Поле секрета:**

```
Client secret                                  1 подпись
● Задан                         [ Заменить ]   2 метка · 3 кнопка
──────────────────────────────────────────────
Client secret
[ ••••••••••••••••••          👁 ] Отменить замену   4 поле · 5 показать · 6 отмена
```

1. **Подпись** — как у любого поля формы ([settings-form](./settings-form.md)).
2. **Метка «Задан»** — [метка состояния](./state-badge.md), вариант «Состояние», нейтральная.
3. **«Заменить»** — кнопка `outline` `sm`.
4. **Поле** — ввод скрытыми символами, Mono 13 / 20.
5. **Показать ввод** — иконочная кнопка `Eye` / `EyeOff` внутри поля справа; показывает только то, что человек сейчас ввёл.
6. **«Отменить замену»** — кнопка `ghost` `sm`; есть, только если секрет уже был задан.

**Показ один раз** — диалог (shadcn `dialog`):

```
Токен SCIM                                         1 заголовок
Скопируйте токен сейчас: после закрытия окна        2 предупреждение
его нельзя будет посмотреть снова.
┌──────────────────────────────────────────────┐
│ scim_9f2c…a71e                     [Копировать]│   3 значение · 4 копировать
└──────────────────────────────────────────────┘
                                         [Готово]   5 закрыть
```

1. **Заголовок** — Heading.
2. **Предупреждение** — UI, `--foreground`, иконка `TriangleAlert` цветом `--warning` перед текстом.
3. **Значение** — Mono 13 / 20 на `--muted`, радиус md, целиком, с переносом; выделяется одним кликом.
4. **«Копировать»** — кнопка `outline` `sm`, иконка `Copy`; после нажатия на 2 с — `Check` и «Скопировано».
5. **«Готово»** — основная кнопка диалога.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Поле секрета | Секрет вводит человек: секрет клиента OIDC, токен общей учётной записи MCP-сервера | Значение никогда не возвращается в форму |
| Показ один раз | Секрет создаёт платформа: токен SCIM | Значение видно только в этом окне |

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Поле: не задан | Пустое поле с плейсхолдером | Обязательное поле формы проверяется при сохранении, как любое другое |
| Поле: задан | Метка «Задан» и «Заменить»; поля ввода нет | Значения нет ни на экране, ни в коде страницы |
| Поле: замена | Пустое поле с фокусом и «Отменить замену» | Сохранение формы заменяет секрет; «Отменить замену» возвращает «Задан» без изменений |
| Поле: ввод показан | Символы видны, иконка `EyeOff` | Скрытие — тем же нажатием; после сохранения поле снова «Задан» |
| Поле: ошибка | Рамка `--destructive`, текст ошибки под полем | Как ошибка поля в settings-form |
| Показ: открыт | Диалог со значением; фокус на «Копировать» | Esc, клик вне окна и «Готово» закрывают окно; закрытое окно значение не возвращает |
| Показ: скопировано | `Check` и «Скопировано» на кнопке 2 с | Затем кнопка возвращается в обычный вид |
| Показ: копирование не удалось | Под значением Caption `--destructive` | Значение остаётся выделяемым вручную |

## Content Rules

- Плейсхолдер поля — «Новое значение».
- Секрет не попадает в подсказки, уведомления, заголовки вкладки и сообщения об ошибке.
- Предупреждение показа один раз называет, что именно нельзя будет посмотреть снова.

## Accessibility

| Аспект | Правило |
|---|---|
| Поле | `input type="password"` с подписью; «Показать ввод» — `button` с `aria-pressed` и именем «Показать введённое значение» |
| Метка «Задан» | Текст, связанный с подписью поля: скринридер читает «{подпись}: задан» |
| «Заменить» | Имя «Заменить: {подпись}»; после нажатия фокус в поле |
| «Отменить замену» | Фокус возвращается на «Заменить» |
| Показ один раз | `dialog` с именем-заголовком и описанием-предупреждением; фокус на «Копировать», после закрытия — на кнопку, которая открыла окно |
| «Скопировано» | Объявление `polite` |
