# Карточка хода

## Purpose

Карточка стоит в ленте там, где чат или агент запустил фонового агента или workflow, и показывает его ход вживую: статус, а у workflow — агентов, которых вызвал координатор. Карточка остаётся на месте запуска весь срок работы и после него; отчёт приходит отдельно ([agent-report](./agent-report.md)). Управлять агентом карточка не даёт — для этого её ссылка ведёт на страницу агента.

## Anatomy

**Workflow:**

```
┌──────────────────────────────────────────────────────┐
│ ⟳ Работает   Глубокий ресерч                  14:35 │  1 статус · 2 название · 3 время
│ Почему с 14:00 падают оплаты                         │  4 строка брифа
│ ✓ План                                               │  5 строки шагов
│ ⟳ Сбор · ошибки gateway                              │
│ ⟳ Сбор · выкладки за день                            │
│ Открыть запуск →                                     │  6 ссылка
└──────────────────────────────────────────────────────┘
```

**Агент:**

```
┌──────────────────────────────────────────────────────┐
│ ⟳ Работает   Инциденты по оплате    14:20  Открыть → │  1 · 2 · 3 · 6
└──────────────────────────────────────────────────────┘
```

1. **Статус** — [agent-status](./agent-status.md), вариант «Метка»: статус агента или координатора.
2. **Название** — UI, 500, `--foreground`: описание агента или имя шаблона; одна строка, усечение в конце.
3. **Время** запуска — Caption, `--muted-foreground`, табличные цифры.
4. **Строка брифа** — вопрос подтверждённого брифа, UI, `--muted-foreground`, одна строка с усечением; полный текст — в карточке решения выше.
5. **Строки шагов** — по строке на каждого агента, которого вызвал координатор, в порядке вызова: [agent-status](./agent-status.md) вариант «Иконка» и описание агента (UI). Строка — ссылка на страницу агента, высота 28 px.
6. **Ссылка** — UI, `--primary`, иконка `ArrowUpRight` 14 px.

Ширина — колонка прозы ленты (chat-shell UXRD, D-01). Подложка `--card`, рамка 1 px `--border`, радиус lg, отступ 12 px, без тени; компактная плотность внутри.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Агент | Запущен один фоновый агент | Одна строка: части 1, 2, 3, 6 |
| Workflow | Запущен workflow по шаблону | Части 1–6; строки шагов появляются по мере вызова |

Размер один. При грубом указателе строки шагов и ссылка — 44 px.

## States

Статус карточки — статус агента или координатора; подложка и рамка от статуса не меняются, цвет есть только у иконок и метки.

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Работает | Статус «Работает» | Иконка вращается; подпись не мерцает |
| Ждёт подтверждения (Агент) | Статус (часть 1) — «Ждёт подтверждения» | Сама карточка решения стоит в конце ленты; карточка хода кнопок не получает |
| Шаг ждёт подтверждения (Workflow) | У строки шага — иконка `Hand`; статус (часть 1) остаётся статусом координатора | Сама карточка решения стоит в конце ленты; карточка хода кнопок не получает |
| Прерван, Завершён, Сбой, Остановлен | Статус меняется на месте; строки шагов остаются | Ссылка остаётся |
| Новый шаг | Строка добавляется под последней, раскрываясь по высоте за 150 ms | Существующие строки не сдвигаются; под reduced motion — мгновенно |
| Смена статуса шага | Иконка шага меняется растворением 150 ms | Высота не меняется |
| Hover / Focus строки шага | Фон `--accent` / кольцо `--ring` внутрь строки | Enter или клик открывает страницу агента |
| Продолжен с историей | Статус снова «Работает» | Новые шаги добавляются в конец |

## Content Rules

- Описание шага — как его дал координатор; усечение в конце, полное — в подсказке.
- Время — «ЧЧ:ММ» за сегодня, иначе «12 нояб., ЧЧ:ММ».
- В карточке нет токенов и стоимости.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | `group` с именем «{название}: {статус}»; строки шагов — список ссылок |
| Доступное имя | Ссылка шага — «{описание}, {статус}»; ссылка карточки — agent-platform UXRD, MC-17 |
| Клавиатура | Tab по ссылкам шагов, затем по ссылке карточки |
| Объявления | Карточка не объявляет смену статусов и новые шаги |
| Цвет | Статус передают иконка и текст или доступное имя |
