# Карточка хода

## Purpose

Карточка стоит в ленте там, где чат или агент запустил фонового агента или workflow, и показывает его ход вживую: статус, а у workflow — кого из команды позвал координатор и кого не звал. Карточка остаётся на месте запуска весь срок работы и после него; отчёт приходит отдельно ([agent-report](./agent-report.md)). Управлять агентом карточка не даёт — для этого её ссылка ведёт на страницу агента. Если агент изменился после старта, карточка говорит об этом и даёт запустить его заново через поле сообщения.

## Anatomy

**Workflow:**

```
┌──────────────────────────────────────────────────────────────┐
│ ⟳ Работает   Разбор инцидента · Аня  SRE · версия 3   14:35 │  1 статус · 2 название · 3 время
│ Почему с 14:00 падают оплаты                                 │  4 строка задания
│ Аня Смирнова · для роли SRE: работает с вашими правами…      │  7 пояснение получателю
│ ✓ Сбор логов     ошибки gateway за 14:00–15:00               │  5 строки шагов
│ ⊘ Сбор логов     предел вызовов исчерпан                     │
│ ⟳ Ответ          сводка по найденному                        │
│ ○ Сбор метрик    не вызывался                                │  после конца запуска
│ ⓘ Workflow изменён после запуска: сейчас версия 4            │  8 изменён после запуска
│                                        [ Запустить заново ]  │
│ Открыть запуск →                                             │  6 ссылка
└──────────────────────────────────────────────────────────────┘
```

**Агент:**

```
┌──────────────────────────────────────────────────────┐
│ ⟳ Работает   Инциденты по оплате    14:20  Открыть → │  1 · 2 · 3 · 6
│ Разбор оплат · Аня Смирнова  SRE                     │  подпись записи
└──────────────────────────────────────────────────────┘
```

1. **Статус** — [agent-status](./agent-status.md), вариант «Метка»: статус агента или координатора.
2. **Название** — UI, 500, `--foreground`: поручение агента; одна строка, усечение в конце. У workflow название — [подпись записи](./record-label.md), вариант «Строка», с версией старта. У агента из библиотеки под строкой карточки стоит подпись записи, вариант «Под названием», и вариант «Агент» становится двухстрочным (custom-agents UXRD, RN-01).
3. **Время** запуска — Caption, `--muted-foreground`, табличные цифры.
4. **Строка задания** — вопрос подтверждённого задания workflow, UI, `--muted-foreground`, одна строка с усечением; полный текст — в карточке «Задание · {имя}» выше (custom-agents UXRD, MC-21).
5. **Строки шагов** — по строке на каждый вызов координатора, в порядке вызова: [agent-status](./agent-status.md) вариант «Иконка», имя исполнителя из команды (UI 500, колонка шириной по самому длинному имени, до 160 px) и текст поручения от координатора (UI, `--muted-foreground`, усечение в конце). Строка — ссылка на страницу агента, высота 28 px.
6. **Ссылка** — UI, `--primary`, иконка `ArrowUpRight` 14 px.
7. **Пояснение получателю** — Caption, `--muted-foreground`, до трёх строк; только при первом запуске агента коллеги в беседе получателя.
8. **Изменён после запуска** — [метка состояния](./state-badge.md) «Сведения» с номером новой версии и «Запустить заново» (`outline`, `sm`) справа; только когда у записи есть версия новее версии старта.

Ширина — колонка прозы ленты (chat-shell UXRD, D-01). Подложка `--card`, рамка 1 px `--border`, радиус lg, отступ 12 px, без тени; компактная плотность внутри.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Агент | Запущен один фоновый агент | Части 1, 2, 3, 6; у агента из библиотеки — подпись записи, 7 и 8 по условиям |
| Workflow | Запущен workflow | Части 1–8; строки шагов появляются по мере вызова |

Размер один. При грубом указателе строки шагов, ссылка и «Запустить заново» — 44 px.

## States

Статус карточки — статус агента или координатора; подложка и рамка от статуса не меняются, цвет есть только у иконок и метки.

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Работает | Статус «Работает» | Иконка вращается; подпись не мерцает |
| Ждёт подтверждения (Агент) | Статус (часть 1) — «Ждёт подтверждения» | Сама карточка решения стоит в конце ленты; карточка хода кнопок не получает |
| Шаг ждёт подтверждения (Workflow) | У строки шага — иконка `Hand`; статус (часть 1) остаётся статусом координатора | Как выше |
| Вызов отклонён по пределу | Строка шага: `Ban` `--muted-foreground`, имя исполнителя, вместо поручения — «предел вызовов исчерпан»; не ссылка | Агента не было, страницы нет |
| Прерван, Завершён, Сбой, Остановлен | Статус меняется на месте; строки шагов остаются | Ссылка остаётся |
| Не вызывался | После конца запуска под шагами — строки исполнителей команды, которых координатор не звал: `Circle` и текст `--muted-foreground`, «не вызывался»; не ссылки | Появляются раскрытием по высоте 150 ms, под reduced motion — мгновенно |
| Новый шаг | Строка добавляется под последней, раскрываясь по высоте за 150 ms | Существующие строки не сдвигаются; под reduced motion — мгновенно |
| Смена статуса шага | Иконка шага меняется растворением 150 ms | Высота не меняется |
| Hover / Focus строки шага | Фон `--accent` / кольцо `--ring` внутрь строки | Enter или клик открывает страницу агента |
| Изменён после запуска | Часть 8 | «Запустить заново» кладёт агента чипом в поле сообщения беседы, где шёл запуск, а если её уже нет — новой (custom-agents UXRD, CH-01); запуска до отправки нет |
| Запись недоступна | Подпись записи в состоянии «Недоступна»; части 8 нет | Запустить заново нельзя |
| Продолжен с историей | Статус снова «Работает» | Новые шаги добавляются в конец |

## Content Rules

- Имя шага — как в команде workflow; текст поручения — как его дал координатор, усечение в конце, полный — в подсказке.
- Время — по [foundations → Language & Formats](../foundations.md#language--formats), строка «Время в списках и ленте».
- В карточке нет токенов и стоимости.
- Тексты частей 7 и 8 и пометок шагов — custom-agents UXRD, MC-17.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | `group` с именем «{название}: {статус}»; строки шагов — список |
| Доступное имя | Ссылка шага — «{исполнитель}, {поручение}, {статус}»; строка без ссылки читается текстом «{исполнитель}, не вызывался» или «{исполнитель}, предел вызовов исчерпан»; ссылка карточки — agent-platform UXRD, MC-17 |
| Клавиатура | Tab по ссылкам шагов, «Запустить заново», затем по ссылке карточки |
| Объявления | Карточка не объявляет смену статусов и новые шаги |
| Цвет | Статус передают иконка и текст или доступное имя |
