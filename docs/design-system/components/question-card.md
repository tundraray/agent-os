# Карточка вопроса

## Purpose

Карточка, в которой агент спрашивает сотрудника, когда сам не может выбрать: один–четыре вопроса, у каждого два–четыре варианта с описанием и поле «Другое» для своего ответа. Сотрудник отмечает ответы и отправляет их одной кнопкой или пропускает всю карточку. Пока ответа нет, спросивший агент ждёт. Карточка — сестра [карточки решения](./decision-card.md): та же рамка, шапка, источник и итог, но тело — вопросы, а не действие. Одна и та же карточка стоит в беседе и в истории спросившего агента; ответ в одном месте закрывает обе.

## Anatomy

```
┌──────────────────────────────────────────────────────┐
│ ✋ Ждёт ответа                                 14:36  │  1 статус · 2 время
│ Агент «Сбор логов» спрашивает:                       │  3 источник
│ Сбор логов · Борис Ким · SRE                         │
│                                                      │
│ 1. Какой сервис разобрать?                           │  4 вопрос
│ (•) payments                                         │  5 вариант
│     Касса и оплаты заказов                           │
│ ( ) checkout                                         │
│     Корзина и оформление заказа                      │
│ ( ) Другое  [ свой ответ…                       ]    │  6 «Другое»
│                                                      │
│ 2. Что добавить в отчёт?            можно несколько  │  4 · 7 пометка
│ [ ] График ошибок по часам                           │
│ [ ] Пять частых сообщений                            │
│ [ ] Другое  [                                   ]    │
│ Без ответа: вопрос 2 — агент решит сам               │  8 сводка
│ ⓧ Не удалось отправить ответ. Попробуйте ещё раз.    │  9 строка ошибки
│ [ Ответить ]  [ Пропустить ]                         │  10 ряд действий
└──────────────────────────────────────────────────────┘
```

После ответа:

```
┌──────────────────────────────────────────────────────┐
│ ✓ Отвечено · 14:37                                   │  итог
│ Агент «Сбор логов» спрашивал:                        │
│ Какой сервис разобрать?                              │  вопрос
│ payments                                             │  ответ
│ Что добавить в отчёт?                                │
│ Свой ответ: только ошибки 5xx                        │
└──────────────────────────────────────────────────────┘
```

1. **Статус** — [статус агента](./agent-status.md), вариант «Метка», вид «Ждёт подтверждения» со словом «Ждёт ответа».
2. **Время** вопроса — как у карточки решения, часть 2.
3. **Источник** — кто спрашивает, по правилам части 3 карточки решения: имя агента — ссылка на его страницу, под ним [подпись записи](./record-label.md), если агент запущен по записи библиотеки. У сабагента глубокого агента здесь стоит сам сабагент, а не глубокий агент.
4. **Вопрос** — UI 500, `--foreground`. При двух и больше вопросах перед текстом стоит номер «1.», при одном номера нет.
5. **Вариант** — строка во всю ширину: радиокнопка (или флажок у вопроса с несколькими ответами), подпись UI `--foreground` и под ней описание UI `--muted-foreground`. Строка нажимается целиком.
6. **«Другое»** — последняя строка каждого вопроса: радиокнопка или флажок, подпись «Другое» и поле для своего ответа в той же строке. Поле однострочное и растёт в высоту по тексту.
7. **Пометка** «можно несколько» — Caption, `--muted-foreground`, справа от вопроса; только у вопроса с несколькими ответами.
8. **Сводка** — Caption, `--muted-foreground`: какие вопросы останутся без ответа. Только пока ответ есть хотя бы на один вопрос, но не на все.
9. **Строка ошибки** — как у карточки решения, часть 9.
10. **Ряд действий** — «Ответить» (`default`) и «Пропустить» (`ghost`), размер `sm`.

Ширина, радиус, рамка, отступ и промежуток — как у карточки решения. Между вопросами 16 px, между вариантами 4 px, между подписью и описанием варианта 0 px.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Один ответ | Вопрос разрешает один вариант | Радиокнопки; выбор другого варианта снимает прежний |
| Несколько ответов | Вопрос разрешает несколько вариантов | Флажки и пометка 7; «Другое» отмечается вместе с вариантами |

В одной карточке вопросы обоих видов стоят вперемешку. Размер один. При грубом указателе строка варианта и кнопки — не ниже 44 px. На ширине < 480 px поле «Другое» встаёт под своей подписью во всю ширину, а кнопки ряда действий — столбцом во всю ширину.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Ждёт | Подложка `--approval-subtle`, рамка `--approval-border`; ничего не отмечено | Ждёт, пока сотрудник не ответит или не пропустит здесь или в другой копии. Переживает перезагрузку и рестарт сервера; отмеченное, но не отправленное, после перезагрузки не сохраняется |
| Hover варианта | Фон строки `--accent` | — |
| Вариант выбран | Отмеченная радиокнопка или флажок цветом акцента, подпись 500 | Повторное нажатие на флажок снимает отметку; радиокнопку снимает только выбор другого варианта того же вопроса |
| «Другое» выбрано | Отметка у «Другое», фокус в поле | Ввод в поле сам отмечает «Другое»; у вопроса с одним ответом он снимает прежний вариант. Пустое поле — вопрос без ответа |
| «Другое» не выбрано | Текст в поле цветом `--muted-foreground` | Выбор другого варианта оставляет введённый текст, но не отправляет его |
| Нет ответов | «Ответить» недоступна (`aria-disabled`) с подсказкой | Сводки нет; «Пропустить» доступна всегда |
| Часть ответов | Сводка 8 называет вопросы без ответа | «Ответить» отправляет то, что есть; вопрос без ответа агент получает как пропущенный |
| Отправка | Как «Ждёт»; варианты, поля и кнопки недоступны, в нажатой — индикатор, как у карточки решения | Повторное нажатие ничего не делает |
| Ошибка отправки | «Ждёт» с отмеченным и строкой ошибки | Отмеченное и введённое остаются; повтор — та же кнопка |
| Отвечено | Подложка `--card`, рамка `--border`; итог иконкой успеха цветом `--success`; источник в прошедшем времени. Под каждым вопросом — ответ UI `--foreground`: подписи выбранных вариантов через запятую, «Свой ответ: …» или «Без ответа» цветом `--muted-foreground`. Вариантов, описаний и кнопок нет | Не меняется |
| Пропущено | Подложка `--card`; итог цветом `--muted-foreground`; вопросы без ответов | Не меняется |
| Не понадобилось | Подложка `--card`; итог цветом `--muted-foreground`; вопросы без ответов | Агента остановили, пока вопрос ждал |
| Focus | Кольцо `--ring` у вариантов, полей и кнопок; у карточки — после ответа | Подложка от фокуса не меняется |

Ответ, данный в другой копии карточки или в другой вкладке, переводит карточку в итог без строки ошибки; отмеченное здесь пропадает. Смена состояния — растворение 150 ms, как у карточки решения. Переход в итог убирает варианты и ряд действий, и карточка становится ниже. Больше высоту меняет только сводка, когда появляется или исчезает, и поле «Другое», когда растёт по тексту.

Пока карточка ждёт, статус спросившего агента везде, где он виден, — в карточке хода, в списке задач, на странице агента — читается «Ждёт ответа»: та же иконка и цвет, что у «Ждёт подтверждения», другое слово.

## Content Rules

- Вопросы, подписи и описания вариантов пишет агент; они не переводятся и не усекаются, длинное слово переносится в любом месте.
- Итог — короткая фраза и время: «Отвечено · 14:37».
- Свой ответ после отправки показан целиком, с переносами строк как ввёл сотрудник.
- Тексты карточки — agent-guidance UXRD, MC-1 – MC-5.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | `group` с именем «Вопрос от {источник}» |
| Вопрос | `fieldset`, легенда — текст вопроса с номером; у вопроса с несколькими ответами пометка входит в легенду |
| Варианты | Один ответ — `radiogroup` из `radio`, несколько — флажки. Доступное имя — подпись варианта, описание — `aria-describedby` |
| «Другое» | Радиокнопка или флажок «Другое» и поле с доступным именем «Свой ответ на вопрос {номер}» |
| Клавиатура | Tab: ссылка источника, затем по вопросу — группа радиокнопок одной остановкой (стрелки переключают и выбирают) или каждый флажок, затем поле «Другое»; затем «Ответить» и «Пропустить». Space отмечает. Enter в поле «Другое» переводит фокус к следующему вопросу, на последнем — на «Ответить»; Shift+Enter — перенос строки. Ctrl+Enter и Cmd+Enter внутри карточки равны «Ответить» |
| Фокус | Появление карточки фокус не забирает. Выбор «Другое» ставит фокус в его поле. После ответа или пропуска — на карточку (программный фокус на контейнер) |
| Недоступная кнопка | «Ответить» без ответов остаётся в порядке Tab, причина — её описание |
| Объявления | Появление карточки объявляет экран; ошибка отправки — `role="alert"` один раз; сводка не объявляется, она — описание «Ответить» |
| Итог | Ответы — список описаний (`dl`): вопрос — `dt`, ответ — `dd` |
| Цвет | Выбор передаёт отметка контрола, статус и итог — иконка и текст; подложка — дополнительный признак |
