# Окно «Поделиться»

## Purpose

Диалог, в котором тот, кто может делиться записью библиотеки, выбирает, кто её видит, и решает, предлагает ли её главный чат получателей. Сотрудник открывает запись только своим ролям, администратор открывает системную запись ролям, отдельным сотрудникам или всем. Владелец в аудитории всегда, и убрать себя он не может.

## Anatomy

**Сотрудник:**

```
Поделиться «Разбор оплат»                               ✕   1 заголовок
Кто видит                                                    2 аудитория
  🔒 Вы — владелец, видите всегда
  ☑ SRE
  ☐ Оплаты
  ☑ Дежурный     вы больше не в этой роли
  ⓘ Запись сразу появится в чате участников отмеченных      3 последствие
    ролей и будет работать с их правами.
Предлагать в главном чате                         [●━]      4 переключатель
  Выключите — и чат коллег не предложит её сам.
  Вы запускаете запись всегда.
                                    [Отмена] [Сохранить]    5 действия
```

**Администратор, системная запись:**

```
Кто видит
  (•) Все сотрудники с ролью     ( ) Выбранные               6 режим
  [ Найти роль или сотрудника…                    ]          7 поиск
  SRE ✕   Борис Ким ✕                                        8 выбранные
```

1. **Заголовок** — Heading: «Поделиться» и имя записи в «ёлочках».
2. **Аудитория** — подпись «Кто видит»; первая строка владельца — иконка `Lock`, текст `--muted-foreground`, без флажка. Дальше флажки по ролям смотрящего, по алфавиту. Роль, которой запись уже открыта, а владелец из неё ушёл, стоит отмеченной с пометкой Caption `--muted-foreground`; снятую, её нельзя вернуть.
3. **Последствие** — `Info` и Caption `--muted-foreground`; видно, пока отмечена хоть одна роль.
4. **Переключатель** — shadcn `switch` с подписью и подсказкой Caption.
5. **Действия** — «Отмена» (`outline`) и «Сохранить» (`default`) в подвале.
6. **Режим** — радиогруппа: «Все сотрудники с ролью» или «Выбранные».
7. **Поиск** — поле со списком совпадений: роли и сотрудники, сотрудник — имя и почта Caption. Только в режиме «Выбранные».
8. **Выбранные** — чипы с кнопкой «Убрать»; пусто — Caption «Никто, кроме администраторов».

Диалог — правила [формы диалога](./settings-form.md) и shadcn `dialog`, ширина 480 px; на ширине < 768 px — на весь экран.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Сотрудник | Владелец делится своей записью | Части 1–5 |
| Администратор | Администратор делится системной записью | Вместо флажков ролей — части 6–8; строки владельца нет |

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Loading | Строки-скелетоны на месте ролей | Действия недоступны |
| Default | Отмечено то, что сохранено | «Сохранить» недоступна, пока ничего не изменено |
| Ролей нет | Вместо флажков — текст Caption `--muted-foreground` | Переключатель доступен, «Сохранить» — после его изменения |
| Сохраняем | «Сохранить» с `LoaderCircle`, всё недоступно | — |
| Сохранено | Диалог закрывается; уведомление (chat-shell UXRD, TST-01) | Фокус — на кнопку, которая открыла диалог |
| Отказ | Ошибка формы с причиной над действиями; выбор остаётся | Например, роль, из которой владелец только что ушёл |
| Ошибка загрузки | Текст и «Повторить» на месте ролей | — |

## Content Rules

- Роли и имена сотрудников не переводятся.
- Тексты — custom-agents UXRD, MC-14.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | `dialog` с заголовком; аудитория — `fieldset` с легендой «Кто видит» |
| Владелец | Строка владельца — текст, не элемент управления |
| Пометка роли | Описание флажка (`aria-describedby`) |
| Переключатель | `switch` с подписью и подсказкой как описанием |
| Поиск | `combobox` со списком вариантов; выбранный чип — кнопка «Убрать: {имя}» |
| Фокус | При открытии — на первый флажок или на радиогруппу; Esc и «Отмена» закрывают без изменений |
| Ошибка | `alert` |
