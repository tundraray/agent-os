# Выбор темы

## Purpose

Выбор одной из встроенных тем ([themes.md](../themes.md)), где каждая видна ещё до выбора. Сотрудник выбирает свою тему, администратор — тему организации. Режим — светлый, тёмный, системный — здесь не выбирается: он остаётся в меню пользователя.

## Anatomy

```
┌──────────────────────┐ ┌──────────────────────┐ ┌──────────────────────┐
│▐▀▀▀▀▀▀▀▀▀▌▐▀▀▀▀▀▀▀▀▀▌│ │▐▀▀▀▀▀▀▀▀▀▌▐▀▀▀▀▀▀▀▀▀▌│ │▐▀▀▀▀▀▀▀▀▀▌▐▀▀▀▀▀▀▀▀▀▌│
│▐ светлый ▌▐  тёмный ▌│ │▐ светлый ▌▐  тёмный ▌│ │▐ светлый ▌▐  тёмный ▌│  1 образец
│▐▄▄▄▄▄▄▄▄▄▌▐▄▄▄▄▄▄▄▄▄▌│ │▐▄▄▄▄▄▄▄▄▄▌▐▄▄▄▄▄▄▄▄▄▌│ │▐▄▄▄▄▄▄▄▄▄▌▐▄▄▄▄▄▄▄▄▄▌│
│ Как в организации  ✓ │ │ Графит               │ │ Петроль              │  2 название, 3 отметка
│ Сейчас: Графит       │ │                      │ │                      │  4 подпись
└──────────────────────┘ └──────────────────────┘ └──────────────────────┘
```

1. **Образец** — схема оболочки в цветах самой темы, разделённая пополам: слева светлый режим, справа тёмный. В каждой половине — полоса сайдбара с двумя строками, у одной метка выбранного; строка заголовка цветом `--foreground`, строка текста `--muted-foreground`, кнопка-таблетка `--primary` и три точки `--chart-1` … `--chart-3`. Образец не зависит от текущих темы и режима и не содержит текста.
2. **Название** темы — UI, `--foreground`.
3. **Отметка** выбранной карточки — иконка `CircleCheck` 16 px цветом `--primary` справа от названия.
4. **Подпись** — Caption `--muted-foreground`, только у карточки «Как в организации».

## Variants & Sizes

| Вариант | Где | Чем отличается |
|---|---|---|
| Сотрудник | Своя тема сотрудника | Первая карточка — «Как в организации»: образец и подпись показывают тему организации. Выбор сразу перекрашивает весь интерфейс |
| Организация | Тема организации в панели администратора | Только встроенные темы. Выбор сохраняется для всех, а интерфейс самого администратора перекрашивается, только если он следует теме организации |

- Карточки стоят сеткой: в ряд столько, сколько помещается при ширине карточки не меньше 148 px, промежуток 12 px; на 360 px — две в ряд.
- Образец — 64 px в высоту на всю ширину карточки, радиус md; карточка — радиус lg, отступ 8 px.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Фон `--card`, рамка 1 px `--border` | Клик или касание выбирает карточку |
| Hover | Рамка `--input`, фон под названием `--accent` | — |
| Focus | Кольцо фокуса 3 px `--ring`, смещение 2 px, вокруг всей карточки | Стрелки переходят к соседней карточке и сразу выбирают её; Space выбирает карточку в фокусе |
| Выбрана | Рамка 2 px `--primary`, отметка, название начертанием 500 | В варианте «Сотрудник» новая тема применяется ко всему интерфейсу в том же кадре, без перехода цвета ([foundations → Motion](../foundations.md#motion)); выбор сохраняется в фоне, карточки остаются доступными, действует последний выбор |
| Не сохранилось | Отметка вернулась на сохранённую карточку, интерфейс — в сохранённую тему; под сеткой Caption `--destructive`: в варианте «Сотрудник» — просьба повторить, в варианте «Организация» — причина словами сервера | Фокус остаётся на карточке, где был; новый выбор повторяет сохранение, и ошибка уходит |

Пока сохранение идёт, ничего не блокируется: тема уже видна, и человек может перейти к следующей, сравнивая их вживую.

## Content Rules

- Название темы — собственное имя без слова «тема»: «Графит», «Петроль», «Nord». Имя переводится, как любая подпись платформы; Nord одинаков на обоих языках.
- Подпись «Как в организации» называет текущую тему организации и меняется вместе с ней.
- Пояснение к выбору стоит под сеткой одной фразой и говорит, где действует выбор.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | `radiogroup`, названная заголовком секции; карточка — `radio` |
| Доступное имя | Название темы; у «Как в организации» описанием служит подпись — «Сейчас: Графит» |
| Образец | Декоративный, скрыт от программ чтения с экрана |
| Клавиатура | Tab приводит на выбранную карточку; стрелки ходят по сетке в порядке чтения и выбирают; Space выбирает карточку в фокусе |
| Объявления | После применения темы — `polite` с её названием; отказ сохранения — `alert` |
| Признак выбора | Рамка, отметка и начертание — не только цвет; в «Графите» рамка графитовая и держит контраст выбранного ([foundations → Color](../foundations.md#color), «Акцент») |
