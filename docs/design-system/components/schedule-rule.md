# Правило расписания

## Purpose

Поле «Когда» в форме расписания: сотрудник выбирает вид правила, задаёт время и сразу видит, когда будет следующий запуск и в каком часовом поясе. Предпросмотр следующего запуска нужен, чтобы ошибка в правиле была видна до сохранения, а не после пропущенного утра. Поле стоит внутри [формы настроек](./settings-form.md) и следует её правилам подписи, подсказки и ошибки.

## Anatomy

```
Когда                                                        1 подпись
( Один раз ) ( Каждый день ) (• По дням недели ) ( Каждые N часов )   2 вид
[Пн] [Вт] [Ср] [Чт] [Пт]  Сб   Вс        в [ 09:00 ]         3 параметры
Следующий запуск: 26 нояб., 09:00                            4 предпросмотр
Время по поясу Europe/Moscow (UTC+3)                         5 пояс
```

1. **Подпись** — как у поля формы настроек.
2. **Вид** — четыре сегмента в одном ряду, UI 14; выбранный — фон `--secondary`, текст `--foreground`, начертание 500; остальные — `--muted-foreground`. Ряд переносится целыми сегментами.
3. **Параметры** — набор полей зависит от вида (Variants). Время — поле часов и минут в 24-часовом формате, дата — поле даты, дни — семь кнопок-переключателей шириной 40 px, число часов — числовое поле шириной 80 px.
4. **Предпросмотр** — Caption, `--foreground`, обновляется при каждом изменении параметров.
5. **Пояс** — Caption, `--muted-foreground`: пояс браузера и его смещение. У сохранённого расписания — пояс, в котором оно создано.

## Variants & Sizes

| Вид | Параметры | Значения по умолчанию |
|---|---|---|
| Один раз | Дата и время | Завтра, текущий час, округлённый вверх |
| Каждый день | Время | 09:00 |
| По дням недели | Дни и время | Пн–Пт, 09:00 |
| Каждые N часов | Число часов | 1 |

Значения из другого вида не теряются при переключении: вернувшись к виду, сотрудник видит то, что ввёл. Высота полей — по плотности формы.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Выбран вид, параметры заполнены, предпросмотр показывает дату и время | Предпросмотр меняется сразу, без кнопки |
| Hover | Сегмент и кнопка дня — фон `--accent` | — |
| Focus | Кольцо `--ring` на сегменте, кнопке дня или поле | Стрелки ←/→ двигают выбор вида внутри ряда сегментов |
| День выбран | Кнопка дня — фон `--secondary`, текст `--foreground`, начертание 500 | Повторное нажатие снимает выбор |
| Ошибка | Рамка поля `--destructive`, под параметрами — текст ошибки Caption `--destructive`; на месте предпросмотра — «—» | Сохранение формы не проходит, фокус уходит на первое поле с ошибкой. Ошибки: время в прошлом, ни одного дня, число часов не целое или меньше 1 |
| Только чтение | Правило одной строкой текста (Content Rules) и строка пояса | На странице расписания вне формы |

## Content Rules

- Правило одной строкой: «Один раз: 26 нояб., 09:00», «Каждый день в 09:00», «По будням в 09:00» (Пн–Пт), «Пн, Ср, Пт в 09:00», «Каждый час», «Каждые 3 часа». Все семь дней — «Каждый день в …».
- Слова при числе часов — полной фразой со всеми формами языка ([foundations → Слова при числах](../foundations.md#слова-при-числах)).
- Дни недели — короткими словами языка интерфейса, неделя начинается с понедельника.
- Время и дата — по [foundations → Language & Formats](../foundations.md#language--formats).

## Accessibility

| Аспект | Правило |
|---|---|
| Вид | Группа радиокнопок с именем «Когда»; сегмент — радиокнопка |
| Дни | Группа с именем «Дни недели»; кнопка дня — переключатель с полным названием дня («понедельник») и состоянием «нажата» |
| Поля | Подписи «Дата», «Время», «Каждые, часов» связаны с полями |
| Предпросмотр | Живая область `status`: изменение читается после паузы ввода, без повтора одинакового текста |
| Ошибка | Текст ошибки связан с полем и объявляется при попытке сохранить |
