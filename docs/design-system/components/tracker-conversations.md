# Беседы задачи

## Purpose

Беседы, которые открыли поручения одной задачи трекера: что каждая делает сейчас, какому агенту поручена и когда. Строка ведёт в беседу. Это не список бесед сайдбара: здесь только беседы одной задачи, без групп по датам, и удалённая беседа остаётся строкой без ссылки.

## Anatomy

```
Беседы · 3                                               1 заголовок
✋ Ждёт вас                                               2 состояние
Разбор алертов за выходные · 2 ↗                         3 название
Сводка дежурства · поручено 27 нояб., 14:00              4 агент · время
─────────────────────────────────────────
Разбор алертов за выходные ↗
Агент чата · поручено 26 нояб., 18:30
─────────────────────────────────────────
Разбор алертов за выходные · беседа удалена              5 удалённая
Сводка дежурства · поручено 26 нояб., 10:15
```

1. **Заголовок** — Heading «Беседы · {N}», N — все беседы задачи, вместе с удалёнными.
2. **Состояние** — [состояние беседы](./agent-status.md#состояния-беседы): иконка 14 px и метка Caption цветом состояния. Строки нет, если беседа закончила работу и прочитана.
3. **Название** — UI `--foreground`, до двух строк с усечением в конце, стрелка 14 px `--muted-foreground` в конце. Вся строка — ссылка на беседу.
4. **Агент и время** — Caption `--muted-foreground`: значок вида 14 px и имя агента, которому поручена беседа, « · », «поручено» и время поручения.
5. **Удалённая беседа** — название и « · беседа удалена» `--muted-foreground`, без стрелки; строка не ссылка.

Строки идут от нового поручения к старому; отступ строки 8 px по вертикали, строки делит 1 px `--border`. Ширина — колонка, в которой стоит компонент.

## Variants & Sizes

Вариант и размер один; ширину и место задаёт экран.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Строки по порядку | Клик или Enter открывают беседу |
| Hover | Фон строки `--accent`, кроме удалённой | — |
| Focus | Кольцо `--ring` внутрь строки-ссылки | Удалённая строка фокус не получает |
| Новая беседа | Строка встаёт первой сразу, число в заголовке растёт | Фокус не двигается |
| Смена состояния | Иконка и метка меняются растворением 150 ms; появление и уход строки состояния не двигают остальные строки скачком | Под reduced motion — мгновенно |
| Беседа удалена | Строка переходит в вид 5 на месте | Если на ней был фокус, он уходит на заголовок |
| Loading | 2 строки-скелетона по две полосы | Пульсация — [foundations → Motion](../foundations.md#motion) |
| Empty | Под заголовком без числа — строка Caption `--muted-foreground` | Действие поручить — на экране, не в компоненте |

## Content Rules

- Название беседы — как в списке бесед; имя агента — как в библиотеке, у агента чата — «Агент чата».
- Время — по [foundations → Language & Formats](../foundations.md#language--formats), строка «Время в списках и ленте».
- Тексты — task-tracker UXRD, MC-10.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | Секция с заголовком `h2`, под ним список (`ul`); строка — `li` |
| Ссылка строки | Имя — «{название}», затем скрытым текстом состояние, агент и время: «, ждёт вас, Сводка дежурства, поручено 27 нояб., 14:00» |
| Удалённая строка | Текст той же строки со словами «беседа удалена» |
| Клавиатура | Tab по ссылкам строк; Enter открывает беседу |
| Объявления | Смены состояния не объявляются |
| Цвет | Состояние передают форма иконки и слово |
