# Исполнитель workflow

## Purpose

Один участник команды workflow в редакторе: агент, которого координатор может вызвать. Карточка показывает, что исполнитель делает, сколько раз его можно вызвать, даёт ли он итог workflow и откуда он скопирован. Если источник в библиотеке изменился, карточка говорит об этом и даёт обновить копию одним действием. Порядка у карточек нет: в каком порядке вызывать исполнителей, решает координатор.

## Anatomy

```
┌───────────────────────────────────────────────┐
│ Сбор логов                         итог    ⋯  │  1 имя · 2 метка итога · 3 меню
│ Собирает ошибки gateway за период             │  4 описание
│ Haiku · sentry, incidents      до [ 3 ] раз   │  5 параметры · 6 предел вызовов
│ из Сбор логов · моя  версия 2                 │  7 источник
│ ⓘ Источник изменился: версия 3   [Обновить]   │  8 состояние источника
└───────────────────────────────────────────────┘
```

1. **Имя** — UI 500; кнопка, которая открывает панель исполнителя.
2. **Метка итога** — [метка состояния](./state-badge.md), вариант «Источник», «итог»; только у исполнителя последнего шага.
3. **Меню** «⋯» — «Изменить», «Сделать итогом» или «Не итог», «Обновить из источника» (только у копии из библиотеки), «Убрать из команды».
4. **Описание** — UI, `--muted-foreground`, до двух строк.
5. **Параметры** — Caption, `--muted-foreground`: модель и серверы. Метку «нет доступа у вас» несёт только сервер, на который автор потерял право уже после копирования: при добавлении из библиотеки и при обновлении серверы без права автора в копию не входят, а под карточкой встаёт строка со списком выпавших (custom-agents UXRD, WF-02).
6. **Предел вызовов** — числовое поле 28 px шириной 56 px между словами «до» и «раз»; от 1, табличные цифры.
7. **Источник** — Caption: «из» и [подпись записи](./record-label.md), вариант «Под названием», с версией, с которой скопирован исполнитель. Только у копии из библиотеки.
8. **Состояние источника** — строка Caption с иконкой 14 px; только когда источник изменился или недоступен.

Подложка `--card`, рамка 1 px `--border`, радиус lg, отступ 12 px; карточки идут столбцом с промежутком 8 px. Порядок — по имени; номеров, стрелок и линий между карточками нет.

**Панель исполнителя** — shadcn `sheet` справа шириной 560 px, на ширине < 768 px — на весь экран. В ней поля [редактора агента](./record-editor.md) (имя, описание, промпт, модель, предел ходов, серверы) и кнопка «Готово». Правка в панели меняет форму workflow, но не сохраняет её: сохраняет общая панель сохранения редактора.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Свой | Исполнитель создан в workflow с нуля | Нет частей 7 и 8, нет «Обновить из источника» |
| Из библиотеки | Исполнитель скопирован из агента библиотеки | Части 7 и 8 |

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Как в анатомии | Клик по имени или Enter открывает панель исполнителя |
| Hover / Focus | Фон `--accent` у карточки; кольцо `--ring` у имени и полей | — |
| Источник изменился | Строка 8: `Info` цветом `--info`, текст `--foreground`, кнопка «Обновить» (`outline`, `sm`) | «Обновить» спрашивает подтверждение (`alert-dialog`): определение исполнителя заменит последняя версия источника, предел вызовов и метка итога останутся |
| Обновляем | «Обновить» с `LoaderCircle`, недоступна | — |
| Обновлено | Строки 8 нет, версия в части 7 новая | Объявление `polite`; изменение ждёт сохранения workflow |
| Источник недоступен | Строка 8: `CircleMinus` и текст `--muted-foreground`; «Обновить» нет | Источник удалён или закрыт для автора; исполнитель остаётся и работает |
| Ошибка предела | Рамка поля `--destructive`, текст ошибки под карточкой | Пустое поле или ноль |
| Ушла из команды | Схлопывается за 150 ms | Под reduced motion — мгновенно |

## Content Rules

- Имя исполнителя уникально в команде: по имени его называют правила координатора.
- Тексты — custom-agents UXRD, MC-13.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | Команда — список (`ul`) с именем «Команда»; карточка — `li` |
| Имя | Кнопка с именем «{имя}, изменить»; метка итога и предел читаются после неё |
| Предел вызовов | Числовое поле с доступным именем «Предел вызовов: {имя}» |
| Меню | Кнопка «Действия: {имя}» |
| Панель | `dialog` с заголовком «Исполнитель «{имя}»»; Esc и «Готово» закрывают её, фокус возвращается на имя карточки |
| Состояние источника | Текст строки 8 — описание кнопки имени |
