# Сабагент

## Purpose

Один сабагент глубокого агента в редакторе: агент из его команды, которого он может позвать или назначить исполнителем задачи. Карточка показывает, за что сабагент отвечает и когда его звать, чем он работает и пишет ли он ответ. Если агент-источник в библиотеке изменился или пропал, карточка говорит об этом. Порядка у карточек нет: кого и когда звать, решает глубокий агент по строкам команды, а порядок задач задают зависимости.

## Anatomy

```
┌───────────────────────────────────────────────┐
│ Сбор логов                    пишет ответ  ⋯  │  1 имя · 2 метка ответа · 3 меню
│ За что отвечает и когда звать                 │  4 строка ответственности
│ [ Собирает ошибки gateway за период задачи  ] │
│ Haiku · Sentry, Инциденты · до 3 раз          │  5 сводка
│ ⓘ Агент «Сбор логов» обновлён в библиотеке    │  6 строка источника
│                        [ Взять новую версию ] │
└───────────────────────────────────────────────┘
```

1. **Имя** — UI 500; кнопка, которая открывает панель сабагента.
2. **Метка ответа** — [метка состояния](./state-badge.md), вариант «Источник», «пишет ответ»; только у финального сабагента. Только показывает выбор: меняют его в поле «Кто пишет ответ» редактора.
3. **Меню** «⋯» — «Изменить», «Убрать из команды».
4. **Строка ответственности** — обязательное поле «За что отвечает и когда звать»: подпись Caption и многострочное поле UI с высотой по содержимому, 1–3 строки. По ней глубокий агент и сабагенты, которые ставят задачи, выбирают исполнителя.
5. **Сводка** — Caption, `--muted-foreground`: модель, системы и «до {N} раз» за запуск. Метку «у вас недоступна» несёт только система, на которую автор потерял право после копирования.
6. **Строка источника** — Caption с иконкой 14 px; только когда агент-источник изменился или пропал. У сабагента из библиотеки без изменений строки нет.

Подложка `--card`, рамка 1 px `--border`, радиус lg, отступ 12 px; карточки идут столбцом с промежутком 8 px. Порядок — по имени; номеров, стрелок и линий между карточками нет.

**Панель сабагента** — shadcn `sheet` справа шириной 560 px, на ширине < 768 px — на весь экран. Поля: имя, строка ответственности, инструкция и системы, как в [редакторе агента](./record-editor.md), и «Дополнительно» с моделью, максимумом шагов и полем «Сколько раз можно звать за запуск» (целое число в пределах контракта). Кнопка «Готово». Правка в панели меняет форму глубокого агента, но не сохраняет её.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Свой | Сабагент создан в записи с нуля | Части 6 нет никогда |
| Из библиотеки | Сабагент скопирован из агента библиотеки | Часть 6, когда источник изменился или пропал; строка ответственности сначала заполнена описанием агента |

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Как в анатомии | Клик по имени или Enter открывает панель сабагента |
| Hover / Focus | Фон `--accent` у карточки; кольцо `--ring` у имени и поля | — |
| Источник обновлён | Строка 6: `Info` цветом `--info`, текст `--foreground`, «Взять новую версию» (`outline`, `sm`) | Нажатие сразу, без диалога, заменяет инструкцию, модель, максимум шагов и системы версией источника. Имя, строка ответственности, «сколько раз звать» и метка ответа остаются. Отменяет «Отменить изменения» редактора |
| Новая версия взята | Строки 6 нет | Объявление `polite`; изменение ждёт сохранения записи. Системы, к которым у автора нет доступа, не вошли — под карточкой Caption-строка с их списком |
| Источник пропал | Строка 6: `CircleMinus`, текст `--muted-foreground`, без действия | Агент удалён или закрыт для автора; сабагент остаётся и работает |
| Нет строки ответственности | Рамка поля `--destructive`, под полем текст ошибки Caption `--destructive` | Появляется при сохранении; неудачное сохранение ставит фокус в поле первой такой карточки. Ввод снимает ошибку |
| Ошибка имени | Панель открыта с ошибкой у имени | Имя уже есть в команде |
| Переименован | Новое имя на карточке | Стартовые задачи и «Кто пишет ответ» следуют за сабагентом; инструкция получает заметку со старым именем |
| Ушёл из команды | Схлопывается за 150 ms | Стартовые задачи этого сабагента получают ошибку исполнителя; под reduced motion — мгновенно |

## Content Rules

- Имя сабагента уникально в команде: по имени его называют инструкция, задачи и список задач запуска.
- Строка ответственности — одна-две фразы, что делает и когда нужен; порядок шагов в ней не задают.
- Тексты — custom-agents UXRD, MC-13, и deep-agents UXRD, MC-5.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | Команда — список (`ul`) с именем «Сабагенты»; карточка — `li` |
| Имя | Кнопка с именем «{имя}, изменить»; метка ответа и сводка читаются после неё |
| Строка ответственности | `textarea` с видимой подписью; ошибка — `aria-invalid` и `aria-describedby` |
| Меню | Кнопка «Действия: {имя}» |
| Панель | `dialog` с заголовком «Сабагент «{имя}»»; Esc и «Готово» закрывают её, фокус возвращается на имя карточки |
| Строка источника | Текст — описание кнопки имени; после «Взять новую версию» фокус — на имя карточки |
