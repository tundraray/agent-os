# Метка запуска ресерча

## Purpose

Метка отмечает сообщение пользователя, которое запустило глубокий ресерч его явным выбором. По ней сообщение-запуск видно в истории, и на него ведёт ссылка «К запросу» из ответа ресерча. Метка не интерактивна.

## Anatomy

```
                    ⌕ Глубокий ресерч
┌────────────────────────────────────────┐
│ Почему с 14:00 выросли ошибки платежей? │
└────────────────────────────────────────┘
```

- **Иконка** — `Telescope`, 14 px, `--muted-foreground`.
- **Подпись** — Caption, `--muted-foreground`; текст — deep-research UXRD, MC-4.

Иконка и подпись стоят в одну строку с промежутком 4 px.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Как в Anatomy | Не реагирует на наведение и нажатие |
| Сообщение в фокусе | Без изменений; кольцо фокуса — у сообщения | Ссылка «К запросу» переводит фокус на сообщение, метка читается вместе с ним |

## Content Rules

- Подпись не усекается и не меняется после отправки.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | Текст внутри сообщения; иконка декоративная (`aria-hidden`) |
| Доступное имя | Подпись читается перед текстом сообщения |
| Клавиатура | Не фокусируется |
| Цвет | `--muted-foreground` держит 5–8,5:1 к поверхностям ([foundations → Color](../foundations.md#color)) |
