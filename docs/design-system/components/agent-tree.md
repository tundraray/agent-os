# Дерево агентов

## Purpose

Список агентов и запусков workflow сотрудника по всем беседам: дочерние агенты стоят под родителями. По строке видно, что это за агент, в каком он статусе, на какой модели, когда запущен и из какой беседы. Строка ведёт на страницу агента. Токенов и стоимости в списке нет.

## Anatomy

**Широкая область (основная область не уже 720 px):**

```
Агент                                     Статус               Модель   Запущен   Беседа      1 шапка колонок
▾ Глубокий ресерч · почему падают оплаты   ⟳ Работает           Sonnet   14:35     Ошибки опл… 2 · 3 · 4 · 5 · 6 · 7
    План                                   ✓ Завершён           Haiku    14:35
    Сбор · ошибки gateway                  ⟳ Работает           Haiku    14:36
▸ Инциденты по оплате                      ✓ Завершён           Haiku    14:20     Ошибки опл…
```

**Узкая область (уже 720 px):**

```
▾ ⟳ Глубокий ресерч · почему падают оплаты         2 · 3 (иконка) · 4
    Sonnet · 14:35 · Ошибки оплаты                  5 · 6 · 7 в строке мета
```

1. **Шапка колонок** — Caption, `--muted-foreground`; только в широкой области.
2. **Раскрытие** — кнопка 24×24 с `ChevronDown` / `ChevronRight` 14 px; только у строк с дочерними.
3. **Описание** — ссылка, UI, `--foreground`, одна строка с усечением в конце; полное — в подсказке.
4. **Статус** — [agent-status](./agent-status.md): «Метка» в широкой области, «Иконка» перед описанием в узкой.
5. **Модель** — Data, `--muted-foreground`.
6. **Запущен** — Data, табличные цифры, `--muted-foreground`.
7. **Беседа** — ссылка на беседу, Data; только у корневых строк, у дочерних пусто.

Компактная плотность ([foundations → Spacing & Density](../foundations.md#spacing--density)): строка 32 px, в узкой области две строки по 20 px; при грубом указателе строка не ниже 44 px. Отступ уровня — 16 px, после четвёртого уровня отступ не растёт. Строки делит `--border`; ширина — вся область до 1200 px.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Агент | Обычный агент | Описание — задание агента |
| Запуск workflow | Сессия координатора | Описание — имя шаблона и вопрос брифа; дочерние — агенты шагов |

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Корневые строки по времени запуска, новые сверху | Клик по строке или Enter по ссылке открывает страницу агента |
| Раскрыто / свёрнуто | Шеврон вниз / вправо; дочерние видны / скрыты | При загрузке раскрыты корни в статусах «Работает», «Ждёт подтверждения», «Прерван», остальные свёрнуты. Дальше раскрытие меняет только сотрудник: смена статуса строку не раскрывает и не сворачивает. Выбор живёт до перезагрузки |
| Hover | Фон `--accent` у всей строки | — |
| Focus | Кольцо `--ring` внутрь строки у ссылки, у кнопки раскрытия — своё | — |
| Новая строка | Раскрывается по высоте за 150 ms | Если список прокручен, видимые строки остаются на месте; под reduced motion — мгновенно |
| Смена статуса | Как в agent-status | Высота строки не меняется, порядок строк — тоже |
| Строка удалена | Схлопывается за 150 ms | Беседу удалили вместе с её агентами |
| Loading | Шапка колонок и 8 строк-скелетонов 32 px разной ширины | Пульсация — [foundations → Motion](../foundations.md#motion) |
| Partial | Под последней строкой — «Показать ещё» (`ghost`, `sm`), как SB-10 в chat-shell UXRD | Подгружает следующие корневые строки вместе с их дочерними |

Пустое состояние и ошибку загрузки задаёт экран, на котором стоит дерево.

## Content Rules

- Описание — как его дал чат или координатор; не переводится.
- Модель — короткое имя: «Haiku», «Sonnet».
- Время — «ЧЧ:ММ» за сегодня, иначе «12 нояб., ЧЧ:ММ».

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | Вложенные списки: корень — `ul`, дочерние — `ul` внутри `li` родителя. Шапка колонок — `aria-hidden` |
| Доступное имя | Ссылка — описание; статус, модель и время читаются следом как текст, со скрытыми подписями «модель», «запущен», «беседа» |
| Раскрытие | `button` с `aria-expanded` и `aria-controls` на список дочерних; имя — agent-platform UXRD, MC-7 |
| Клавиатура | Tab по кнопке раскрытия, ссылке агента и ссылке беседы в каждой строке; Enter и Space раскрывают |
| Объявления | Смена статуса и новые строки не объявляются |
| Цвет | Статус передают иконка и текст или доступное имя |
