# Лоток очереди

## Purpose

Лоток показывает над композером то, что уже принято, но агент или чат ещё не получил: сообщения сотрудника, сообщения других агентов, отчёты дочерних агентов. В ленте стоит только то, что агент действительно получил, поэтому после доставки запись уходит из лотка и встаёт в ленту на своё место.

## Anatomy

```
┌ ◷ Ждут доставки · 2 ─────────────────────────────────┐  1 заголовок
│ Вы          а что по стейджу?                        │  2 запись: источник · текст
│ Отчёт       Инциденты по оплате                      │
│ ⓘ Ждём вашего решения по запросу выше — сообщения    │  3 подсказка
│   уйдут после него.  К запросу ↑                     │
└──────────────────────────────────────────────────────┘
┌──────────────────────────────────────────────────────┐
│ Спросите что-нибудь…                    [Прервать][↑]│  композер (chat-shell TH-04)
```

1. **Заголовок** — иконка `Clock` 14 px и текст с числом записей; Caption, `--muted-foreground`, табличные цифры.
2. **Запись** — источник (Caption, `--muted-foreground`, колонка 80 px) и текст (UI, `--foreground`), не больше двух строк с усечением в конце.
3. **Подсказка** — иконка `Info` цветом `--info` и текст (UI, `--foreground`) со ссылкой «К запросу» (`--primary`); только в состоянии «Заблокирован решением».

Лоток — над композером, той же ширины, промежуток 8 px. Подложка `--muted`, рамка 1 px `--border`, радиус lg, отступ 8 px 12 px, компактная плотность. Тексты — agent-platform UXRD, MC-21.

## Variants & Sizes

Один вариант, один размер. Видно не больше трёх записей; остальные сводит строка «и ещё {N}» под ними.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Пусто | Лотка нет, место под него не занято | — |
| Есть записи | Заголовок и записи в порядке отправки | Новая запись встаёт в конец, раскрываясь по высоте за 150 ms; лента над композером остаётся прижатой к последнему сообщению |
| Доставка | Запись схлопывается за 150 ms; в ленте на её месте появляется сообщение | Последняя запись уходит вместе с лотком |
| Заблокирован решением | Есть записи и подсказка | Чат или агент ждёт решения по карточке решения, поэтому записи не уйдут до решения. «К запросу» прокручивает ленту к карточке и переводит на неё фокус |
| После перезагрузки | Как «Есть записи» | Недоставленные записи остаются в лотке и доставляются один раз |

Под reduced motion раскрытие и схлопывание мгновенные. Записи не интерактивны: убрать запись из очереди нельзя.

## Content Rules

- Источник — одно слово или «Отчёт»; текст записи — начало сообщения или описание агента, который прислал отчёт.
- Текст сообщения сотрудника не меняется и не переводится.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | `region` с именем «Ждут доставки»; записи — список |
| Объявления | Новая запись от сотрудника — `role="status"` «Сообщение ждёт доставки», один раз; доставка не объявляется |
| Клавиатура | Фокусируется только ссылка «К запросу» |
| Фокус | «К запросу» — на карточку решения |
| Цвет | Источник передаёт текст |
