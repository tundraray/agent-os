# Список трекера

## Purpose

Задачи трекера сотрудника одним плотным списком: статус, название, что сейчас делают её беседы и когда задача менялась. Строка ведёт на экран задачи. Список рассчитан на десятки открытых и сотни закрытых задач, поэтому строка одна и читается одним взглядом, а открытые задачи разложены по группам статуса. Шаги плана агента — другой компонент, [список задач](./run-task-list.md).

## Anatomy

```
Нужно решение · 1                                                    1 заголовок группы
?  Согласовать окно релиза                      ✋ Ждёт вас   14:20   2 статус · 3 название · 4 беседы · 5 время
На проверке · 2
◕  Разобрать алерты за выходные                 • Новый ответ  12:05
◕  Сводка по инцидентам ноября                                вчера
В работе · 1
◐  Найти, почему падает выгрузка                ◌ Работает   11:40
```

1. **Заголовок группы** — Caption 500 `--muted-foreground`, « · » и число задач табличными цифрами; отступ сверху 16 px, у первой группы 0. Пустых групп нет.
2. **Статус** — [статус задачи трекера](./tracker-status.md), вариант «Иконка», в слоте 16 px.
3. **Название** — UI `--foreground`, одна строка с усечением в конце; полное — в подсказке. У задач «Готово» и «Отменена» — `--muted-foreground`.
4. **Беседы** — [состояние беседы](./agent-status.md#состояния-беседы): иконка и метка Caption цветом состояния. Показано одно состояние — то, что раньше всех требует сотрудника. Если ни одна беседа не работает, не ждёт и не непрочитана, места пусто.
5. **Время** — когда задача менялась последний раз: Caption `--muted-foreground`, табличные цифры, по правому краю.

Компактная плотность ([foundations → Spacing & Density](../foundations.md#spacing--density)): строка 36 px, при грубом указателе не ниже 44 px. Строки делит 1 px `--border`. Ширина — основная область до 1024 px.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| По группам | Открытые задачи | Части 1–5; группы идут в порядке экрана |
| Один статус | Выбран один статус | Без заголовков групп; иконка статуса остаётся |
| Узкий | Ширина области < 768 px | Вторая строка Caption `--muted-foreground` под названием: метка статуса, « · », метка беседы, « · », время; пустая часть выпадает вместе с разделителем. Иконка состояния беседы стоит перед её меткой. Строка не ниже 52 px |

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Группы и строки по порядку экрана | Клик или Enter открывают экран задачи |
| Hover | Фон строки `--accent` | — |
| Focus | Кольцо `--ring` внутрь строки | Tab идёт по строкам сверху вниз |
| Новая строка | Встаёт на своё место в группе сразу, без анимации | Видимые строки не сдвигаются, если список прокручен ниже неё |
| Смена статуса или беседы | Иконка и метка меняются растворением 150 ms; задача с новым статусом переходит в свою группу | Если на строке был фокус, он остаётся на ней в новой группе |
| Строка ушла | Строка исчезает сразу, число в заголовке группы уменьшается | После удаления задачи или смены статуса на закрытый в списке открытых |
| Loading | Заголовок-скелетон и 6 строк-скелетонов разной ширины | Пульсация — [foundations → Motion](../foundations.md#motion) |
| Empty | Иконка 24 px `--muted-foreground`, строка UI `--foreground` и строка Caption `--muted-foreground` по центру области | Текст и действие решает экран |
| Error | Текст ошибки и «Повторить» (`outline`, `sm`) по центру | «Повторить» возвращает Loading |

Под reduced motion смена иконки мгновенная.

## Content Rules

- Название — как его написал сотрудник; не переводится, усекается только в конце.
- Время — по [foundations → Language & Formats](../foundations.md#language--formats), строка «Время в списках и ленте».
- Тексты — task-tracker UXRD, MC-4 и MC-5.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | Каждая группа — заголовок `h2` и список (`ul`) под ним; строка — `li` со ссылкой |
| Ссылка строки | Имя — «{название}, {статус}», затем скрытым текстом состояние беседы и время: «, ждёт вас, изменена 14:20» |
| Иконки | Декоративные внутри ссылки: всё сказано её именем |
| Клавиатура | Tab по ссылкам; Enter открывает задачу |
| Объявления | Новые строки, переходы между группами и смены не объявляются |
| Цвет | Статус и состояние передают форма иконки и слово |
