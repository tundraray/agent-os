# Редактор записи

## Purpose

Форма, в которой владелец правит свою запись библиотеки, а администратор — системную: агента или workflow. Редактор собран из полей [формы настроек](./settings-form.md) и добавляет к ней то, чего у короткой формы нет: длинный текст промпта, выбор серверов и моделей только из прав автора, номер версии, панель сохранения, конфликт с более новой версией и защиту несохранённых изменений.

## Anatomy

```
Библиотека / Разбор оплат · моя  ролевая  версия 3   [Поделиться] ⋯   1 шапка
Имя              [ Разбор оплат                    ]                    2 поля основы
Описание         [ Разбирает падения оплат…        ]  84 / {предел}
Промпт           [                                 ]                    3 длинный текст
                 [                                 ]
Модель           [ Haiku                         ▾ ]                    4 модель
Предел ходов     [ 40 ]
Серверы          ☑ sentry      Ошибки и события                         5 выбор серверов
                 ☑ jira        ⊖ нет доступа у вас — останется в записи
                 ☐ incidents   Инциденты
Может запускать  Сбор логов · моя ✕   [ + Добавить ]                    6 записи для запуска
⚠ Запись изменилась: сохранена версия 4 …                               7 конфликт
● Есть несохранённые изменения       [Отменить изменения] [Сохранить]   8 панель сохранения
```

1. **Шапка** — ссылка на раздел, [подпись записи](./record-label.md) с версией (`h1` — имя), справа «Поделиться» (`outline`, `sm`) и меню «⋯». Новая запись — заголовок «Новый агент» или «Новый workflow» без версии.
2. **Поля основы** — «Имя» и «Описание»; у описания справа счётчик знаков Caption табличными цифрами.
3. **Длинный текст** — многострочное поле Body 16 / 26 с высотой по содержимому: от 8 строк до 60 % высоты окна, дальше прокрутка внутри поля.
4. **Модель** — выпадающий список моделей из прав автора; у администратора на системной записи — весь каталог. Модель, на которую автор потерял право, остаётся выбранной с [меткой](./state-badge.md) «нет доступа у вас», а сохранение с ней отклоняется ошибкой поля.
5. **Выбор серверов** — флажки по серверам, к которым у автора есть право: имя Mono 13 / 20 и описание Caption. Сервер, на который автор потерял право, стоит первым, отмечен и несёт [метку](./state-badge.md) «нет доступа у вас»; его можно снять, но вернуть нельзя. У администратора на системной записи — все серверы реестра и над ними переключатель «Все серверы развёртывания»; включённый, он делает флажки недоступными.
6. **Записи для запуска** — подписи записей-агентов чипами с кнопкой «Убрать»; «Добавить» открывает поиск по видимым автору агентам библиотеки.
7. **Конфликт** — блок предупреждения формы настроек (`--warning-subtle`, `TriangleAlert`) над панелью сохранения.
8. **Панель сохранения** — прилипает к низу основной области: слева состояние Caption, справа «Отменить изменения» (`ghost`) и «Сохранить» (`default`; у новой записи — «Создать»).

Поля идут одной колонкой шириной до 720 px. Плотность — комфортная у сотрудника и компактная в панели администратора ([foundations → Spacing & Density](../foundations.md#spacing--density)).

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Агент | Запись вида «агент» | Части 2–6 |
| Workflow | Запись вида «workflow» | Вместо 3–6: пояснение, правила координатора, модель и предел ходов координатора, команда из [исполнителей](./executor-item.md) и поле «Итог даёт». В основной области не уже 1024 px правила и команда стоят двумя колонками (команда — 360 px справа), уже — одна под другой |
| Системная | Администратор правит системную запись в панели | Модель — из каталога, серверы — из реестра с «Все серверы развёртывания»; у встроенной записи в меню нет «Удалить»; у пустой формы workflow нет подсказки начать в чате |

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Чисто | Панель: «Сохранено · версия {N}» или у новой — пусто; «Сохранить» и «Отменить изменения» недоступны | Недоступность — `aria-disabled`, а не `disabled`: кнопки остаются в порядке Tab и не теряют фокус, нажатие ничего не делает |
| Изменено | Точка 6 px `--muted-foreground` и «Есть несохранённые изменения» | Кнопки доступны; «Отменить изменения» возвращает сохранённые значения без вопроса |
| Ошибка поля | Как в форме настроек | Фокус — на первое поле с ошибкой |
| Сохраняем | «Сохраняем…» с `LoaderCircle`, поля недоступны | Кнопки — `aria-disabled`, фокус остаётся на «Сохранить»; повторное нажатие ничего не делает |
| Сохранено | Панель: «Сохранено · версия {N}», версия в шапке растёт | Фокус остаётся на «Сохранить»; новая запись получает свой адрес |
| Сервер отказал | Ошибка формы над панелью; введённое остаётся | Фокус — на блок ошибки |
| Конфликт | Блок конфликта; введённое остаётся; «Сохранить» заменена на «Сохранить поверх» | «Открыть версию {N}» открывает сохранённую версию в новой вкладке; «Сохранить поверх» спрашивает подтверждение (`alert-dialog`) и сохраняет правку как следующую версию |
| Уход с изменениями | `alert-dialog` «Уйти без сохранения?» | Ссылка, кнопка «Назад» и закрытие вкладки при изменениях спрашивают; фокус по умолчанию — «Остаться» |

Смена состояния панели — растворение 150 ms; панель не меняет высоту.

## Content Rules

- Подписи полей и тексты состояний — custom-agents UXRD, MC-7–MC-13.
- Счётчик описания — «{знаков} / {предел}»; предел задаёт дизайн части `library` (custom-agents PRD, FR-06).
- Подсказка под полем объясняет последствия, а не формат: у серверов — что получит агент при запуске.

## Accessibility

| Аспект | Правило |
|---|---|
| Заголовок | `h1` — имя записи или «Новый агент» / «Новый workflow» |
| Поля | Как в [форме настроек](./settings-form.md#accessibility); счётчик — описание поля, объявляется только при превышении предела |
| Серверы | `fieldset` с легендой «Серверы»; метка «нет доступа у вас» — описание флажка |
| Записи для запуска | Чипы — список; кнопка «Убрать: {имя}» |
| Панель | Область `region` «Сохранение»; смена «Сохранено · версия {N}» объявляется `polite` |
| Конфликт, ошибка | `alert`; фокус переходит на блок |
| Клавиатура | Ctrl+S / Cmd+S сохраняет, когда фокус внутри формы; Enter в многострочном поле — перенос строки |
