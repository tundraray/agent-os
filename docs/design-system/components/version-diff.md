# Отличие версий

## Purpose

Показывает, чем одна версия агента или workflow отличается от другой: какие поля изменились и что именно в длинных текстах добавлено и убрано. Администратор читает так кандидата перед включением и прежнюю версию перед возвратом. Неизменённые поля сворачиваются в одну строку, чтобы взгляд шёл только по правке.

## Anatomy

```
Без изменений: Описание, Модель                               1 строка без изменений
Инструкция                                                    2 поле
    Ты разбираешь падения оплат.                              3 строка контекста
  − Ищи ошибки в логах gateway.                               4 убранная строка
  + Ищи ошибки в логах сервиса из вопроса.                    5 добавленная строка
  ▸ ещё 18 строк без изменений                                6 свёрнутый контекст
Максимум шагов      30 → 40                                   7 короткое значение
Системы             + Sentry   − Jira                         8 список
Команда · Сбор логов
  За что отвечает   − собирает ошибки gateway                 9 исполнитель
                    + собирает ошибки сервиса из задания
```

1. **Строка без изменений** — Caption `--muted-foreground`: подписи полей, которые совпадают, через запятую. Нет совпадающих полей — строки нет.
2. **Поле** — подпись Caption `--muted-foreground`, как в [определении записи](./definition-view.md); поля идут в порядке редактора.
3. **Строка контекста** — неизменённая строка длинного текста, Body `--foreground`; вокруг каждой правки — до двух строк контекста сверху и снизу.
4. **Убранная строка** — знак «−» в колонке 16 px цветом `--destructive`, подложка строки `--destructive-subtle`, текст Body `--foreground`.
5. **Добавленная строка** — знак «+» цветом `--success`, подложка `--success-subtle`, текст Body `--foreground`. Если строка пары изменилась частично, изменённые слова подчёркнуты линией 2 px цвета знака и набраны 500.
6. **Свёрнутый контекст** — `ghost` `sm` «ещё {N} строк без изменений» с шевроном; раскрывает строки на месте.
7. **Короткое значение** — модель, максимум шагов, «Кто пишет ответ»: «было → стало», UI `--foreground`, стрелка `--muted-foreground`.
8. **Список** — системы, «Может запускать», исполнители команды: добавленные с «+», убранные с «−», цвет знака как у строк; неизменённые элементы не показываются.
9. **Исполнитель** — изменённый исполнитель workflow — подзаголовок «Команда · {имя}» и его изменённые поля по тем же правилам; новый и убранный исполнитель — строкой списка.

Компонент стоит в колонке прозы (chat-shell UXRD, D-01): длинный текст сравнивают строка под строкой, а не двумя колонками, и это одинаково работает с 360 px. Промежуток между полями 16 px, между строками текста — без промежутка.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Агент | Запись вида «агент» | Поля агента; «Инструкция» — длинный текст |
| Workflow | Запись вида «workflow» | Поля workflow; «Как работает команда» — длинный текст; исполнители по части 9 |

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Только изменённые поля, контекст свёрнут по правилу части 3 | Порядок полей постоянный |
| Контекст раскрыт | Свёрнутые строки на месте кнопки | Раскрытие по высоте 150 ms, под reduced motion — мгновенно; фокус — на первую раскрытую строку |
| Нет отличий | Строка Caption `--muted-foreground` «Совпадает с версией {N}» | Бывает после возврата версии с тем же содержимым |
| Loading | Три строки-скелетона разной ширины | Пульсация по foundations |

## Content Rules

- Тексты версий показываются как написаны: без перевода, усечения и смены разметки.
- Подписи полей — как в редакторе записи (custom-agents UXRD, MC-7, MC-12); остальные тексты компонента и заголовок над ним — self-correction UXRD, MC-13.
- Длинная строка переносится; знак «+» или «−» стоит только у первой строки переноса.

## Accessibility

| Аспект | Правило |
|---|---|
| Структура | Список описаний (`dl`): поле — `dt`, правка — `dd` |
| Строки текста | Каждая убранная и добавленная строка начинается со скрытого «убрано:» или «добавлено:»; знак «+» или «−» скрыт от скринридера |
| Изменённые слова | Подчёркивание и вес — дополнительные признаки; смысл несут слова «убрано» и «добавлено» |
| Раскрытие контекста | `button` с `aria-expanded` |
| Цвет | Подложки декоративны: убранное и добавленное различают знак и скрытое слово |
| Клавиатура | Tab только по кнопкам раскрытия |
