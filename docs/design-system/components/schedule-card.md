# Карточка расписания

## Purpose

Короткая строка-итог в ленте после того, как агент беседы завёл, изменил, поставил на паузу, возобновил или удалил расписание. Агент уже всё сделал, поэтому решать в карточке нечего: она называет расписание, говорит, что с ним теперь, и даёт переход в форму расписания. Каждый вызов даёт свою карточку, и она хранит итог этого вызова.

## Anatomy

```
┌──────────────────────────────────────────────────────┐
│ ◷  Утренняя сводка                      [ Открыть ]  │  1 значок · 2 имя · 5 кнопка
│    На паузе · По будням в 09:00 ·                    │  3 строка
│    Europe/Moscow (UTC+3) · Только чтение             │
│    Полный доступ снят: расписание теперь только      │  4 пометка
│    читает. Вернуть его можно в форме — «Открыть».    │
└──────────────────────────────────────────────────────┘
```

1. **Значок** — часы, 16 px, `--muted-foreground`, по верху имени.
2. **Имя** расписания — UI, 500, `--foreground`.
3. **Строка** — Caption, `--muted-foreground`, через « · »: итог действия, если он есть, строка правила по [правилу расписания → Content Rules](./schedule-rule.md#content-rules), пояс расписания со смещением и уровень доступа.
4. **Пометка** — UI, `--foreground`, под строкой. Две пометки: о снятом полном доступе — только у изменения, которое его сняло, и «Расписание удалено» — когда расписания больше нет.
5. **Кнопка** «Открыть» — shadcn `button`, `outline`, `sm`, справа, по центру первой строки.

Ширина — колонка прозы ленты. Рамка 1 px `--border`, радиус lg, подложка `--card`, без тени; отступ 12 px, промежуток между значком и текстом 8 px. Карточка стоит под блоком вызова инструмента расписания.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Создано | Агент завёл расписание | Строка без итога; кнопка есть |
| Изменено | Агент изменил расписание | Как «Создано»; пометка о снятом доступе, если изменение его сняло |
| На паузе, Возобновлено | Агент поставил на паузу или возобновил | Строка начинается итогом; кнопка есть |
| Удалено | Агент удалил расписание | Строка начинается «Удалено», уровня доступа в ней нет; значок и имя `--muted-foreground`; кнопки нет |

Размер один. При грубом указателе кнопка — 44 px. На ширине < 480 px имя и строка переносятся, кнопка остаётся справа.

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Как в варианте | Карточка не меняется, когда расписание потом меняют |
| Hover, Focus | У кнопки — по shadcn `button`, кольцо `--ring` | Карточка целиком не кликается |
| Расписание удалено | Кнопка приглушена как недоступная, под строкой пометка «Расписание удалено» | Ставится при показе ленты; если расписание удалили, пока лента открыта, — при нажатии, без открытия формы. Кнопка остаётся в порядке Tab |

## Content Rules

- Имя и строка не усекаются и переносятся.
- Время и пояс — по [foundations → Language & Formats](../foundations.md#language--formats); пояс — тот, что у расписания.
- Итог — одно слово или короткая фраза с заглавной буквы в начале строки.
- Тексты — chat-scheduling UXRD, MC-1.

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | `group` с именем «Расписание «{название}»»; строка и пометка читаются текстом |
| Кнопка | Имя «Открыть расписание «{название}»»; недоступная — `aria-disabled` с описанием «Расписание удалено» |
| Объявления | Появление карточки не объявляется — итог называет ответ агента. Пометка, появившаяся после нажатия, объявляется `polite` |
| Фокус | Появление карточки фокус не двигает; закрытие формы возвращает фокус на «Открыть» |
