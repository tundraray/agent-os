# Форма настроек

## Purpose

Как устроены формы панели администратора: подписи и поля, подсказки, значения для копирования, сохранение и ошибки. Поля, кнопки, переключатели, радиогруппы и выпадающие списки — компоненты shadcn (`input`, `button`, `switch`, `radio-group`, `select`, `label`, Source); спецификация задаёт, как они складываются в форму и как форма сохраняется.

## Anatomy

```
Название кнопки                                  1 подпись
[ Okta                                    ]      2 поле
Сотрудники увидят «Войти через Okta»             3 подсказка

Данные для IdP                                   4 группа
Sign-in redirect URI
https://agent-os.corp/auth/oidc/7/callback  [⧉]  5 значение для копирования

Не удалось сохранить: Okta не ответила        6 ошибка формы
[ Сохранить ]  [ Отмена ]                        7 действия
```

1. **Подпись** — UI 500, `--foreground`, над полем; у необязательного поля — «(необязательно)» `--muted-foreground`.
2. **Поле** — высота контрола по плотности страницы ([foundations → Spacing & Density](../foundations.md#spacing--density)): 28 px в панели администратора, 36 px на странице входа; ширина формы не больше 640 px.
3. **Подсказка** — Caption, `--muted-foreground`, под полем.
4. **Группа** — заголовок Heading и поля под ним; группы разделяет 24 px.
5. **Значение для копирования** — значение Mono 13 / 20 на `--muted`, радиус md, и иконочная кнопка `Copy` справа; значение не редактируется.
6. **Ошибка формы** — блок с подложкой `--destructive-subtle`, рамкой `--destructive-border`, иконкой `CircleX` `--destructive` и текстом `--foreground` над действиями.
7. **Действия** — основная кнопка (одна на форму) и `outline` «Отмена» слева направо, под формой.

Поля идут одной колонкой, промежуток между полями 16 px. Форма в диалоге — те же правила внутри диалога, действия — в его подвале.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Форма страницы | Подключение входа, регистрация сервера, сервер | Действия под формой; «Отмена» возвращает к записи или к списку |
| Форма диалога | Создать роль, добавить право, поднять квоту | Действия в подвале диалога; «Отмена» и Esc закрывают диалог без изменений |
| Сохранение на месте | Переключатель «Включено», «Право администратора»; одно поле с кнопкой «Сохранить» рядом | Переключатель сохраняет сразу; поле — своей кнопкой |

## States

| Состояние | Как выглядит | Как ведёт себя |
|---|---|---|
| Default | Поля с текущими значениями | Основная кнопка доступна всегда; проверка полей — при нажатии |
| Ошибка поля | Рамка `--destructive`, под полем Caption `--destructive` с текстом ошибки | Фокус на первое поле с ошибкой; ошибка уходит, когда поле изменили |
| Сохраняем | Основная кнопка с `LoaderCircle` и подписью «Сохраняем…», поля и кнопки недоступны | Повторное нажатие ничего не делает |
| Сохранено | Форма страницы возвращается к записи; уведомление «Сохранено» (chat-shell UXRD, TST-01) | Форма диалога закрывается, фокус — на кнопку, которая его открыла |
| Сервер отказал | Ошибка формы с причиной от сервера; поля сохраняют введённое | Фокус на блок ошибки; повтор — та же кнопка |
| Переключатель: сохраняем | Переключатель в новом положении, недоступен до ответа | Отказ — переключатель возвращается за 150 ms, причина — Caption `--destructive` под ним |
| Значение скопировано | Иконка `Check` 2 с вместо `Copy` | Подсказка «Скопировано» |

Уход со страницы с несохранёнными изменениями не спрашивает подтверждения: изменения теряются.

## Content Rules

- Подпись — существительное с заглавной буквы, без двоеточия. Технические названия полей стандарта (Client ID, Issuer) не переводятся.
- Подсказка — одна фраза, что изменится после сохранения или где взять значение.
- Ошибка поля называет, что исправить: «Введите адрес», а не «Неверное значение».
- Ошибка от сервера начинается с «Не удалось сохранить:» и называет причину словами сервера.

## Accessibility

| Аспект | Правило |
|---|---|
| Подпись | `label` связан с полем; подсказка и ошибка — описание поля (`aria-describedby`) |
| Ошибка поля | `aria-invalid` на поле |
| Ошибка формы | `alert` |
| Значение для копирования | Кнопка с именем «Копировать: {подпись}»; «Скопировано» — объявление `polite` |
| Переключатель | `switch` с подписью; отказ сервера объявляется как `alert` |
| Клавиатура | Enter в однострочном поле нажимает основную кнопку формы |
