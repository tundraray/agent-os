# Статус агента

## Purpose

Показывает, в каком статусе агент или запуск workflow: в списке агентов, в карточке хода, в шапке страницы агента, в отчёте и строкой события в ленте. Статусов шесть, по PRD `agent-platform` (раздел «Агенты», схема «Статусы агента»). Во всех местах один статус выглядит одинаково.

## Anatomy

```
⟳ Работает          1 иконка · 2 метка          (вариант «Метка»)
⟳                   1 иконка                    (вариант «Иконка»)
⏹ Остановлен вами · 14:40                       (вариант «Строка события»: 1 · 3 текст события · 4 время)
```

1. **Иконка** — 14 px, цвет основы статуса; стоит в слоте фиксированного размера.
2. **Метка** — Caption, цвет основы статуса; текст — agent-platform UXRD, MC-3.
3. **Текст события** — Caption, `--muted-foreground`: что произошло и, у сбоя, причина (agent-platform UXRD, MC-14).
4. **Время** — Caption, `--muted-foreground`, табличные цифры.

Иконка и метка — в одну строку с промежутком 4 px.

## Variants & Sizes

| Вариант | Когда | Чем отличается |
|---|---|---|
| Метка | Везде, где есть место: шапка, карточки, отчёт, строка списка на десктопе | Иконка и метка |
| Иконка | Строка шага в карточке хода, строка списка на мобильном | Только иконка; метка — доступное имя и подсказка |
| Строка события | Лента беседы или агента, когда статус сменился без реплики модели | Иконка и текст события с временем, по левому краю колонки |

## States

Каждое состояние — один статус агента. Роли цвета — [foundations → Статусы агента](../foundations.md#статусы-агента).

| Статус | Иконка | Цвет иконки и метки | Как ведёт себя |
|---|---|---|---|
| Работает | `LoaderCircle`, вращение | `--info` | Вращается, пока статус «Работает»; все такие иконки на экране вращаются в одной фазе |
| Ждёт подтверждения | `Hand` | `--approval` | Статична: агент ждёт человека |
| Прерван | `CirclePause` | `--muted-foreground` | Статична |
| Завершён | `CircleCheck` | `--success` | Статична |
| Сбой | `CircleX` | `--destructive` | Статична; причина — в строке события и в отчёте |
| Остановлен | `CircleStop` | `--muted-foreground` | Статична |

- **Смена статуса** — перекрёстное растворение иконки и цвета за 150 ms, без вспышки и без подсветки фона. Высота элемента не меняется, соседние элементы не сдвигаются ([foundations → Motion](../foundations.md#motion)).
- **Reduced motion** — вместо вращения `LoaderCircle` статичная `CircleDashed` того же цвета; смена статуса мгновенная.
- **Наведение** на вариант «Иконка» показывает подсказку с меткой через 500 ms; у вариантов «Метка» и «Строка события» подсказки нет.

## Content Rules

- Метка — одно-два слова без точки, с заглавной буквы. Метка не усекается.
- Текст события — короткая фраза без точки; причина сбоя идёт после двоеточия.
- Время — «ЧЧ:ММ» за сегодня, иначе «12 нояб., ЧЧ:ММ».

## Accessibility

| Аспект | Правило |
|---|---|
| Роль | Текст; иконка декоративная (`aria-hidden`) в вариантах «Метка» и «Строка события» |
| Доступное имя | Вариант «Иконка» — `img` с именем = метка статуса |
| Клавиатура | Не фокусируется; подсказка варианта «Иконка» показывается при фокусе на строке, в которой он стоит |
| Объявления | Компонент не объявляет смену статуса; что объявлять, решает экран |
| Цвет | Статус передают форма иконки и текст; цвет — дополнительный признак |
