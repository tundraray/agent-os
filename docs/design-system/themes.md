# Темы

Тема — набор значений для каждой роли цвета ([foundations → Color](./foundations.md#color)) в светлом и тёмном режиме. Здесь записаны три встроенные темы: откуда взята каждая, под какой лицензией, какие значения поправлены под полосу комфорта и что показала проверка контраста. Правила, которым подчиняется любая тема, и порядок проверки задают основы; эта страница хранит только значения и результаты.

| Тема | Характер | Источник | Лицензия |
|---|---|---|---|
| [«Графит»](#графит) — по умолчанию | Ахроматическая серая основа, графитовый акцент, плоские поверхности | Тема по умолчанию [bb](https://github.com/get-bb/bb), `apps/app/src/components/ui/theme.css` | MIT, Copyright (c) 2026 Michael Yong |
| [«Петроль»](#петроль) | Тёплая серая основа, бирюзовый акцент | Определена здесь | — |
| [Nord](#nord) | Холодная сине-серая основа, акцент цвета льда | Палитра [Nord](https://www.nordtheme.com), репозиторий `nordtheme/nord`, файл `license`; подбор ролей — по `apps/app/src/lib/themes/nord.ts` из bb | MIT, Copyright (c) 2016-present Sven Greb; bb — MIT |

Копия значения из bb или Nord сохраняет строку об авторских правах источника рядом с этими значениями в коде.

## Графит

Ориентир — тема по умолчанию bb: чистая серая шкала без оттенка, почти чёрный акцент на кнопках и метках, карточки на одном уровне со страницей. Сама тема bb выходит из полосы комфорта, поэтому каждое её значение поправлено; что именно, показывает таблица.

| Текст на акценте светлого режима — чистый белый, 15,07:1 | Чистый белый; контраст выше 15:1 | Текст на акценте — цвет фона, 13,13:1 |

- **Статусы агента и графики** — значения «Петроль» без изменений.
