## Direction

- **Характер**: спокойный нейтральный инструмент, в котором работают с агентами часами без усталости — тёплая мягкая серая основа, один акцент там, где решает человек, и точные цвета статусов там, где действует агент.
- **Эмоции**: ясность, контроль, уверенность, спокойная сосредоточенность, которая не выдыхается к концу дня.
- **Ориентиры**:
  - **ChatGPT** — монохромная оболочка, ритм ленты и композера, отсутствие декора вокруг текста.
  - **Linear** — плотные списки, статус как иконка плюс цвет, компактная плотность для данных, уровни контраста по выбору человека.
  - **Vercel / Geist** — шрифты Geist, табличные цифры, моноширинный шрифт для технических значений, иерархия рамками, а не тенями.
  - **iA Writer** — некипельный фон, мягкий тёмный текст и выверенная длина строки для многочасового чтения.

**Принципы, к которым сводится каждый выбор в основах:**

- **Комфорт долгой сессии — прежде всего.** Интерфейс открыт часами, поэтому ничто не слепит и не дёргает: контраст ограничен сверху и снизу, нет чистого белого и почти чёрного, насыщенный цвет — только на малой площади, строка и интерлиньяж — для длинного чтения, постоянное движение — только пока идёт работа. Обе темы проверены одинаково, по умолчанию тема следует за ОС.
- **Цвет означает состояние.** Серый — основа; акцент — действие или выбор человека; цвета статусов — состояние работы агента. Декоративного цвета нет.
- **Плотность по задаче.** Чтение и беседа — просторно; запуски, аудит и бюджеты — компактно.
- **Тишина по умолчанию.** Движение короткое и без пружин; ничего не мигает.
