# Секрет только на запись

## Problem

Администратор задаёт в панели секрет чужой системы — токен MCP-сервера, ключ провайдера моделей, — а платформа отправляет его в запросе к этой системе. Прочитать секрет обратно не может никто: ни ответ API, ни аудит, ни лог. Признак: поле, которое администратор вводит и может заменить, но не должен видеть после сохранения.

## Shape

- **Хранение** — столбец в таблице владельца секрета, значение как есть (решение владельца, [design-identity.md](../../features/enterprise-access/design-identity.md), KD-7). Читает его только код, который отправляет запрос к чужой системе.
- **Ответ API** — вместо значения признак «задан». Где панели нужно узнать, какой секрет стоит, ответ добавляет его последние четыре символа, вычисленные при чтении, без отдельного столбца.
- **Запись** — тело несёт новое значение или `null`, чтобы убрать секрет. Поле называется именем из списка секретных имён логгера (`apiKey`, `sharedToken`, `token`), поэтому логгер и `AuditLog` вырезают его по имени.
- **Аудит** — пишущая операция возвращает «было» и «стало», где секрет заменён меткой `changed`; `AuditLog` пишет `secret_changed`. Если операция в пакете, аудит пишет `apps/api` после неё.
- **Маска** — код, который читает или принимает значение, сразу кладёт его в память секретов процесса (`rememberSecret` из `common`), и маска логгера скрывает его с этого момента ([logging.md](./logging.md)).

## Reference

- `packages/agents/src/mcp/mcp-registry.ts` — метка `changed` и признак «задан»; `apps/api/src/audit/audit-log.ts` — `secret_changed`

## Not For

| Looks like | Use instead |
|---|---|
| секрет, который нужен до подключения к базе | переменная окружения, разобранная функцией сборки ([composition-root.md](./composition-root.md)) |
| значение, которое сервер только сверяет (пароль) | хеш, а не значение |
| несекретная настройка панели | строка настроек ([settings-row.md](./settings-row.md)) |
