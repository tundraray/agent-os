# Структурный ответ модели вызовом инструмента

## Problem

Код зовёт модель не как агента, а чтобы получить от неё данные заданной формы, которые потом проверит сам: операции графа знаний, выбор похожих сущностей, утверждения и цитаты. Признак: вызов модели вне шага модели агента, чей ответ код разбирает и применяет, а не показывает.

## Shape

- **Вызывающий** — обработчик шага или шаг агента в пакете `agents`. Он строит инструкции и одно сообщение, где всё внешнее — в конверте данных (`envelope`), и предлагает модели ровно один инструмент со схемой zod. Модель просят вызвать его один раз; принудительного выбора инструмента у вызова нет.
- **Раунд** — вызов `ModelClient.call` и разбор ответа: найти вызов инструмента по имени и разобрать аргументы свободной схемой, чтобы одна испорченная часть не губила весь ответ. Ответ без нужного вызова, с неразборчивыми аргументами или обрезанный на пределе длины (`cutOff`) получает одну повторную попытку: ошибка уходит модели результатом её вызова, а если вызова не было — новым сообщением. Второй такой ответ — исход `invalid_answer`. Раунд живёт в одном общем модуле пакета `agents`, его не копируют.
- **Три исхода вызова** — отказ `AccessGate` (`not_started`), ошибка модели и ответ — вызывающий обрабатывает сам: падение агента, пропуск раунда или продолжение без результата. Раунд их не решает.
- **Проверка** — разобранный ответ проверяет чистая функция ([pure-decision.md](./pure-decision.md)). Ссылкам модели на данные она не доверяет: модель видит короткие номера, которые выдал код, а функция переводит их обратно и отклоняет чужие.
- **Журнал** — счётчики и исходы, никогда тексты ответа модели и входа.

## Not For

| Looks like | Use instead |
|---|---|
| ход агента, где вызовы инструментов — действия | шаг модели и шаг инструментов ([step-handler.md](./step-handler.md)) |
| свободный текст, который код хранит как есть, например сводка сжатия | вызов `ModelClient.call` без инструментов |
| решение по уже прочитанным данным без модели | [pure-decision.md](./pure-decision.md) |
