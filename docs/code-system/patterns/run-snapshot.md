# Снимок запуска

## Problem

Запуск работает по данным, которые сотрудник или администратор может править и удалять, пока запуск идёт: определение агента, workflow, позже скилл или приложение. Признак: долгая работа читает изменяемую запись другого модуля, и правка этой записи не должна менять уже идущую работу.

## Shape

- **Процедура старта** — одна функция пакета `agents` (`resolveStart`). Она выбирает источник по виду старта, спрашивает модуль записей через порт от имени того, кто запускает, превращает содержимое в снимок и проверяет то, без чего старт бессмыслен, — сейчас модель. Каждый вид старта зовёт её, а не повторяет её шаги; новая проверка перед стартом встаёт в неё.
- **Порт записей** — объявлен в пакете, который зовёт (`RecordLibrary` в `agents`), реализован модулем записей в `apps/api` ([port-module-split.md](./port-module-split.md)). Невидимая запись отвечает как несуществующая.
- **Снимок** — содержимое записи в его хранимой форме из `contracts`, имя запуска и происхождение: номер записи, вид, версия, автор. Второго формата определения нет. Снимок пишется во вход задачи в транзакции шага, который стартует ребёнка, и больше не меняется.
- **Чтение** — шаги, инструменты и перезапуск берут определение только из снимка; определение, которое шаг передаёт модели, вычисляет из снимка одна чистая функция. Снимок из входа задачи читает одна функция рядом со схемой этого входа (`sessionInputOf` у `AgentTaskInputSchema`). Живые данные, которые запуск видит на каждом шаге (список записей для выбора, права), читаются отдельно и снимок не меняют. Строка сессии держит только то, что читают виды и счётчики: имя, происхождение и метку первого запуска.
- **Где спрашивают** — процедура работает в `prepare` инструмента, до транзакции шага. Повтор шага повторяет её; в силе снимок закоммиченной попытки.

## Not For

| Looks like | Use instead |
|---|---|
| данные, которые должны меняться и у идущей работы: права, квоты, аккаунты MCP | проверка перед каждым вызовом через порт (`AccessGate`) |
| настройка платформы, которую читают все запуски | константа кода или настройка в базе, без снимка |
| запись, которую только показывают, не запуская | чтение через маршруты модуля записей при открытии экрана ([read-on-open.md](./read-on-open.md)) |
