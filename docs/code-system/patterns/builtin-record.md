# Встроенная запись

## Problem

Платформа поставляет строки, без которых система не работает: роль «Супер-администратор», строки ключей настроек, агентов по умолчанию и агента `deep-research`. Администратор может часть из них править. Признак: строка нужна в каждой базе с постоянным id или ключом.

## Shape

- **Где лежат** — только в миграции встроенных строк `packages/db/src/migrations/0001_builtin_rows.sql`. Это custom-миграция (`drizzle-kit generate --custom`), её пишут руками; сгенерированную миграцию схемы руками не правят. Строк данных в других миграциях нет.
- **Агенты по умолчанию** — по одному на тип задачи: `builtin_key` равен `chat`, `agent`, `deep_agent` или `trainer`. У каждого агента постоянный id и версия 1 без автора ([immutable-versions.md](./immutable-versions.md)). Записи с ключами `chat` и `trainer` по имени и чипом не запускаются: главный чат — сам корень, а тренера начинает только кнопка обучения. `deep-research` лежит там же без ключа, с долей «всем», и дальше это обычный системный агент.
- **Новое содержимое** — меняется в миграции встроенных строк. Существующие базы не мигрируют: новое содержимое доходит до базы, когда базу пересоздают.
- **Проверка** — тест на новой базе разбирает строки агентов схемой их вида. Сломанная строка ломает тест в CI, а не запуск сервера.
- **Имя на языке страницы** — имя агента по умолчанию и роли, равное русскому из `BUILTIN_NAMES` в `contracts`, показывается на языке страницы (`builtinNameIn`); имя, которое дал администратор, — как есть ([interface-text.md](./interface-text.md)).

## Reference

- `packages/db/src/migrations/0001_builtin_rows.sql` — встроенные строки
- `packages/contracts/src/library.ts` — `BUILTIN_NAMES` и `builtinNameIn`

## Not For

| Looks like | Use instead |
|---|---|
| агент сотрудника или системный агент, которого создал администратор | маршруты через `LibraryService` и `LibraryPanelService`, инструменты записей через `LibraryChatService` |
| значение, которое администратор настраивает для всей платформы | [keyed-settings.md](./keyed-settings.md); строку ключа по умолчанию создаёт эта миграция |
| новое поле содержимого со значением по умолчанию | значение по умолчанию в схеме вида; строки не переписываются |
