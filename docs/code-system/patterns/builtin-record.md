# Встроенная запись

## Problem

Платформа поставляет кодом системные записи библиотеки — главный чат, агентов и флоу, — а администратор может их править. Признак: запись нужна в каждой базе с постоянным id, к этому id привязаны другие данные, а её содержимое меняется вместе с кодом.

## Shape

- **Определение** — `builtinRecords()` в модуле `library` приложения `apps/api`. У каждой записи постоянный id константой кода, `builtinKey` и содержимое, которое проходит схему своего вида (`CreateRecordBodySchema`). Имя засевается русским из `BUILTIN_NAMES` в `contracts`.
- **Сидер** — на старте приложения вставляет запись, если строки с её `builtinKey` нет, и не трогает существующую, даже правленую. Новая встроенная запись поэтому приходит в любую базу сама.
- **Новое содержимое существующей записи** — миграция только с данными ([ADR-0002](../../adr/ADR-0002-app-schema-migrations.md)) переписывает строку на месте по `builtinKey` литералом из `builtinRecords()` на момент генерации. Id, адресаты и значения, которые меняют только люди (`selfLearning`), остаются, версия растёт на 1. Удалить и вставить строку заново нельзя: к id записи каскадом привязаны граф знаний и адресаты. На новой базе строки ещё нет, миграция ничего не меняет, и сидер вставляет запись уже с новым содержимым.
- **Текст на языке страницы** — имя и описание, равные засеянным русским, показываются на языке страницы (`builtinNameIn` и такое же правило для описания); изменённые администратором — как есть ([interface-text.md](./interface-text.md)).

## Reference

- `apps/api/src/library/builtin-records.ts` — определения записей
- `apps/api/src/library/builtin-records.seeder.ts` — сидер
- `packages/contracts/src/library.ts` — `BUILTIN_NAMES` и `builtinNameIn`

## Not For

| Looks like | Use instead |
|---|---|
| запись сотрудника или системная запись, которую создал администратор | маршруты и инструменты записей через `LibraryService` |
| значение, которое администратор настраивает для всей платформы | [settings-row.md](./settings-row.md) |
| новое поле содержимого со значением по умолчанию | значение по умолчанию в схеме вида; строки не переписываются |
