# Текст интерфейса

## Problem

Код веба показывает сотруднику текст: надпись, подсказку, доступное имя кнопки, уведомление, отказ, дату, сумму, количество. Признак: любая строка, которую увидит или услышит сотрудник, и любое значение, которое форматируется для него. Если текст записан в коде экрана, его не перевести, а дата, отформатированная заранее, не следует за сменой языка.

## Shape

- **Каталоги** — JSON-файлы в `apps/web`, по одному на область экранов и язык (`en`, `ru`); область — пространство имён next-intl. Английский каталог задаёт тип сообщений, русский объявлен тем же типом, поэтому `tsc` отвергает пропущенный или лишний ключ. Ключ называет место и смысл по-английски в camelCase; данные-ключи (имя инструмента, код ошибки) идут как есть.
- **Языковой корень** — в корневом макете, внутри `<Suspense>` вокруг содержимого `<body>`: серверный компонент читает cookie `aos_locale` и `Accept-Language`, выбирает язык чистой функцией и отдаёт язык и сообщения клиентскому `NextIntlClientProvider` с часовым поясом браузера и общими форматами. Он же ставит `lang` на `<html>`. Поэтому язык есть у оболочки, страницы входа и страниц ошибок; сервер Next к API не ходит.
- **Компоненты** берут текст хуком `useTranslations` области, даты и числа — `useFormatter` с общими форматами. Фраза с числом, именем или видом — одно сообщение ICU с `plural` и `select`, а не склейка кусков.
- **Вне React** — стор, служба оболочки, адаптер — текст не собирают: они отдают ключ сообщения со значениями, а переводит компонент, который его показывает (`Announcer`, уведомление). Данные, а не отформатированные строки, хранятся в сторе.
- **Ключ из данных** (код ошибки с сервера, имя инструмента) проверяется на наличие перед переводом; при отсутствии показывается запасной вид, а не ключ.
- **Смена языка** — `router.refresh()` после того, как API поставил новую cookie: сервер рисует корень заново, клиентское состояние остаётся.
- **Проверка полноты** — правило `no-restricted-syntax` в `apps/web/eslint.config.mjs` запрещает кириллицу в строках, шаблонах и тексте JSX вне каталогов и тестов.

## Not For

| Looks like | Use instead |
|---|---|
| текст для модели: промпт, описание инструмента | остаётся в пакете на своём языке, вне каталогов |
| имя или содержимое, которое дал человек, модель или сервер MCP | показывается как пришло |
| перевод кода ошибки в текст | функция области ([web-api-client.md](./web-api-client.md), Not For), которая берёт сообщение из каталога |
| текст, который пишет сам API на языке сотрудника | только имя копии записи; язык приходит в теле запроса |
