# Стор оболочки

## Problem

Данные или намерение нужны нескольким экранам оболочки чата и должны пережить переход между ними без перезагрузки вкладки: кто вошёл, список агентов, живые данные записей библиотеки, чип для поля сообщения, черновик, который редактор берёт из беседы, несохранённая правка, о которой надо спросить перед уходом. Признак: значение кладёт один экран, а читает другой или несколько экранов сразу, и его не нужно хранить ни в адресе, ни на сервере.

## Shape

- **Стор** — хранилище zustand (vanilla) с фабрикой `create…Store` в модуле своей области в `src/lib`. Зависимости — клиент API, поток событий, логгер — фабрика получает параметрами.
- **Владелец** — `createShellServices` в `lib/threads/shell-services.ts`: создаёт стор один раз на монтирование оболочки и кладёт полем в `ShellServices`. Стор, который нужен не каждому визиту, создаётся при первом чтении (ленивый геттер, как `agentList`).
- **Чтение** — компоненты берут стор из `ShellServices` и подписываются селектором; экран не создаёт свой экземпляр.
- **Сервер** — стор, который держит данные API, читает их через модуль области клиента API ([web-api-client.md](./web-api-client.md)), перечитывает по событию (вход на экран, своё изменение, событие потока). Просьбы перечитать идут через `createCoalescedRunner` (`lib/live/coalesced-runner.ts`): просьба во время чтения получает ровно одно чтение после него, и все просьбы за время одного чтения делят это одно. Поэтому экран, который только что изменил запись, не получит список, прочитанный до своего изменения. Ошибку чтения стор пишет в лог один раз и прежние данные не стирает.
- **Перенос через перемонтирование** — то, что экран должен передать следующему экрану, который смонтируется на новом адресе, кладут в один перенос страницы `draftHandoff` (`lib/library/draft-handoff.ts`), а не в новый стор уровня модуля. Перенос знает адрес страницы, для которой он положен; эта страница забирает его при монтировании через `take(page)`, а перенос, положенный для другой страницы, при этом стирается.
- **Жизнь** — только память вкладки: ни адреса, ни `localStorage`. Перезагрузка вкладки начинает стор заново, поэтому в стор не кладут то, что должно пережить перезагрузку.

## Not For

| Looks like | Use instead |
|---|---|
| данные одного экрана, не нужные после ухода с него | `useResource` ([read-on-open.md](./read-on-open.md)) |
| то, что должно пережить перезагрузку или открыться ссылкой | адрес ([shell-route.md](./shell-route.md)) или сервер |
| лента одной беседы | `FeedStore` из `feeds.forThread` |
