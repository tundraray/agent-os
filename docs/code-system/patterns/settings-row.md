# Строка настроек

## Problem

Модулю нужны несколько значений, которые администратор меняет в панели и которые действуют на всю платформу: срок сеанса, лимит ходов новой записи, предел знаний в промпте. Признак: значение — не секрет, его правят без рестарта, а переменная окружения запрещена (настройки — в базе и в панели).

## Shape

- **Таблица из одной строки** — у модуля, который читает значения: первичный ключ — логическое поле, всегда `true`, с CHECK, поэтому вторая строка невозможна. Каждое значение — свой столбец со значением по умолчанию и CHECK границ; `updated_at` пуст, пока стоят умолчания; кто менял — в аудите. Строку создаёт миграция; код её только читает и обновляет.
- **Репозиторий** — чтение и запись строки над транзакцией ([repository-over-transaction.md](./repository-over-transaction.md)).
- **Чтение** — владелец читает строку там, где значение нужно, каждый раз заново, без кэша в памяти: правка действует со следующего чтения.
- **Маршруты** — `GET` и `PUT` под `@AdminOnly()` ([auth-boundary.md](./auth-boundary.md)); тело проверяет схема из `contracts` с границами, вне границ — 400 `VALIDATION_FAILED`, и ничего не меняется.
- **Аудит** — `admin_change` с «было» и «стало». Если строка в модуле `apps/api`, аудит пишется в транзакции записи. Если строка в пакете, его операция записи возвращает «было» и «стало», и `apps/api` пишет аудит после неё, как для реестра MCP.

## Reference

- `apps/api/src/library/library-settings.ts` — сервис, аудит в транзакции; таблица `library_settings` в `packages/db/src/schema.ts`

## Not For

| Looks like | Use instead |
|---|---|
| секрет или адрес, который нужен до подключения к базе | переменная окружения, разобранная функцией сборки ([composition-root.md](./composition-root.md)) |
| значение одной записи, которое правит её автор | поле в содержимом записи библиотеки |
| значение, которое идущая работа должна держать неизменным до конца | снимок запуска ([run-snapshot.md](./run-snapshot.md)) |
