# Строка настроек

## Problem

Администратор меняет в панели значение, от которого зависит работа платформы: лимит ходов новой записи, правила входа, срок хранения случаев. Настройки живут в базе, а не в переменных окружения и файлах. Признак: одно значение на всю установку, у него есть значение по умолчанию, и его смену нужно видеть в аудите.

## Shape

- **Таблица** — одна строка на область (`identity_settings`, `library_settings`). Ключ всегда `true`, и проверка базы держит ровно одну строку. Миграция, которая создаёт таблицу или добавляет столбец, пишет значение по умолчанию в эту строку; поле со своей проверкой границ базы.
- **Репозиторий** — чтение строки и запись всех полей области над транзакцией ([repository-over-transaction.md](./repository-over-transaction.md)).
- **Сервис настроек** в модуле области — `get` и `update`. `update` в одной транзакции читает прежнюю строку, пишет новую и событие аудита `admin_change` с типом объекта области (`library_settings`, `sign_in_settings`) и полями «было» и «стало», затем пишет строку лога с той же парой.
- **Контракт** — схема тела в `packages/contracts` несёт все поля области и их границы; ответ — те же поля и время правки. Новое поле области добавляется в эту схему, а не в свою таблицу, и тело остаётся полным: форма панели сохраняет все группы одной кнопкой.
- **Читатели** — другие модули берут значение через сервис настроек; маршрут сотрудника, если значение нужно ему, отдаёт только это поле.
- **Кто включил** — `updated_by` строки называет того, кто сохранил форму последним. Если работа идёт от имени того, кто включил настройку, у неё свои столбцы «кто» и «когда», и `update` пишет их только при включении.
- **Системная запись** — если настройка должна выключиться без администратора, сервис настроек пишет это сам при чтении, когда условие нарушено, с событием аудита от `SYSTEM_ACTOR`.

## Not For

| Looks like | Use instead |
|---|---|
| значение у каждой записи или у каждого сотрудника | столбец этой записи или строки прав |
| постоянная, которую администратор не решает (интервал таймера, размер страницы) | именованная постоянная в коде |
| секрет или параметр подключения процесса | окружение процесса, которое читает только `apps/api` |
