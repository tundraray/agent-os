# Блок промпта шага

## Problem

Модели агента на каждом шаге нужно живое состояние, которое хранится в таблицах, а не в истории: оглавление памяти, список задач сессии. История для него не годится: сжатие заменяет её сводкой, а запись в историю — это прошлое, а не текущее состояние. Признак: шаг агента должен показывать модели то, что меняется между шагами и переживает сжатие.

## Shape

- **Чтение** — шаг модели и шаг сжатия пакета `agents` читают состояние из таблиц перед каждым вызовом модели. Объект агента между шагами держит только свою сессию и историю, а блок не кеширует; версия агента, на которой идёт запуск, не меняется.
- **Текст** — одна функция пакета превращает прочитанное в блок текста для модели. Для пустого состояния она возвращает пустой блок.
- **Место** — блок ставится в конец системного промпта определения; в историю и в журнал он не пишется. Порядок блоков фиксирован, чтобы начало промпта оставалось одинаковым от шага к шагу.
- **Запись** — состояние меняют инструменты в коммите шага или отдельные задачи runtime, а не сам блок.

## Reference

- `packages/agents/src/agent/step-common.ts` — `withStepBlocks`: порядок блоков, общий для шага модели и шага сжатия
- `packages/agents/src/tools/system/task-list-block.ts` — блок задач сессии
- `packages/agents/src/agent/model-step.ts` — где шаг модели ставит блок

## Not For

| Looks like | Use instead |
|---|---|
| определение агента, которое не должно меняться в идущем запуске | [immutable-versions.md](./immutable-versions.md) |
| сообщение агенту о событии, которое он должен увидеть один раз | запись `notice` или `event` в истории |
| данные, которые модель запрашивает сама и не каждый шаг | инструмент чтения |
